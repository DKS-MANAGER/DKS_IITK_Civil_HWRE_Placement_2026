## Minimum Working Proficiency

### Python
- NumPy: array operations, broadcasting, linear algebra
- Pandas: DataFrame manipulation, groupby, merge, filter
- Matplotlib: figure creation, subplot layouts, customization
- SciPy: optimization, interpolation, statistical functions
- File I/O: CSV, JSON, text files
- Regex: pattern matching, string operations

### MATLAB
- Matrix operations and indexing
- Plotting: 2D plots, subplots, annotations
- Functions and scripts
- ODE solvers (ode45, ode15s)
- Curve fitting tool

### LaTeX
- Document structure: sections, subsections, chapters
- Mathematical expressions and equation arrays
- Tables (tabular, longtable) and figures
- Bibliographies (BibTeX)
- Beamer presentations

### Git
- Branch, commit, merge, rebase
- PR workflow, conflict resolution
- Remote management, tagging

### OpenFOAM
- Case structure: `0/`, `constant/`, `system/`
- Meshing: `blockMesh`, `snappyHexMesh`
- Boundary conditions specification
- Solver selection: `simpleFoam`, `pimpleFoam`, `interFoam`
- PostProcessing and y+ calculation
