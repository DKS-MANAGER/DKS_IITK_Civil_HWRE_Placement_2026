# Darwinbox

## Interview Process
Darwinbox's recruitment process consists of five rounds:

1. **MCQ Test** — Coding-related questions and core subjects
2. **Coding Round** — 2 medium-level coding questions; filtered on completion and efficiency
3. **First Technical Round (TR1)** — Data Structures and Algorithms (DSA) questions
4. **Second Technical Round (TR2)** — Full-stack development knowledge, emphasis on PHP and hands-on project experience
5. **HR Round** — General HR questions; generally straightforward

## Key Notes
- If you reach the HR round, you are likely selected
- TR2 is specific to full-stack development with PHP focus
- Coding efficiency is as important as completion

## Preparation Tips
- Master DSA fundamentals (arrays, trees, graphs, DP)
- Review full-stack concepts, especially PHP if applying for backend roles
- Prepare project explanations for technical rounds
