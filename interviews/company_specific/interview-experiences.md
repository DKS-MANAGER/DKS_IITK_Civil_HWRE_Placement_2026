## Tech Mahindra

### Process Overview
Tech Mahindra's on-campus recruitment consists of **5 rounds**:

1. **Aptitude Round** — Basic aptitude questions.
2. **English Comprehension** — Essay writing (300–400 words), listening transcription, and fill-in-the-blanks from audio.
3. **Coding Round** — 2 to 3 basic programming problems (e.g., array sum, prime number generation).
4. **Technical HR** — 30 to 40 minutes covering basic to medium-level programming theory and coding.
5. **General HR** — Personal details, location preference, and fit.

### Key Takeaways
- Aptitude and English are elimination filters; do not underestimate them.
- Coding is straightforward; focus on clean syntax and explaining your approach.
- Technical HR is conversational; be ready to discuss projects briefly.

## Schneider Electric India Pvt Ltd

### Process Overview
Schneider Electric visited VJTI, Matunga, Mumbai for campus recruitment (2011). Package offered: **4.75 LPA (CTC)**.

1. **Technical + Analytical Aptitude (60 min, 60 questions)**
   - Technical (Electronics): 30 questions — Control Systems, OP-AMPS, Zener Diode, Transistors.
   - Analytical (Quantitative, Data Interpretation, Logical Puzzles): 30 questions — CAT-level difficulty.

2. **Group Discussion (15 min)**
   - Topic: "Business ethics in the corporate world: A passing fad?"

3. **Technical Interview**
   - Flip Flops: J-K and S-R using NAND gates, truth tables, race around condition.
   - Bridge Wave Rectifier: Circuit diagram, waveforms, filtered output.
   - K-Maps: Explanation and drawing for a given truth table.
   - Semiconductor Memories: Types, volatile vs non-volatile.
   - Digital vs Analog Signal: Differences and classification of DC signals.

4. **HR Interview**
   - Tell me about yourself.
   - What do you know about Schneider Electric?
   - What are the different ways in which you can manage energy?
   - Energy management problem-solving scenario.
   - Flexibility to work anywhere in India.

### Key Takeaways
- GD topics are current and abstract; practice articulating balanced viewpoints.
- Technical questions are depth-first on core subjects; expect circuit-level and digital-logic details.
- HR probes domain awareness (energy management) and mobility.

## Expeditors

### Process Overview

Expeditors uses a Java (Spring Boot) and Angular stack. Technical interviews focus on object-oriented and database fundamentals.

### Common Technical Questions
- What is an Interface in Java and why is it used?
- What is the `abstract` keyword and how does it relate to interfaces?
- What is an Exception and how do you handle it in Java?
- Primary Key vs Foreign Key in SQL.
- `finalize` vs `finally` vs `final` in Java.
- What is a Thread? Is multithreading possible in Java?
- What is Inheritance and its types? Why is multiple inheritance not supported?
- Are there pointers in Java?
- Explain Garbage Collection. Is Java garbage-collected?
- What is JIT and AOT compilation? Does Java use JIT, AOT, or both?

### Key Takeaways
- Questions are concept-heavy; prepare to explain each topic with code examples.
- SQL and Java are core; know the differences between related concepts (e.g., keys, compilation types).

System design questions, Spring Boot-specific queries, and Angular front-end questions are not documented.

## Darwinbox

### Process Overview

1. **MCQ Test** — Coding-related and core-subject multiple-choice questions.
2. **Coding Round** — 2 medium-level problems; solutions are evaluated on correctness and time/space efficiency.
3. **First Technical Round (TR1)** — Data Structures and Algorithms questions.
4. **Second Technical Round (TR2)** — Full-stack development, emphasis on PHP and hands-on project experience.
5. **HR Round** — General fit questions; reaching this stage is a strong signal of selection.

### Key Takeaways
- Full-stack breadth matters; know your projects deeply.
- DSA rounds are standard; practice arrays, trees, and graphs.
- PHP familiarity is a differentiator for TR2.

## Deltax

### Process Overview

1. **MCQ Round** — Programming foundation and aptitude; shortlisting based on score and submission time.
2. **Coding Round** — 4 to 5 easy-to-medium questions; solve at least 80 percent.
3. **Interview Round** — Explain one coding-round solution, solve 1 to 2 LeetCode medium-level problems, and answer basic programming/software design questions.

### Key Takeaways
- Speed matters in the MCQ round; practice timed tests.
- Be ready to discuss your coding approach in depth during the interview.
- Software design fundamentals (OOP, basic architecture) are tested alongside coding.

## CEI America

### Process Overview

1. **Round 1: Aptitude and Technical Questions (40 questions)**
   - Quantitative Aptitude
   - Programming
   - Networks
   - Operating Systems

2. **Round 2: Coding Challenge (7 questions, attempt any 4)**

3. **Round 3: Technical Interview**
   - College project deep-dive
   - OOPS concepts (inheritance, encapsulation, polymorphism, abstraction)
   - SQL / Oracle database queries
   - Java / .NET / C / C++ practical questions
   - Software Development Life Cycle (SDLC)
   - Basics of algorithms and data structures
   - Programming arrays

### Key Takeaways
- Broad technical net; prepare CS fundamentals across multiple domains.
- Project discussion is mandatory; rehearse explaining design choices and trade-offs.
- Database and SDLC questions are recurring.
