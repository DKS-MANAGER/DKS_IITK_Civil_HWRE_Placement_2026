# Expeditors

## Interview Process
Expeditors conducts technical interviews focusing on Java backend (Spring Boot) and Angular frontend.

## Common Technical Questions

### Java Concepts
- **Interface vs Abstract Class** — Interfaces allow multiple inheritance and define method signatures; abstract classes cannot be instantiated directly
- **Exception Handling** — `try`, `catch`, `finally`, `throw`; checked vs unchecked exceptions
- **Inheritance** — Single, multilevel, hierarchical; no multiple inheritance via classes (use interfaces)
- **Threads & Multithreading** — Lightweight processes via `Thread` class or `Runnable` interface
- **Garbage Collection** — Automatic memory reclamation by JVM
- **JIT vs AOT Compilation** — JIT compiles bytecode at runtime; AOT compiles before execution

### SQL Concepts
- **Primary Key** — Uniquely identifies a record, cannot be null
- **Foreign Key** — Establishes relationship between tables

## Preparation Tips
- Master Java OOPs concepts and exception handling
- Practice SQL queries and database design
- Understand Spring Boot and Angular basics if applying for full-stack roles
