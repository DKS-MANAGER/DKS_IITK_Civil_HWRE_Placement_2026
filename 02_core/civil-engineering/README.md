# Civil Engineering Technical Preparation Hub

> **Target Audience**: IIT Kanpur Civil Engineering students and M.Tech HWRE candidates preparing for core civil engineering campus placements (EPC contractors, design consultancies, infrastructure developers, and PSU technical rounds).  
> **Placement Variance Notice**: Core engineering test formats, cutoff weightages, and interview depth vary by recruiter, role, and placement cycle. Always cross-verify role-specific requirements with the IIT Kanpur Students' Placement Office (SPO).

## 2. Integrated Mixed-Subject Timed Technical Mock Tests

In campus placement written tests, recruiters rarely present single-subject questions in isolation. Technical screening tests feature mixed-discipline sections with time limits.
