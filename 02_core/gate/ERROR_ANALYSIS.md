# GATE Civil — Error Analysis

> Track every mistake. Reattempt after 1 day, 3 days, and 7 days. This is the highest-ROI revision activity.

## How to Use

1. After every practice session or mock test, log each wrong answer.
2. Classify the error cause (below).
3. Re-solve the question after 1 day without looking at the solution.
4. Mark `Reattempt 1/3/7` as you pass each reattempt.

## Error Categories

| Category | Meaning | Fix |
| -------- | ------- | --- |
| `Concept` | Didn't understand the principle | Re-read notes + theory |
| `Formula` | Wrong/misremembered formula | Re-memorize from formula sheet |
| `Calculation` | Arithmetic slip | Slow down, verify with estimation |
| `Unit` | Unit conversion error | Always write units in every step |
| `Misread` | Misread the question | Underline key words (NOT, EXCEPT, max, min) |
| `Time` | Ran out of time | Improve speed with timed drills |
| `Guess` | Random guess | Eliminate options; never blind-guess |
| `Selection` | Chose wrong question to attempt | Prioritize high-confidence questions |

## Common GATE Traps (Checklist)

| Trap | Avoid By |
| ---- | -------- |
| Gauge vs absolute pressure | Always check: `p_abs = p_gauge + p_atm` |
| Hydraulic radius vs pipe radius | `R = A/P`; for full pipe `R = D/4`, not `D/2` |
| Gross vs net area (steel) | Tension uses net area for rupture, gross for yield |
| Effective vs total stress | `σ' = σ − u` |
| Degree vs radian | Trig functions in radians unless stated |
| kN vs N, mm² vs m² | Convert before substituting |
| Percentage vs decimal | `12% = 0.12` |
| Sign conventions (bending) | Define +ve direction first |
| Boundary conditions | Check supports before deflection formulas |
| BOD vs COD | `BOD < COD`, ratio ≈ 0.5–0.6 |
| SSD vs OSD | SSD = stopping, OSD = overtaking |
| Curvature vs refraction | Curvature −ve, refraction +ve |
| Critical depth vs normal depth | `y_c` from energy, `y_n` from Manning |
| Partial safety factors | `γ_f` for loads, `γ_m` for materials |
| One-way vs two-way slab | One-way: `l_y/l_x > 2` |

## Weekly Review Routine

- **Daily**: log errors after practice.
- **Weekly (Sunday)**: re-solve all errors from the week.
- **Monthly**: re-solve all errors from the month; delete mastered ones.
- **Pre-exam**: only re-solve errors marked `Concept` or `Formula`.
