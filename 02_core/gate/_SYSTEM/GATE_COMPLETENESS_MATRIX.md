## Scoring Rubric

| Dimension | 0–3 | 4–6 | 7–8 | 9–10 |
| --------- | --- | --- | --- | ---- |
| Study | Topic list only | Short paragraphs | Real explanations | Full concept + conditions + traps |
| Formula | Missing | Partial | Most key formulas | Complete + units + assumptions + traps |
| Examples | None | 1–2 | 3–5 | 5+ verified with method |
| Practice | None | Few | Basic + intermediate | Basic → GATE-level → hard |
| PYQ | None | Paper links | Topic-wise refs | Topic-wise + concept + solution ref |
| Test | None | — | Topic test | Topic + subject + full mock |
| Revision | None | Partial | Good | 30-min/2-hr/1-day supported |

## Priority System

| Priority | Meaning | Subjects |
| -------- | ------- | -------- |
| P0 — Must Master | Repeated direct-calculation questions | EM, SOM, Structural Analysis, RCC, Steel, Geotech, Fluid, Hydraulics, Hydrology, Env |
| P1 — High Value | Consistent question presence | Transportation, Geomatics, Construction Mgmt, Engineering Math |
| P2 — Moderate | Occasional questions | Specialized sub-topics (sediment transport, air pollution) |
| P3 — Low | Rare / advanced | Out-of-syllabus depth |
