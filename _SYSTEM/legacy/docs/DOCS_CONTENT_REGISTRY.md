## Sprawl Prevention Rules

1. **One canonical doc per topic.** Link everywhere else; do not duplicate.
2. **New topic → new entry here first.** Add the row, then create the file.
3. **No orphan content.** Every new file must be linked from at least one hub/guide.
4. **Keep this registry in sync** with [`DOCS_FILE_MAP.md`](DOCS_FILE_MAP.md).
