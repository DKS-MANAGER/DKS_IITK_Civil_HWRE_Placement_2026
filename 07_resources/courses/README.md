# Curated Courses & Technical Video Lectures

> **Domain**: Core Civil, Hydraulics, CFD, GIS, Programming & Consulting.

---

## 1. Core Civil & Water Resources Engineering (NPTEL / MOOCs)
* **Fluid Mechanics**: NPTEL IIT Kharagpur (Prof. S. Chakraborty) — *Comprehensive fluid kinematics, Navier-Stokes, boundary layer theory.*
* **Advanced Hydrology**: NPTEL IIT Kanpur (Prof. B.S. Murty / Prof. R. Srivastava) — *Infiltration, hydrograph analysis, flood routing.*
* **Open Channel Flow**: NPTEL IIT Roorkee (Prof. K. Subramanya / Prof. P.K. Mohapatra) — *Gradually varied flow, hydraulic jumps, channel transitions.*
* **Groundwater Hydrology**: NPTEL IIT Madras — *Darcy's Law, well hydraulics, aquifer pumping tests.*

---

## 2. Computational Fluid Dynamics & OpenFOAM
* **Computational Fluid Dynamics**: NPTEL IIT Madras (Prof. S. Majumder) — *Finite volume method, pressure-velocity coupling, turbulence.*
* **OpenFOAM Foundation Training**: Official OpenFOAM Foundation & CFD Direct Tutorials — *Meshing (blockMesh, snappyHexMesh), solver execution, ParaView post-processing.*

---

## 3. Programming & Data Science
* **CS50 / Python for Everybody**: Harvard / Univ. of Michigan — *Python fundamentals, data structures, APIs.*
* **SQL for Data Science**: UC Davis (Coursera) — *Multi-table joins, subqueries, aggregations, window functions.*
