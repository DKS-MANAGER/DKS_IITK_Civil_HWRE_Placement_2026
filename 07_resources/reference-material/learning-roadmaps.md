# 🗓️ Learning Roadmaps

> **7-day, 30-day, 3-month, and 6-month plans, plus branch-specific plans.**
> **Customize based on: current skill → target role → available time → expected ROI.**

---

## How to Use This Page

1. Determine your available time
2. Find your target role/branch
3. Follow the plan
4. Adjust based on your current skill level

## 7-Day Roadmap (Urgent — Interview Soon)

### For Any Role

```
Day 1:  Identify your ONE primary tool (see anti-overload)
Day 2:  Learn the basics (interface, core workflow)
Day 3:  Complete one tutorial project
Day 4:  Prepare 5 interview Q&As for your tool
Day 5:  Practice explaining your project workflow
Day 6:  Review resume bullets, ensure honesty
Day 7:  Mock interview + revision
```

### HWRE Student — 7 Days

```
Day 1:  HEC-RAS basics (tutorial)
Day 2:  HEC-RAS steady flow project
Day 3:  HEC-RAS unsteady flow
Day 4:  GIS flood mapping basics
Day 5:  Prepare HEC-RAS interview Q&As
Day 6:  Resume bullet + project explanation
Day 7:  Mock interview
```

### Data Analyst — 7 Days

```
Day 1:  SQL basics (SELECT, WHERE, GROUP BY)
Day 2:  SQL joins + practice
Day 3:  Python Pandas basics
Day 4:  Python data cleaning
Day 5:  Statistics basics (hypothesis testing)
Day 6:  Prepare interview Q&As
Day 7:  Mock interview
```

## Customization Guide

```
Adjust the plan based on:

1. Current Skill
    - Beginner: follow the plan as-is
    - Intermediate: skip basics, focus on domain tools
    - Advanced: focus on projects + interview prep

2. Target Role
    - Core Civil: prioritize domain tools
    - Non-Core: prioritize Excel, SQL, Python
    - Research: prioritize Python, Linux, Git, LaTeX

3. Available Time
    - 7 days: ONE tool + interview prep
    - 30 days: 2-3 tools + project
    - 3 months: full stack + project
    - 6 months: full stack + 2 projects

4. Expected ROI
    - Prioritize [MUST LEARN] and [HIGH ROI] tools
    - Skip [OPTIONAL] and [SPECIALIZED] unless role requires
```
