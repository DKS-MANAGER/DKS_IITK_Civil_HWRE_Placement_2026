# 🔬 Tool Deep-Dives

> **Purpose:** Hands-on, step-by-step walkthroughs for the most important Civil engineering software tools.
> **How to use:** Pick the tool relevant to your specialization, follow the steps in order, and build a real model end-to-end. Each guide ends with interview questions you can answer after completing it.

These deep-dives complement the [branch tech roadmaps](../README.md) — the roadmaps tell you **which** tools to learn, and these guides tell you **how** to use them.

## 📈 Recommended Learning Order

If you're unsure where to start, follow this order (most broadly useful first):

1. **HEC-RAS** — the single most important tool for HWRE students
2. **HEC-HMS** — pairs with HEC-RAS for flood studies
3. **SWMM** — essential for urban drainage roles
4. **EPANET** — essential for water supply roles
5. **PLAXIS 2D** — the standard geotechnical FEM tool
6. **SLOPE/W** — the standard slope stability tool
7. **OpenFOAM** — for CFD/research/M.Tech paths

## 📐 Common Structure

Every deep-dive follows the same structure so you can navigate them consistently:

1. **What You Will Build** — the end goal
2. **Before You Start** — installation + data needed
3. **Step-by-step walkthrough** — each step explains *what*, *why*, and *how to check*
4. **Troubleshooting** — common errors and fixes
5. **Interview Questions** — what you can now answer
6. **Self-Checklist** — verify you completed everything
7. **Related Resources** — cross-links
