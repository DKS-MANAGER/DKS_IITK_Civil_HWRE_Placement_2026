# 💻 Technology / Tech-Adjacent Careers for Civil Students

> **Target:** Civil students moving toward tech roles
> **Defines realistic tracks and honest expectations. Do NOT promise software-engineering placement from minimal programming knowledge.**

---

## ⚠️ Honest Reality Check

> **A Civil student with a few months of Python is NOT a software engineer.**
> Software engineering requires deep CS fundamentals (data structures, algorithms, systems design) that take years to build.

**Realistic tech-adjacent roles for Civil students:**
- Data Analyst
- Business Analyst
- Product Analyst
- Technical Product Manager
- Analytics / BI roles
- Technical Consulting
- GIS / Geospatial roles
- Simulation / CFD roles (leverages Civil background)

**Unrealistic without significant CS training:**
- Software Engineer (FAANG)
- Backend/Frontend Developer
- Machine Learning Engineer (without strong math + CS)

## Career Tracks

### Track 1: Data Analyst

```
Excel → SQL → Python → Statistics → BI
```

| Step | Skill | Level | Time |
|:-----|:------|:------|:-----|
| 1 | Excel (pivot, lookup, charts) | L3 | 2 weeks |
| 2 | SQL (joins, aggregates, window functions) | L3 | 3 weeks |
| 3 | Python (Pandas, NumPy, Matplotlib) | L2–L3 | 4 weeks |
| 4 | Statistics (hypothesis testing, regression) | L2–L3 | 3 weeks |
| 5 | Power BI (dashboards) | L2 | 2 weeks |
| 6 | Portfolio project | L3 | 2 weeks |

**Total: ~16 weeks (4 months)**

### Track 2: Business Analyst

```
Excel → SQL → Analytics → Business Problem Solving
```

| Step | Skill | Level | Time |
|:-----|:------|:------|:-----|
| 1 | Excel (advanced modelling) | L3 | 2 weeks |
| 2 | SQL (querying) | L2–L3 | 3 weeks |
| 3 | Business fundamentals (metrics, finance) | L2 | 2 weeks |
| 4 | Case studies / guesstimates | L2 | 3 weeks |
| 5 | Power BI (reporting) | L2 | 2 weeks |

**Total: ~12 weeks (3 months)**

### Track 3: Product Analyst

```
SQL → Analytics → Statistics → Experimentation
```

| Step | Skill | Level | Time |
|:-----|:------|:------|:-----|
| 1 | SQL (advanced) | L3 | 3 weeks |
| 2 | Product analytics (funnels, cohorts) | L2–L3 | 3 weeks |
| 3 | Statistics (A/B testing) | L2–L3 | 3 weeks |
| 4 | Python (analysis) | L2 | 3 weeks |
| 5 | Product sense (frameworks) | L2 | 2 weeks |

**Total: ~14 weeks (3.5 months)**

### Track 4: Technical PM

```
Business → Product → Technical Fundamentals → Analytics
```

| Step | Skill | Level | Time |
|:-----|:------|:------|:-----|
| 1 | Business fundamentals | L2 | 2 weeks |
| 2 | Product management frameworks | L2 | 3 weeks |
| 3 | Technical fundamentals (APIs, databases, cloud) | L1–L2 | 3 weeks |
| 4 | SQL + analytics | L2 | 3 weeks |
| 5 | Product sense + case interviews | L2 | 3 weeks |

**Total: ~14 weeks (3.5 months)**

### Track 5: Software-Adjacent (Simulation/CFD/GIS)

```
Python → Git → Linux → APIs → Databases → Projects
```

| Step | Skill | Level | Time |
|:-----|:------|:------|:-----|
| 1 | Python (advanced) | L3 | 4 weeks |
| 2 | Git + GitHub | L2–L3 | 1 week |
| 3 | Linux + Bash | L2 | 2 weeks |
| 4 | Domain tool (OpenFOAM/GIS) | L2–L3 | 4 weeks |
| 5 | Portfolio project | L3 | 3 weeks |

**Total: ~14 weeks (3.5 months)**

## How to Choose a Track

```
Ask yourself:

1. Do I enjoy working with data and numbers?
    → Yes: DA or PA track
    → No: BA or Tech-PM track

2. Do I enjoy business strategy and problem solving?
    → Yes: BA or Tech-PM track
    → No: DA or PA track

3. Do I want to leverage my Civil/engineering background?
    → Yes: SW-Adjacent (CFD/GIS) track
    → No: General DA/BA track

4. How much time do I have before placement?
    → < 3 months: BA or DA (fastest)
    → 3-6 months: Any track
    → > 6 months: SW-Adjacent (deepest)
```

## Interview Questions

### Data Analyst
- Walk me through your data analysis project.
- How do you handle missing data?
- Explain a time you found an insight from data.

### Business Analyst
- How do you approach a business problem?
- Walk me through a guesstimate.
- How do you prioritize requirements?

### Product Analyst
- How do you measure the success of a feature?
- Design an A/B test for a product change.
- Your retention dropped. How do you investigate?

### Technical PM
- How do you communicate with engineers?
- Explain a technical concept to a non-technical stakeholder.
- How do you prioritize features?
