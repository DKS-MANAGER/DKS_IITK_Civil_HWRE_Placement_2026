> **For every tool: does it have Study, Examples, Practice, Project, Test, Interview, Revision?**
> Target: **≥8/10** for P0 tools. Score = number of ✅ out of 10 components.

---

## Scoring Legend

| Component | Meaning |
|:----------|:--------|
| **Study** | Actual study material (concepts, syntax, workflow) |
| **Examples** | Worked examples with explanation |
| **Practice** | Concrete exercises (basic/intermediate/role-specific) |
| **Project** | Mini-project with objective → input → workflow → output |
| **Test** | Quiz / workflow test / troubleshooting test |
| **Interview** | Interview questions with concept tested + strong answers |
| **Revision** | Rapid revision / quick reference |
| **Theory Link** | Links to engineering fundamentals |
| **Company Link** | Links to companies that require it |
| **Resume** | Resume bullet guidance |
