# 🗺️ Branch-Wise Golden Stack

> **For each Civil branch: Minimum placement stack → Strong stack → Advanced/research stack**

---

## How to Use This Page

1. Find your branch below
2. Identify your current level (Minimum / Strong / Advanced)
3. Check what you're missing
4. Use [`learning-roadmaps.md`](learning-roadmaps.md) to plan your study

---

## HWRE / Water Resources

### Minimum (Placement-Ready)

```
HEC-RAS + Excel + GIS (QGIS)
```

| Tool | Level | Time |
|:-----|:------|:-----|
| HEC-RAS | L2–L3 | 20–40 hrs |
| Excel | L3 | 15–20 hrs |
| QGIS | L2 | 15–20 hrs |

### Strong

```
HEC-RAS + EPANET + Python + GIS
```

| Tool | Level | Time |
|:-----|:------|:-----|
| HEC-RAS | L3 | 30–40 hrs |
| EPANET | L2–L3 | 15–25 hrs |
| Python | L2–L3 | 30–50 hrs |
| GIS | L2 | 15–20 hrs |

### Advanced / Research

```
OpenFOAM + Python + Linux + HPC + ParaView
```

| Tool | Level | Time |
|:-----|:------|:-----|
| OpenFOAM | L3–L4 | 60–100 hrs |
| Python | L3 | 40–60 hrs |
| Linux | L2 | 10–15 hrs |
| HPC/SLURM | L2 | 10–15 hrs |
| ParaView | L2–L3 | 15–25 hrs |
