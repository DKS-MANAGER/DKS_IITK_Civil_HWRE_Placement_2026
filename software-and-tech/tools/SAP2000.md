## 1. What It Is

SAP2000 is a **general-purpose structural finite element analysis (FEA)** software by CSI. Unlike ETABS (buildings only), SAP2000 handles **any structure** — bridges, towers, industrial structures, and complex geometries.

## 2. Where It Is Used

| Application | Context |
|:------------|:--------|
| Bridge analysis | Superstructure, substructure |
| General FEA | Complex geometries, shells, solids |
| Dynamic analysis | Modal, response spectrum, time-history |
| Industrial structures | Equipment supports, pipe racks |
| Nonlinear analysis | Pushover, material nonlinearity |
| Geotech interaction | Soil-structure interaction |

## 7. Typical Engineering Workflow

```
Step 1: Define materials + sections
Step 2: Draw geometry (frames, shells)
Step 3: Assign supports
Step 4: Apply loads + combinations
Step 5: Run analysis (static/dynamic)
Step 6: Check results (forces, drift, reactions)
Step 7: Design members
Step 8: Review ratios, iterate
```

## 8. Worked Example — Bridge Girder Analysis

**Task:** Analyze a simply supported bridge girder (20m span) under UDL.

```
1. Grid: 20m span, 1m spacing
2. Material: M40 concrete
3. Section: Box girder (or I-girder)
4. Supports: Pinned left, roller right
5. Loads: Self-weight + UDL 50 kN/m (traffic)
6. Analysis: Static
7. Check: Max moment (wL²/8 = 50×400/8 = 2500 kN·m), deflection
8. Design: Concrete design per IS 456
```

**Output:** BMD, SFD, deflection, design ratio.

## 11. Common Mistakes

| Mistake | Why It's Wrong | Correct Approach |
|:--------|:---------------|:-----------------|
| Wrong element type | Incorrect results | Use shell for walls, frame for beams |
| No mesh refinement | Inaccurate stress | Refine mesh near stress concentrations |
| Ignoring P-delta | Slender structures under-designed | Enable P-delta |
| Wrong supports | Unstable model | Define correctly |
| No dynamic check | Miss resonance | Run modal analysis |
