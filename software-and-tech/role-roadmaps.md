# 🎯 Role-Wise Golden Stack

> **For every job role: required technology → optional technology → learning order → expected proficiency → portfolio project**

---

## How to Use This Page

1. Find your target role
2. Identify required vs optional technology
3. Follow the learning order
4. Build the portfolio project
5. Prepare interview questions
