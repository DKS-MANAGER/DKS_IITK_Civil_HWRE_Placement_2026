# 🗺️ SOFTWARE_ROADMAP.md — Learning Roadmap by Timeline

> **How to go from zero to interview-ready in the time you have.**
> Combines the [priority system](priority-system.md), [role matrix](SOFTWARE_ROADMAP.md), and [tool index](TOOLS_INDEX.md).

---

## The Core Principle

```
ROLE → REQUIRED TOOLS → WHAT TO LEARN → STUDY → PRACTICE → PROJECT → TEST → INTERVIEW
```

**Never learn a tool "because it exists."** Learn it because your target role requires it (see [`SOFTWARE_ROLE_MATRIX.md`](SOFTWARE_ROLE_MATRIX.md)).

---

## Universal Foundation (Every Civil Student)

These 3 tools cover **all** HIGH/MEDIUM companies:

| Tool | Why | Level | Source |
|:-----|:----|:-----:|:-------|
| **Excel** | Universal — BOQ, calculations, data | L3 | [`tools/Excel.md`](tools/Excel.md) |
| **AutoCAD** | Universal — drawings, detailing | L2–L3 | [`tools/AutoCAD.md`](tools/AutoCAD.md) |
| **One domain tool** | Your specialization's P0 tool | L3 | See role matrix |

> **Key insight from company data:** `AutoCAD + one analysis software (ETABS/STAAD) + Excel` covers all HIGH/MEDIUM companies. Add Primavera for PM-track companies. — [`civil-cross-company-strategy.md`](../prep/company-profiles/civil-cross-company-strategy.md)

## Timeline Roadmaps

### 7-Day Emergency (Interview in 1 week)

| Day | Focus | Tool | Deliverable |
|:---:|:------|:-----|:------------|
| 1 | Your P0 domain tool — basics | e.g., HEC-RAS / ETABS | Complete one tutorial |
| 2 | Your P0 domain tool — workflow | Same | Build one small model |
| 3 | Excel — BOQ/calculations | Excel | Build a calculation sheet |
| 4 | AutoCAD — drawing reading | AutoCAD | Read/interpret a drawing |
| 5 | Interview questions | [`software-interview-questions.md`](software-interview-questions.md) | 5 Q&As per tool |
| 6 | Resume + project story | [`resume-positioning.md`](resume-positioning.md) | 3 resume bullets |
| 7 | Mock interview | [`prep/interview/`](../prep/interview/) | Full mock |

### 30-Day (Standard placement prep)

| Week | Focus | Tools | Deliverable |
|:----:|:------|:------|:------------|
| 1 | P0 tool #1 — fundamentals | Domain tool | Complete deep-dive |
| 2 | P0 tool #1 — project | Domain tool | Mini-project done |
| 3 | P0 tool #2 + Excel | Excel + 2nd tool | BOQ + 2nd tool basics |
| 4 | Interview + resume + revision | All | 10 Q&As, resume, revision sheet |

### 90-Day (Deep preparation)

| Month | Focus | Tools | Deliverable |
|:-----:|:------|:------|:------------|
| 1 | P0 tools — L2 | Domain tool + Excel | Both at L2 |
| 2 | P0 tools — L3 + project | Domain tool | Full project at L3 |
| 3 | P1 tools + interview | P1 tools + Python | Portfolio + mock interviews |

## Role-Specific Roadmaps

### Structural Engineer (30-day)

```
Week 1: AutoCAD (L2) → draw a beam-column detail
Week 2: STAAD.Pro (L2) → model a portal frame
Week 3: ETABS (L2) → model a G+3 building
Week 4: Excel (L3) → design calc sheet + interview prep
Project: Multi-story building design (ETABS + AutoCAD + Excel)
```

### Water Resources Engineer (30-day)

```
Week 1: HEC-RAS (L2) → complete deep-dive walkthrough
Week 2: HEC-RAS (L3) → real river reach + flood map
Week 3: HEC-HMS (L2) → watershed model
Week 4: QGIS (L2) + Python (L2) + interview prep
Project: Flood modeling (HEC-RAS + GIS)
```

### CFD Engineer (90-day)

```
Month 1: Linux + Python (L2) + OpenFOAM basics
Month 2: OpenFOAM (L3) + ParaView + mesh independence
Month 3: Custom CFD project + validation + portfolio
Project: CFD simulation with validation
```

### Data Analyst (45-day)

```
Weeks 1-2: Python + Pandas (L3)
Weeks 3-4: SQL (L3) + practice
Weeks 5-6: Excel (L3) + statistics
Week 7: Power BI (L2) + project
Week 8: Resume + interview prep
```

### Project Engineer (30-day)

```
Week 1: Excel (L3) → BOQ + rate analysis
Week 2: AutoCAD (L2) → drawing reading
Week 3: MS Project / Primavera (L2) → schedule
Week 4: Power BI (L2) + interview prep
Project: Project tracking dashboard (Power BI)
```

## Proficiency Level Targets

| Level | Meaning | When to Stop |
|:-----:|:--------|:-------------|
| **L1** | Know what it does | Tool is `[OPTIONAL]` |
| **L2** | Can do standard workflows | Tool is `[ROLE DEPENDENT]` |
| **L3** | Can complete a realistic project | Tool is `[MUST LEARN]` / `[HIGH ROI]` |
| **L4** | Can handle complex/automation | Only for specialized roles (CFD, R&D) |

> ⚠️ **Only list a tool on your resume at L3+.** See [`resume-positioning.md`](resume-positioning.md).

## Anti-Patterns

| ❌ Don't | ✅ Do |
|:---------|:------|
| Learn 15 tools at L1 | Master 4–6 tools at L3 |
| Spend 3 months on OpenFOAM for a PM role | Spend 3 months on Excel + SQL |
| Skip Excel because "I know it" | Excel is universal — reach L3 |
| Learn every CAD package | Master AutoCAD, know Civil 3D exists |
| Skip Git for tech roles | Git is a differentiator |
