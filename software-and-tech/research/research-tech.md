## Research Skill → Contribution

### Python

```
Data analysis      → Process experimental/field/simulation data
Numerical methods  → Implement FDM/FVM/FEM algorithms
Visualization      → Publication-quality plots
Automation         → Batch processing, parameter sweeps
Machine learning   → Surrogate models, classification
Documentation      → Jupyter notebooks for reproducibility
```

### MATLAB

```
Matrix operations  → FEM assembly, linear algebra
ODE/PDE solving    → Numerical methods for physics
Optimization       → Parameter fitting, design optimization
Signal processing  → Time-series analysis
Simulink           → Dynamic system modelling
```

### LaTeX

```
Thesis writing     → Structured document with math
Paper writing      → Journal/conference formatting
Formula sheets     → Quick reference documents
Presentations      → Beamer slides
Bibliography       → BibTeX for references
```

### Git

```
Code versioning    → Track every change to your code
Reproducibility    → Others can reproduce your work
Portfolio          → Showcase research to future employers
Collaboration      → Work with advisor/peers
Backup             → Never lose code
```

### Linux

```
HPC access         → Connect to university clusters
OpenFOAM           → CFD on Linux
Shell scripting    → Automate repetitive tasks
File management    → Organize large datasets
Remote computing   → SSH for server access
```

## Reproducible Research Checklist

```
☐ Code is in a Git repository with clear README
☐ Data is stored separately and documented
☐ Environment is specified (requirements.txt or conda.yml)
☐ Results can be regenerated from code + data
☐ Figures are generated from code (not manually edited)
☐ Key parameters are documented and versioned
☐ Analysis workflow is documented in Jupyter notebook
☐ Raw data is preserved alongside processed data
```

## Interview Questions for Research Candidates

### General Research

- Walk me through your thesis project.
- What was the most challenging part of your research?
- How did you validate your methodology?
- What software did you use and why?
- How do you ensure reproducibility?

### Technical

- Explain the numerical method you used.
- How did you handle convergence issues?
- What validation data did you use?
- How did you quantify uncertainty?

### Industry Connection

- How does your research apply to industry?
- What transferable skills did you develop?
- How would you approach a similar problem in an industry setting?
