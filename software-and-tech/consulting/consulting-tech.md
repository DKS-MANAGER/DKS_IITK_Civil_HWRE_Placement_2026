# 📈 Consulting / Strategy Technology

> **Target:** Consulting, Strategy, Technical Consulting roles
> **Do NOT learn dozens of technical tools. Prioritize structured analysis + quantitative reasoning + communication.**

---

## The Consulting Technology Principle

> **The key technology for consulting is not coding volume; it is structured analysis + quantitative reasoning + communication.**

Consulting candidates should focus on a **minimal, high-impact stack**:

```
Excel → PowerPoint → (Power BI/Tableau) → (SQL) → (Python if role requires)
```

---

## Priority Stack

| Tool | Tag | Level | Purpose |
|:-----|:----|:------|:--------|
| Excel | `[MUST LEARN]` | L3 | Financial modelling, data analysis |
| PowerPoint | `[MUST LEARN]` | L3 | Executive presentations, storytelling |
| Power BI / Tableau | `[ROLE DEPENDENT]` | L1–L2 | Dashboards (analytics-heavy roles) |
| SQL | `[ROLE DEPENDENT]` | L2 | Analytics-heavy consulting roles |
| Python | `[ROLE DEPENDENT]` | L1–L2 | Only if role requires it |

## Excel for Consulting

### Core Skills

```
1. Financial modelling (income statement, balance sheet, cash flow)
2. Sensitivity analysis (data tables, scenario manager)
3. What-if analysis (Goal Seek, Solver)
4. Advanced formulas (INDEX/MATCH, nested IF, SUMPRODUCT)
5. Pivot tables for data analysis
6. Charts for executive communication
7. Data cleaning and organization
8. Break-even analysis
9. Valuation basics (DCF, multiples)
10. Market sizing in Excel
```

### Excel Modelling Workflow

```
Step 1: Structure — Define assumptions clearly
Step 2: Build — Create linked formulas (no hardcoding)
Step 3: Test — Check for errors, consistency
Step 4: Analyze — Sensitivity, scenarios
Step 5: Present — Clear charts, executive summary
```

## PowerPoint for Consulting

### Slide Structure

```
1. Executive Summary (answer first)
2. Problem Statement
3. Analysis / Findings
4. Recommendations
5. Next Steps / Appendix
```

### Chart Selection

| Message | Chart Type |
|:--------|:-----------|
| Comparison | Bar chart |
| Trend over time | Line chart |
| Part of a whole | Pie / donut |
| Relationship | Scatter plot |
| Distribution | Histogram |
| Ranking | Horizontal bar |

### Executive Communication

```
- One idea per slide
- Answer first (bottom-line up front)
- Use the Pyramid Principle
- Quantify everything
- Visual > text
- 30-second rule: can you explain the slide in 30 seconds?
```

### Data Storytelling

```
1. Context — What's the situation?
2. Insight — What did you find?
3. Implication — Why does it matter?
4. Action — What should be done?
```

## When to Learn SQL/Python

```
Learn SQL IF:
    ✓ You're targeting analytics-heavy consulting (e.g., strategy + data)
    ✓ You want to query client data independently
    ✓ The role involves data-driven recommendations

Learn Python IF:
    ✓ The role explicitly requires it
    ✓ You're targeting technical consulting
    ✓ You want to automate analysis

Skip SQL/Python IF:
    ✗ You're targeting generalist strategy consulting
    ✗ You have limited time before placement
    ✗ Excel covers your analysis needs
```

## Interview Questions

### Excel
- Build a break-even model for a product.
- How do you perform a sensitivity analysis?
- What is the difference between NPV and IRR?

### PowerPoint
- How do you structure a consulting presentation?
- How do you choose the right chart for your data?
- Explain the Pyramid Principle.

### General
- How do you approach a market sizing problem?
- Walk me through a financial model you've built.
- How do you present complex data to executives?
