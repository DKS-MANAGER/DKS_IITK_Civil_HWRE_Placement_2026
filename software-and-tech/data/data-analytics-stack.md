# 📊 Data / Analytics Stack for Civil Students

> **Target:** Data Analyst, Business Analyst, Product Analyst, Analytics, Consulting, Operations roles
> **Core stack: Excel → SQL → Python → BI → Statistics**

---

## The Stack

```
Excel → SQL → Python → BI (Power BI/Tableau) → Statistics
```

| Layer | Tool | Tag | Level | Purpose |
|:------|:-----|:----|:------|:--------|
| 1 | Excel | `[MUST LEARN]` | L3 | Data manipulation, quick analysis |
| 2 | SQL | `[MUST LEARN]` | L3 | Querying databases |
| 3 | Python | `[MUST LEARN]` | L2–L3 | Advanced analysis, automation |
| 4 | Power BI / Tableau | `[HIGH ROI]` | L2 | Dashboards, visualization |
| 5 | Statistics | `[MUST LEARN]` | L2–L3 | Hypothesis testing, regression |

---

## Excel

### Core Skills (L2)

```
1. Formulas: SUM, AVERAGE, COUNT, IF, SUMIF, COUNTIF
2. Lookup: VLOOKUP, HLOOKUP, INDEX, MATCH, XLOOKUP
3. Pivot tables: create, filter, group, calculated fields
4. Charts: bar, line, pie, combo, scatter
5. Data cleaning: TRIM, CLEAN, TEXT, CONCATENATE
6. Conditional formatting
7. Sorting and filtering
8. Data validation
```

### Advanced (L3)

```
9. Power Query: data import, transformation, merging
10. Power Pivot: data modeling, DAX basics
11. Macros / VBA basics (automation)
12. Array formulas
13. What-if analysis (Goal Seek, Solver, Data Tables)
14. Advanced charts (waterfall, Pareto, sparklines)
```

### Excel Interview Questions

- What is the difference between VLOOKUP and INDEX/MATCH?
- How do you create a pivot table? When would you use one?
- Explain the difference between a formula and a function.
- How do you handle errors like #N/A and #DIV/0!?

## SQL

### Core Skills (L2)

```
1. SELECT, FROM, WHERE
2. ORDER BY, LIMIT
3. Aggregates: COUNT, SUM, AVG, MIN, MAX
4. GROUP BY, HAVING
5. JOINs: INNER, LEFT, RIGHT
6. Subqueries
7. CASE WHEN
8. Date functions
```

### Advanced (L3)

```
9. Window functions: ROW_NUMBER, RANK, LAG, LEAD
10. CTEs (WITH ... AS)
11. Complex JOINs, self-joins
12. UNION, INTERSECT, EXCEPT
13. Query optimization basics
```

### SQL Interview Questions

- Write a query to find the top 3 products by revenue.
- How do you calculate a running total?
- What is the difference between WHERE and HAVING?
- Explain window functions with an example.

---

## Python

### Core Skills (L2)

```
1. Pandas: DataFrame, read_csv, groupby, merge, pivot
2. NumPy: arrays, operations, statistics
3. Matplotlib: line, bar, scatter, histogram
4. Data cleaning: missing values, duplicates, outliers
5. Basic statistics: mean, median, std, percentiles
6. File I/O: CSV, Excel, JSON
```

### Advanced (L3)

```
7. Scikit-learn: regression, classification, clustering
8. Statsmodels: hypothesis testing, regression
9. Seaborn: advanced visualization
10. Jupyter Notebooks for analysis
11. Data pipelines (ETL basics)
```

### Python Interview Questions

- How do you handle missing values in a DataFrame?
- Explain the difference between `.loc` and `.iloc`.
- How do you merge two DataFrames?
- Write code to compute the mean and standard deviation of a column.

## BI (Power BI / Tableau)

### Power BI

```
1. Data import (Excel, SQL, CSV)
2. Data modeling (relationships)
3. DAX basics (CALCULATE, SUMX, FILTER)
4. Visualizations (bar, line, map, matrix)
5. Dashboards and reports
6. Power Query for data transformation
```

### Tableau

```
1. Data connection
2. Worksheets and dashboards
3. Calculated fields
4. Table calculations
5. Filters and parameters
```

### BI Interview Questions

- What is the difference between Power BI and Tableau?
- How do you create a calculated measure in DAX?
- Explain the difference between a report and a dashboard.

## Statistics

### Core Concepts (L2)

```
1. Descriptive statistics: mean, median, mode, variance, std
2. Probability: conditional, Bayes theorem
3. Distributions: normal, binomial, Poisson
4. Central Limit Theorem
5. Confidence intervals
6. Hypothesis testing: null/alternative, p-value, Type I/II errors
7. Correlation and regression
8. A/B testing basics
```

### Advanced (L3)

```
9. Multiple regression
10. ANOVA
11. Time series basics
12. Logistic regression
13. Feature selection
```

### Statistics Interview Questions

- What is the difference between Type I and Type II errors?
- Explain the Central Limit Theorem.
- How do you interpret a p-value?
- What is the difference between correlation and causation?
- How would you design an A/B test?

## Example Project: Infrastructure Analytics Dashboard

```
Project: Construction Project Performance Dashboard
Objective: Analyze 100+ construction projects for delays and cost overruns
Tools: SQL + Python + Power BI
Workflow:
    1. SQL: Query project database for schedule/cost data
    2. Python: Clean data, compute KPIs (SPI, CPI, delay)
    3. Power BI: Build interactive dashboard
    4. Insights: Identify top risk factors
Expected Output: Interactive dashboard + insights report
Resume value: High
```
