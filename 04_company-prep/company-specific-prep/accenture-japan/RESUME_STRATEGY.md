# Resume Strategy — Engineering to Digital Consultant Resume Positioning

> **Document Focus**: Tailoring IIT engineering resumes for Accenture Japan Digital Consultant selection.  
> **Rule**: Reframing genuine technical and analytical achievements into business-impact language without inventing fake experience.

---

## 1. Resume Architecture for Digital Consulting

Accenture Japan HR screeners look for 4 primary signals:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       RESUME SELECTION SIGNALS                              │
├──────────────────────────┬──────────────────────────┬───────────────────────┤
│ 1. Quantitative Problem  │ 2. Technology & Systems  │ 3. Measurable Value   │
│    Solving (IIT Core)    │    (Python/SQL/Cloud)    │    & Data Impact      │
├──────────────────────────┴──────────────────────────┴───────────────────────┤
│ 4. Leadership, Teamwork & Cross-Cultural Adaptability                       │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## 2. Reframing Engineering Projects into Digital Consultant Terminology

Do **NOT** invent consulting experience. Instead, translate technical project bullet points into **Action + Technology + Business/Analytical Outcome**:

### Example 1: Computational / Simulation Project
* **Weak / Pure Academic Bullet**:  
  *"Wrote Python script to run hydraulic flow simulations on a cluster."*
* **Strong Digital Consultant Bullet**:  
  *"Architected automated Python simulation pipeline to model fluid dynamics; reduced computation latency by 45% and enabled real-time parameter sensitivity analysis across 10,000+ data points."*

### Example 2: Data Analytics / Machine Learning Lab
* **Weak Bullet**:  
  *"Built a linear regression model to predict water quality metrics."*
* **Strong Digital Consultant Bullet**:  
  *"Engineered predictive analytics model evaluating water quality indicators; achieved 92% prediction accuracy and presented automated reporting dashboard to project stakeholders."*

### Example 3: Software / Web / Automation Project
* **Weak Bullet**:  
  *"Designed website for college festival using React and Node.js."*
* **Strong Digital Consultant Bullet**:  
  *"Developed responsive web platform for 15,000+ users during annual tech festival; optimized API response times by 30% and managed cloud database under peak traffic loads."*

---

## 3. Recommended Resume Section Order

1. **Header & Contact**: IIT Email, Phone, LinkedIn, GitHub.
2. **Education**: Degree, IIT Name, CPI/CGPA, Expected Graduation: June 2027 (`[JD VERIFIED]`).
3. **Technical & Analytical Skills**:
   * *Languages*: Python, SQL, C++, R, Bash.
   * *Technologies & Tools*: Cloud (AWS/Azure basics), Git, Docker, Tableau/PowerBI, MS Excel.
   * *Domains*: Data Analytics, Machine Learning, Enterprise Systems, Digital Transformation.
4. **Key Projects & Research**: 3–4 bullet points per project demonstrating quantitative outcomes.
5. **Leadership & Extracurricular Achievements**: Position of Responsibility (PoR), Fest Head, Sports, Volunteering (cross-cultural/teamwork proof).

---

## 4. Master Resume Checklist for Accenture Japan

- [ ] Education explicitly states graduation by June 2027 and zero full-time post-bachelor experience (`[JD VERIFIED]`).
- [ ] Language skills state Native/Fluent English (`[JD VERIFIED]`).
- [ ] Every project bullet starts with a strong action verb (Architected, Engineered, Optimized, Automated, Diagnosed).
- [ ] Every project includes a quantified metric (% efficiency gained, speedup factor, accuracy %, user volume).
- [ ] Resume fits cleanly on 1 page (IIT standard format).
