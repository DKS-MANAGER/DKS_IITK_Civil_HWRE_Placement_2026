## 4. Pre-Interview Exit Gate Verification Checklist

Before walking into the technical interview room, ensure 100% completion of the following 10 checkpoints:
- [ ] **CHK-01**: Can write a 5-line SQL query using `DENSE_RANK() OVER (PARTITION BY territory ORDER BY trx DESC)` on a blank whiteboard.
- [ ] **CHK-02**: Can derive the geometric adstock half-life formula: $t_{1/2} = -\ln(2)/\ln(\lambda)$.
- [ ] **CHK-03**: Can explain why Average ROI and Marginal ROI differ, and state the condition for optimal marketing budget allocation ($\text{mROI}_1 = \text{mROI}_2$).
- [ ] **CHK-04**: Can explain the difference between a SAS `WHERE` statement and a subsetting `IF` statement.
- [ ] **CHK-05**: Can explain why Deep Learning is generally unsuitable for Marketing Mix Modeling on $N=104$ weekly data points.
- [ ] **CHK-06**: Can define Proportion of Days Covered (PDC) and state the $80\%$ threshold for patient adherence.
- [ ] **CHK-07**: Can calculate the Variance Inflation Factor (VIF) and explain why multicollinearity destabilizes channel coefficients.
- [ ] **CHK-08**: Can deliver the 3-minute executive pivot narrative connecting engineering modeling to healthcare commercial analytics with confidence.
- [ ] **CHK-09**: Can defend handling class imbalance using PR-AUC and `scale_pos_weight` in XGBoost.
- [ ] **CHK-10**: Can articulate alignment with IQVIA's corporate values and global delivery hours supporting US/European brand managers.
