## 1. Quantitative Foundations & Theoretical Framework

Percentages form the absolute bedrock of commercial quantitative problem solving. In elite recruitment assessments (Goldman Sachs, McKinsey, WorldQuant, Google PM), testing moves beyond simple fraction conversions into **successive multiplicative compounding**, **the product constancy rule**, **multidimensional geometric scaling**, **tax slab bracket modeling**, and **weighted index elasticity**.

### 1.1 The Multiplier Method & Base Identification

Always compute percentage changes via decimal multipliers rather than multi-step additions:

$$\text{Final Value} = \text{Original Value} \times \left(1 \pm \frac{x}{100}\right)$$

$$\text{Percentage Change (\%)} = \frac{\text{New} - \text{Old}}{\text{Old}} \times 100\%$$

### 1.2 The Product Constancy Rule ($A \times B = \text{Constant}$)

If the product of two variables remains invariant ($P \times C = E$), an increase in one variable forces a non-linear percentage reduction in the second variable:

$$\text{If } A \text{ increases by } \frac{x}{100} = \frac{1}{n}, \quad B \text{ must decrease by } \frac{x}{100 + x} = \frac{1}{n + 1}$$

$$\text{Example: Price } \uparrow 25\% \left(\frac{1}{4}\right) \implies \text{Consumption } \downarrow \frac{1}{4+1} = \frac{1}{5} = 20\%$$

### 1.3 Successive Compounding Theorem

For two successive changes of $a\%$ and $b\%$ on a single base:

$$\text{Net Percentage Change} = a + b + \frac{a \cdot b}{100}$$

For three successive percentage changes $a\%$, $b\%$, and $c\%$, use multiplicative factors:

$$\text{Net Multiplier} = \left(1 + \frac{a}{100}\right) \left(1 + \frac{b}{100}\right) \left(1 + \frac{c}{100}\right)$$

## 5. Rapid Revision & Strategic Traps

### 5.1 The 8 Deadliest Placement Traps in Percentages

| Trap Name | Why Candidates Stumble | Mathematical Reality | Placement Antidote |
|:---|:---|:---|:---|
| **The Base Inversion Fallacy** | Assuming that if A is $x\%$ greater than B, B is $x\%$ less than A | The denominator shifts from B to A: $(1 + x) > 1$, making the reverse percentage smaller | Always calculate: Percentage Less $= [x / (100 + x)] \times 100\%$ |
| **The Additive Compounding Trap** | Adding successive percentage changes directly ($20\% + 15\% = 35\%$) | The second percentage applies to the inflated intermediate base | Use $a + b + (ab/100)$ or decimal multipliers: $1.20 \times 1.15 = 1.38 \implies +38\%$ |
| **Percentage vs Percentage Point** | Conflating absolute percentage point shifts with relative percentage change | Increasing from $20\%$ to $25\%$ is $+5$ percentage points, but a $+25\%$ relative jump | Relative Change $= (\Delta P / P_{\text{initial}}) \times 100\% = (5 / 20) \times 100\% = 25\%$ |
| **The Invalid Vote Base Error** | Applying candidate voting percentages to total polled votes | Candidate shares apply strictly to **valid votes**; invalid votes must be subtracted first | $\text{Valid Votes} = \text{Total Polled} \times (1 - \text{Invalid Fraction})$ |
| **The Geometric 3D Scaling Fallacy** | Assuming linear dimension shifts offset identically in volume | Volume is cubic ($V \propto r^2 h$); radius squared dominates height changes | If $r \uparrow 20\%$ and $h \downarrow 20\%$, $V_{\text{new}} = (1.2)^2 \times 0.8 = 1.152 \implies +15.2\%$ |
| **The Scrap Rate Cascade Error** | Subtracting scrap percentages additively across sequential factory stages | Each production stage loses a percentage of the *surviving input* from the previous stage | Net Yield $= (1 - s_1)(1 - s_2)(1 - s_3)$ |
| **The Marginal Tax Slab Discontinuity** | Applying a higher tax rate to the entire income upon crossing a threshold | Higher marginal tax rates apply strictly to the income *above* the bracket threshold | Compute tax piecewise: $\text{Tax} = \sum r_i \times (\text{Income}_i - \text{Threshold}_i)$ |
| **The Reversible Markdown Illusion** | Assuming a $50\%$ markdown can be restored by a $50\%$ markup | Discounting by $50\%$ halves the value; restoring it requires a $+100\%$ markup | Markup required to restore a discount of $d\%$: $\text{Markup} = [d / (100 - d)] \times 100\%$ |

### 5.2 The 30-Second Execution Protocol

1. **Seconds 0-8:** Read the problem. Identify the Base ($100\%$) and whether changes are successive or parallel.
2. **Seconds 8-15:** Convert percentages to fractional equivalents ($20\% = 1/5, 25\% = 1/4, 16.67\% = 1/6$).
3. **Seconds 15-25:** If $A \times B = \text{Constant}$, apply the product constancy fraction pivot $1/n \implies 1/(n+1)$.
4. **Seconds 25-30:** Check for base inversion traps and confirm units (relative \% vs percentage points).
