# Ratio & Proportion

## Concept Definitions

- **Ratio**: A comparison of two quantities of the same kind, written as $a : b$ or $\frac{a}{b}$.
- **Proportion**: An equality of two ratios. If $a : b = c : d$, then $a, b, c, d$ are in proportion, written $a : b :: c : d$.
  - **Extremes**: $a$ and $d$.
  - **Means**: $b$ and $c$.
- **Direct Variation**: $y = kx$ for some constant $k$. As $x$ increases, $y$ increases proportionally.
- **Inverse Variation**: $y = \frac{k}{x}$. As $x$ increases, $y$ decreases proportionally.

---

## Key Formulas & Shortcuts

### Proportion Properties
If $a : b :: c : d$:
- **Product of extremes = Product of means**:
  $$a \times d = b \times c$$
- **Fourth Proportional**: $d = \frac{b \times c}{a}$
- **Third Proportional** (continued proportion $a : b :: b : c$):
  $$c = \frac{b^2}{a}$$
- **Mean Proportional** between $a$ and $b$:
  $$\sqrt{ab}$$

### Componendo and Dividendo
If $\frac{a}{b} = \frac{c}{d}$, then:
$$\frac{a + b}{a - b} = \frac{c + d}{c - d}$$

### Partnership Profits
If partners invest capitals $C_A, C_B, C_C$ for time periods $T_A, T_B, T_C$:
$$P_A : P_B : P_C = (C_A \times T_A) : (C_B \times T_B) : (C_C \times T_C)$$

## Practice Problems

### Problem 1
A bag contains 50p, 25p, and 10p coins in the ratio $5 : 9 : 4$, amounting to Rs. 206. Find the number of coins of each type.

### Problem 2
Find the mean proportional between 9 and 64, and the third proportional to 12 and 18.

### Problem 3
If $A : B = 2 : 3$, $B : C = 4 : 5$, and $C : D = 6 : 7$, find $A : B : C : D$.

### Problem 4
Two numbers are in the ratio $3 : 5$. If 9 is subtracted from each, the new numbers are in the ratio $12 : 23$. Find the smaller number.

### Problem 5
The ratio of incomes of A and B is $5 : 4$ and the ratio of expenditures is $3 : 2$. If each saves Rs. 1600, find the income of A.

---

## Step-by-Step Solutions

### Solution 1
1. Convert coin values: 50p $= 0.50$, 25p $= 0.25$, 10p $= 0.10$.
2. Let numbers be $5x, 9x, 4x$.
3. Equation:
   $$(5x \times 0.50) + (9x \times 0.25) + (4x \times 0.10) = 206$$
   $$2.5x + 2.25x + 0.40x = 206 \implies 5.15x = 206 \implies x = 40$$
4. Coins: 50p $= 5 \times 40 = 200$, 25p $= 9 \times 40 = 360$, 10p $= 4 \times 40 = 160$.
5. **Answer**: 200, 360, and 160 coins respectively.

### Solution 2
1. Mean proportional $x$ between 9 and 64:
   $$x = \sqrt{9 \times 64} = \sqrt{576} = 24$$
2. Third proportional $y$ to 12 and 18:
   $$y = \frac{18^2}{12} = \frac{324}{12} = 27$$
3. **Answer**: Mean proportional is **24**, third proportional is **27**.

### Solution 3
1. Make $B$ common. LCM of 3 and 4 is 12.
   - $A : B = (2 \times 4) : (3 \times 4) = 8 : 12$
   - $B : C = (4 \times 3) : (5 \times 3) = 12 : 15$
   - So $A : B : C = 8 : 12 : 15$.
2. Make $C$ common. LCM of 15 and 6 is 30.
   - $A : B : C = (8 \times 2) : (12 \times 2) : (15 \times 2) = 16 : 24 : 30$
   - $C : D = (6 \times 5) : (7 \times 5) = 30 : 35$
3. Combined: $A : B : C : D = 16 : 24 : 30 : 35$.
4. **Answer**: **$16 : 24 : 30 : 35$**.

### Solution 4
1. Let numbers be $3x$ and $5x$.
2. After subtracting 9:
   $$\frac{3x - 9}{5x - 9} = \frac{12}{23}$$
3. Cross-multiply:
   $$23(3x - 9) = 12(5x - 9) \implies 69x - 207 = 60x - 108 \implies 9x = 99 \implies x = 11$$
4. Smaller number $= 3x = 33$.
5. **Answer**: **33**.

### Solution 5
1. Let A's income $= 5x$, B's income $= 4x$.
2. A's expenditure $= 5x - 1600$. B's expenditure $= 4x - 1600$.
3. Ratio of expenditures:
   $$\frac{5x - 1600}{4x - 1600} = \frac{3}{2}$$
4. Cross-multiply:
   $$2(5x - 1600) = 3(4x - 1600) \implies 10x - 3200 = 12x - 4800 \implies 2x = 1600 \implies x = 800$$
5. A's income $= 5x = 4000$.
6. **Answer**: **Rs. 4000**.
