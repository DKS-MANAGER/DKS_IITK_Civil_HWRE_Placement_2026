## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(C) -- `INR 4,800`**
- **Mathematical Proof:**
  - $\text{SI} = \frac{P \times R \times T}{100} = \frac{12,000 \times 8 \times 5}{100} = 120 \times 40 = \text{INR } 4,800$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 4,200$ calculates $7\%$ rate.

#### Q2 Solution
- **Correct Option:** **(B) -- `INR 8,275`**
- **Mathematical Proof:**
  - $A = 25,000 \times (1.10)^3 = 25,000 \times 1.331 = \text{INR } 33,275$.
  - $\text{CI} = 33,275 - 25,000 = \text{INR } 8,275$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 7,500$ is the simple interest.

#### Q3 Solution
- **Correct Option:** **(B) -- `INR 100`**
- **Mathematical Proof:**
  - $D_2 = P\left(\frac{R}{100}\right)^2 = 40,000 \times \left(\frac{5}{100}\right)^2 = 40,000 \times \frac{25}{10,000} = \text{INR } 100$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 80$ calculates at $4\%$ rate.

#### Q4 Solution
- **Correct Option:** **(C) -- `24 years`**
- **Mathematical Proof:**
  - In SI, interest earned $I = N - 1$ times principal.
  - Doubles $\implies I_1 = 1P$ in $6\text{ years}$.
  - $5$ times $\implies I_2 = 4P$.
  - Time $T_2 = 4 \times 6 = 24\text{ years}$.
- **Distractor Analysis:**
  - Option (D) $30\text{ years}$ mistakenly computes $5 \times 6$.

#### Q5 Solution
- **Correct Option:** **(B) -- `12 years`**
- **Mathematical Proof:**
  - In CI, factor multiplies geometrically: $P \xrightarrow{4\text{ yr}} 3P \xrightarrow{4\text{ yr}} 9P \xrightarrow{4\text{ yr}} 27P$.
  - Total time $= 4 + 4 + 4 = 12\text{ years}$.
- **Distractor Analysis:**
  - Option (C) $16\text{ years}$ computes 4 cycles instead of 3.

#### Q6 Solution
- **Correct Option:** **(B) -- `12.36%`**
- **Mathematical Proof:**
  - $\text{EAR} = \left(1 + \frac{0.12}{2}\right)^2 - 1 = (1.06)^2 - 1 = 1.1236 - 1 = 0.1236 \implies 12.36\%$.
- **Distractor Analysis:**
  - Option (A) $12.00\%$ is the nominal rate.

#### Q7 Solution
- **Correct Option:** **(C) -- `INR 30,000`**
- **Mathematical Proof:**
  - $D_3 = P\left(\frac{R}{100}\right)^2 \left(3 + \frac{R}{100}\right) = P(0.01)(3.1) = 0.031P$.
  - $0.031P = 930 \implies P = \frac{930}{0.031} = \text{INR } 30,000$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 25,000$ computes $930 / 0.0372$.

#### Q8 Solution
- **Correct Option:** **(B) -- `10%`**
- **Mathematical Proof:**
  - $16,000\left(1 + \frac{r}{100}\right)^3 = 18,522$ where $r = R/2$ (semi-annual rate).
  - $\left(1 + \frac{r}{100}\right)^3 = \frac{18,522}{16,000} = \frac{9,261}{8,000} = \left(\frac{21}{20}\right)^3$.
  - $1 + \frac{r}{100} = 1.05 \implies r = 5\%$.
  - Annual nominal rate $R = 2 \times 5\% = 10\%$.
- **Distractor Analysis:**
  - Option (A) $8\%$ uses linear extrapolation.

#### Q9 Solution
- **Correct Option:** **(C) -- `INR 6,200`**
- **Mathematical Proof:**
  - $\text{SI for } (5 - 2) = 3\text{ years} = 8,700 - 7,200 = \text{INR } 1,500$.
  - $\text{SI per year} = \frac{1,500}{3} = \text{INR } 500$.
  - Principal $P = A_2 - 2 \times (\text{SI per year}) = 7,200 - 1,000 = \text{INR } 6,200$.
- **Distractor Analysis:**
  - Option (B) $\text{INR } 6,000$ subtracts $1,200$.

#### Q10 Solution
- **Correct Option:** **(A) -- `INR 4,000`**
- **Mathematical Proof:**
  - Overall simple interest rate $= \frac{960}{10,000} \times 100\% = 9.6\%$.
  - By Alligation Rule:
    - Part 1 ($8\%$) vs Part 2 ($12\%$) with mean $9.6\%$.
    - $\text{Ratio} = \frac{12 - 9.6}{9.6 - 8} = \frac{2.4}{1.6} = \frac{3}{2}$.
  - $12\%$ component $= \frac{2}{3+2} \times 10,000 = \frac{2}{5} \times 10,000 = \text{INR } 4,000$.
- **Distractor Analysis:**
  - Option (D) $\text{INR } 6,000$ is the $8\%$ portion.

#### Q11 Solution
- **Correct Option:** **(B) -- `INR 14,520`**
- **Mathematical Proof:**
  - Let equal installment be $X$.
  - $\text{PV} = \frac{X}{1.10} + \frac{X}{1.10^2} = X\left(\frac{10}{11} + \frac{100}{121}\right) = X\left(\frac{210}{121}\right)$.
  - $X \times \frac{210}{121} = 25,200 \implies X = 25,200 \times \frac{121}{210} = 120 \times 121 = \text{INR } 14,520$.
- **Distractor Analysis:**
  - Option (D) $\text{INR } 15,120$ computes simple interest installment.

#### Q12 Solution
- **Correct Option:** **(C) -- `INR 18,750`**
- **Mathematical Proof:**
  - In equal time intervals ($3$ years), compound growth factor is constant:
  - $\frac{A_3}{A_0} = \frac{15,000}{12,000} = 1.25$.
  - Maturity at $6\text{ years} = A_6 = A_3 \times 1.25 = 15,000 \times 1.25 = \text{INR } 18,750$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 18,000$ adds equal arithmetic interest of $\text{INR } 3,000$.

#### Q13 Solution
- **Correct Option:** **(B) -- `INR 2,542,400`**
- **Mathematical Proof:**
  - $A = P e^{rt} = 2,000,000 \times e^{0.08 \times 3} = 2,000,000 \times e^{0.24}$.
  - $A = 2,000,000 \times 1.2712 = \text{INR } 2,542,400$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 2,480,000$ is simple interest.

#### Q14 Solution
- **Correct Option:** **(B) -- `10%`**
- **Mathematical Proof:**
  - $\text{SI}$ for 2 years $= 600 \implies \text{SI for 1st year} = 300$.
  - 2nd year $\text{CI} - \text{SI} = 630 - 600 = \text{INR } 30$.
  - This $\text{INR } 30$ is the interest earned on the 1st year's interest of $\text{INR } 300$:
  - $R = \frac{30}{300} \times 100\% = 10\%$.
- **Distractor Analysis:**
  - Option (D) $15\%$ computes $30/200$.

#### Q15 Solution
- **Correct Option:** **(B) -- `20 years`**
- **Mathematical Proof:**
  - In CI: $P \to 2P$ in $5\text{ years}$.
  - $16P = 2^4 P$, which requires $4$ consecutive doubling periods.
  - Total time $= 4 \times 5 = 20\text{ years}$.
- **Distractor Analysis:**
  - Option (A) $15\text{ years}$ computes $3$ doubling cycles ($8P$).
