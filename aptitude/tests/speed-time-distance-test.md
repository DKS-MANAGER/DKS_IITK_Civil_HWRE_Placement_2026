## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(B) -- `20 m/s`**
- **Mathematical Proof:**
  - $72 \times \frac{5}{18} = 4 \times 5 = 20\text{ m/s}$.
- **Distractor Analysis:**
  - Option (A) $15\text{ m/s}$ corresponds to $54\text{ km/h}$.

#### Q2 Solution
- **Correct Option:** **(B) -- `10 seconds`**
- **Mathematical Proof:**
  - Speed $= 54 \times \frac{5}{18} = 15\text{ m/s}$.
  - Passing time $= \frac{\text{Train Length}}{\text{Speed}} = \frac{150}{15} = 10\text{ seconds}$.
- **Distractor Analysis:**
  - Option (C) $12\text{ seconds}$ computes $150 / 12.5$.

#### Q3 Solution
- **Correct Option:** **(C) -- `90 km/h`**
- **Mathematical Proof:**
  - Total time available $= 4\text{ hours}$.
  - First half distance $= 90\text{ km}$.
  - Time taken for first half $= \frac{90}{30} = 3\text{ hours}$.
  - Remaining time for second half $= 4 - 3 = 1\text{ hour}$.
  - Required speed for second $90\text{ km} = \frac{90}{1} = 90\text{ km/h}$.
- **Distractor Analysis:**
  - Option (A) $60\text{ km/h}$ is the arithmetic mean.

#### Q4 Solution
- **Correct Option:** **(B) -- `5.0 hours`**
- **Mathematical Proof:**
  - Upstream speed $= 10 - 2 = 8\text{ km/h} \implies T_{\text{up}} = \frac{24}{8} = 3\text{ hours}$.
  - Downstream speed $= 10 + 2 = 12\text{ km/h} \implies T_{\text{down}} = \frac{24}{12} = 2\text{ hours}$.
  - Total round trip time $= 3 + 2 = 5.0\text{ hours}$.
- **Distractor Analysis:**
  - Option (A) $4.5\text{ hours}$ computes $48 / 10 = 4.8\text{ h}$.

#### Q5 Solution
- **Correct Option:** **(B) -- `12 seconds`**
- **Mathematical Proof:**
  - Relative speed in opposite directions $= 40 + 50 = 90\text{ km/h} = 90 \times \frac{5}{18} = 25\text{ m/s}$.
  - Total distance to clear $= 120 + 180 = 300\text{ meters}$.
  - Passing time $= \frac{300}{25} = 12\text{ seconds}$.
- **Distractor Analysis:**
  - Option (A) $10\text{ seconds}$ divides only $250\text{ m}$.

#### Q6 Solution
- **Correct Option:** **(B) -- `60 minutes`**
- **Mathematical Proof:**
  - Speed ratio $= 3 : 4 \implies$ Time ratio $= 4 : 3$.
  - Additional time taken $= 4 - 3 = 1\text{ unit}$.
  - $1\text{ unit} = 20\text{ minutes} \implies$ Usual time ($3\text{ units}$) $= 3 \times 20 = 60\text{ minutes}$.
- **Distractor Analysis:**
  - Option (D) $80\text{ minutes}$ is the delayed duration ($4\text{ units}$).

#### Q7 Solution
- **Correct Option:** **(C) -- `250 m`**
- **Mathematical Proof:**
  - Speed $= 60 \times \frac{5}{18} = \frac{50}{3}\text{ m/s}$.
  - Distance covered in $27\text{ s} = \frac{50}{3} \times 27 = 450\text{ meters}$.
  - Distance $= L_{\text{train}} + L_{\text{platform}} \implies 450 = L_{\text{train}} + 200 \implies L_{\text{train}} = 250\text{ meters}$.
- **Distractor Analysis:**
  - Option (A) $220\text{ m}$ is an arithmetic slip.

#### Q8 Solution
- **Correct Option:** **(B) -- `5.26 m/s`**
- **Mathematical Proof:**
  - $B$ covers the remaining $50\text{ meters}$ in $10\text{ seconds} \implies v_B = \frac{50}{10} = 5\text{ m/s}$.
  - When $A$ completes $1,000\text{ m}$, $B$ has covered $950\text{ m}$.
  - Time taken by $B$ to cover $950\text{ m} = \frac{950}{5} = 190\text{ seconds}$.
  - Since $A$ and $B$ ran for the same duration, $A$'s time is $190\text{ seconds}$.
  - $v_A = \frac{1,000}{190} = 5.263\text{ m/s}$.
- **Distractor Analysis:**
  - Option (A) $5.00\text{ m/s}$ is $B$'s speed.

#### Q9 Solution
- **Correct Option:** **(C) -- `400 seconds`**
- **Mathematical Proof:**
  - Lap time for $P = \frac{400}{5} = 80\text{ seconds}$.
  - Lap time for $Q = \frac{400}{3}\text{ seconds}$.
  - They meet at the starting point at $\text{LCM}\left(80, \frac{400}{3}\right) = \frac{\text{LCM}(80, 400)}{\text{GCD}(1, 3)} = \frac{400}{1} = 400\text{ seconds}$.
- **Distractor Analysis:**
  - Option (B) $200\text{ seconds}$ is the relative meeting time anywhere on track ($\frac{400}{5-3} = 200\text{ s}$).

#### Q10 Solution
- **Correct Option:** **(A) -- `48.0 km/h`**
- **Mathematical Proof:**
  - For equal distance journeys: $v_{\text{avg}} = \frac{2 v_1 v_2}{v_1 + v_2} = \frac{2 \times 40 \times 60}{40 + 60} = \frac{4,800}{100} = 48.0\text{ km/h}$.
- **Distractor Analysis:**
  - Option (B) $50.0\text{ km/h}$ is the arithmetic mean.

#### Q11 Solution
- **Correct Option:** **(B) -- `54 km/h`**
- **Mathematical Proof:**
  - By the After-Meeting Theorem: $\frac{v_A}{v_B} = \sqrt{\frac{T_B}{T_A}}$.
  - $T_A = 4\text{ h } 48\text{ min} = \frac{24}{5}\text{ hours}$.
  - $T_B = 3\text{ h } 20\text{ min} = \frac{10}{3}\text{ hours}$.
  - $\frac{v_A}{v_B} = \sqrt{\frac{10/3}{24/5}} = \sqrt{\frac{50}{72}} = \sqrt{\frac{25}{36}} = \frac{5}{6}$.
  - $v_B = 45 \times \frac{6}{5} = 54\text{ km/h}$.
- **Distractor Analysis:**
  - Option (D) $60\text{ km/h}$ inverts the time ratio.

#### Q12 Solution
- **Correct Option:** **(B) -- `4:00 PM`**
- **Mathematical Proof:**
  - In 30 minutes ($1:30 \to 2:00$), thief covers: $40 \times 0.5 = 20\text{ km}$.
  - Relative speed of owner chasing $= 50 - 40 = 10\text{ km/h}$.
  - Time required to close gap $= \frac{20}{10} = 2\text{ hours}$.
  - Time of catch $= 2:00\text{ PM} + 2\text{ hours} = 4:00\text{ PM}$.
- **Distractor Analysis:**
  - Option (C) $4:30\text{ PM}$ counts from 1:30 PM.

#### Q13 Solution
- **Correct Option:** **(B) -- `24 km`**
- **Mathematical Proof:**
  - $v_{\text{up}} = 6 - 2 = 4\text{ km/h}$.
  - $v_{\text{down}} = 6 + 2 = 8\text{ km/h}$.
  - $\frac{D}{4} - \frac{D}{8} = 3 \implies \frac{2D - D}{8} = 3 \implies \frac{D}{8} = 3 \implies D = 24\text{ km}$.
- **Distractor Analysis:**
  - Option (A) $20\text{ km}$ computes $(6 \times 2) + 8$.

#### Q14 Solution
- **Correct Option:** **(C) -- `5`**
- **Mathematical Proof:**
  - When running in opposite directions on a circular track, the number of distinct meeting points is $a + b$, where $a : b$ is the simplified ratio of their speeds.
  - Ratio $= 15 : 10 = 3 : 2$ (co-prime).
  - Distinct points of meeting $= 3 + 2 = 5$.
- **Distractor Analysis:**
  - Option (A) $3$ is the count if running in the same direction ($3 - 2 = 1$).

#### Q15 Solution
- **Correct Option:** **(A) -- `A wins by 20 m`**
- **Mathematical Proof:**
  - $A$ needs to run $500 - 140 = 360\text{ meters}$.
  - $B$ needs to run $500\text{ meters}$.
  - Speed ratio $v_A : v_B = 3 : 4$.
  - In the time $A$ runs $360\text{ m}$, $B$ runs: $\frac{4}{3} \times 360 = 480\text{ meters}$.
  - Since $B$ only reaches $480\text{ m}$ when $A$ crosses the finish line ($500\text{ m}$ mark), $A$ wins by $500 - 480 = 20\text{ meters}$.
- **Distractor Analysis:**
  - Option (B) $B$ wins by $20\text{ m}$ inverts the winner.
