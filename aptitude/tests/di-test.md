### Caselet 1: SaaS Enterprise Financial Metrics (Questions 1–5)

| $U_1$ | $120.0$ | $45.0$ | $4.5\%$ | $118\%$ | $75\%$ |
| $U_2$ | $180.0$ | $60.0$ | $6.0\%$ | $112\%$ | $80\%$ |
| $U_3$ | $240.0$ | $50.0$ | $3.0\%$ | $125\%$ | $85\%$ |

## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(B) -- `INR 618.0 Crores`**
- **Mathematical Proof:**
  - $U_1: 120 \times 0.75 = 90.0$.
  - $U_2: 180 \times 0.80 = 144.0$.
  - $U_3: 240 \times 0.85 = 204.0$.
  - $U_4: 90 \times 0.70 = 63.0$.
  - $U_5: 150 \times 0.78 = 117.0$.
  - $\text{Total Gross Profit} = 90 + 144 + 204 + 63 + 117 = \text{INR } 618.0\text{ Crores}$.
- **Distractor Analysis:**
  - Option (A) $598.0$ omits one unit's margin.

#### Q2 Solution
- **Correct Option:** **(C) -- `U_3`**
- **Mathematical Proof:**
  - $U_3$ Gross Profit $= 204\text{ Crores} = 204,000\text{ Thousands}$.
  - Ratio $= \frac{204,000}{50} = 4,080$ (highest among all units).
- **Distractor Analysis:**
  - Option (B) $U_2$ yields $\frac{144,000}{60} = 2,400$.

#### Q3 Solution
- **Correct Option:** **(B) -- `INR 300.0 Crores`**
- **Mathematical Proof:**
  - $\text{New ARR} = 240.0 \times 1.25 = \text{INR } 300.0\text{ Crores}$.
- **Distractor Analysis:**
  - Option (A) $280.0$ applies simple $16.6\%$ growth.

#### Q4 Solution
- **Correct Option:** **(B) -- `4.88%`**
- **Mathematical Proof:**
  - Total ARR $= 120 + 180 + 240 + 90 + 150 = 780\text{ Crores}$.
  - Churn volume $= (120 \times 0.045) + (180 \times 0.06) + (240 \times 0.03) + (90 \times 0.08) + (150 \times 0.05) = 5.4 + 10.8 + 7.2 + 7.2 + 7.5 = 38.1\text{ Crores}$.
  - Weighted Churn Rate $= \frac{38.1}{780} \times 100\% \approx 4.884\% \approx 5.05\%$.
- **Distractor Analysis:**
  - Option (A) is simple arithmetic mean of churn percentages.

#### Q5 Solution
- **Correct Option:** **(A) -- `7 : 11`**
- **Mathematical Proof:**
  - Combined $(U_1 + U_4) = 120 + 90 = 210\text{ Crores}$.
  - Combined $(U_2 + U_5) = 180 + 150 = 330\text{ Crores}$.
  - Ratio $= \frac{210}{330} = \frac{7}{11}$.
- **Distractor Analysis:**
  - Option (D) $2:3$ is an inaccurate approximation.

#### Q6 Solution
- **Correct Option:** **(C) -- `30.0 ML`**
- **Mathematical Proof:**
  - Industrial allocation $= 25\% \times 120\text{ ML} = 30.0\text{ ML}$.
- **Distractor Analysis:**
  - Option (A) $25.0\text{ ML}$ takes the percentage value directly.

#### Q7 Solution
- **Correct Option:** **(B) -- `54.0 deg`**
- **Mathematical Proof:**
  - Commercial angle $= 15\% \times 360^\circ = 0.15 \times 360^\circ = 54.0^\circ$.
- **Distractor Analysis:**
  - Option (A) $48.0^\circ$ evaluates $13.3\%$.

#### Q8 Solution
- **Correct Option:** **(B) -- `44.0%`**
- **Mathematical Proof:**
  - Transmission losses reduced by $50\% \implies 8\% \times 0.5 = 4\%$ saved.
  - New Domestic share $= 40\% + 4\% = 44.0\%$.
- **Distractor Analysis:**
  - Option (D) $48.0\%$ adds the entire $8\%$ loss without the $50\%$ reduction factor.

#### Q9 Solution
- **Correct Option:** **(A) -- `55 : 37`**
- **Mathematical Proof:**
  - Domestic + Commercial $= 40\% + 15\% = 55\%$.
  - Industrial + Agricultural $= 25\% + 12\% = 37\%$.
  - Ratio $= 55 : 37$.
- **Distractor Analysis:**
  - Option (B) $11 : 7$ is an inaccurate reduction.

#### Q10 Solution
- **Correct Option:** **(B) -- `9.6 ML`**
- **Mathematical Proof:**
  - Initial Agricultural volume $= 12\% \times 120\text{ ML} = 14.4\text{ ML}$.
  - Revised Agricultural volume $= 16\% \times 150\text{ ML} = 24.0\text{ ML}$.
  - Net increase $= 24.0 - 14.4 = 9.6\text{ ML}$.
- **Distractor Analysis:**
  - Option (A) $8.4\text{ ML}$ computes $150 \times 4\% = 6.0\text{ ML}$.

#### Q11 Solution
- **Correct Option:** **(C) -- `P_3`**
- **Mathematical Proof:**
  - $P_3$ delivers the highest absolute excess return: $22\% - 6\% = 16\%$.
- **Distractor Analysis:**
  - All portfolios have strong risk metrics.

#### Q12 Solution
- **Correct Option:** **(B) -- `INR 670.0 Crores`**
- **Mathematical Proof:**
  - $P_1: 500 \times 0.18 = 90.0$.
  - $P_2: 800 \times 0.14 = 112.0$.
  - $P_3: 1,200 \times 0.22 = 264.0$.
  - $P_4: 600 \times 0.10 = 60.0$.
  - $P_5: 900 \times 0.16 = 144.0$.
  - $\text{Total Return} = 90 + 112 + 264 + 60 + 144 = \text{INR } 670.0\text{ Crores}$.
- **Distractor Analysis:**
  - Option (A) $650.0$ misses $20\text{ Crores}$.

#### Q13 Solution
- **Correct Option:** **(C) -- `16.75%`**
- **Mathematical Proof:**
  - Total AUM $= 500 + 800 + 1,200 + 600 + 900 = 4,000\text{ Crores}$.
  - Total Returns $= \text{INR } 670.0\text{ Crores}$.
  - Weighted return $= \frac{670}{4,000} \times 100\% = 16.75\% \approx 17.25\%$.
- **Distractor Analysis:**
  - Option (D) $18.10\%$ is the unweighted arithmetic mean.

#### Q14 Solution
- **Correct Option:** **(A) -- `INR 162.0 Crores`**
- **Mathematical Proof:**
  - Revised AUM $= 1,200 \times (1 - 0.10) = 1,080\text{ Crores}$.
  - Absolute return $= 1,080 \times 0.15 = \text{INR } 162.0\text{ Crores}$.
- **Distractor Analysis:**
  - Option (C) $180.0$ applies $15\%$ on the original $1,200\text{ Crores}$.

#### Q15 Solution
- **Correct Option:** **(B) -- `30.0%`**
- **Mathematical Proof:**
  - Contribution $= \frac{1,200}{4,000} \times 100\% = 30.0\%$.
- **Distractor Analysis:**
  - Option (A) $25.0\%$ computes $1,000 / 4,000$.
