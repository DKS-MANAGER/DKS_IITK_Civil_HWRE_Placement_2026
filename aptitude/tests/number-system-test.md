### Explanations
1. 23 is prime. **B**
2. 3^4 = 81, unit digit 1. **A**
3. 10×11/2 = 55. **A**
4. 12 = 2²×3. Factors = 3×2 = 6. **A**
5. 15 = 3×5, composite. **B**
6. 7-cycle length 4. 123 mod 4 = 3. 7³ = 343 → 3. **C**
7. 72 = 2³×3². Factors = 4×3 = 12. **A**
8. 20² = 400. **A**
9. 3-cycle mod 5: 3,4,2,1. 50 mod 4 = 2. 3²=9≡4. **A**
10. 50/5 + 50/25 = 10+2 = 12. **A**
11. 7-cycle: 562 mod 4=2 → 9. 4-cycle: odd → 4. 9×4=36 → 6. **A**
12. 899=29×31. 63 mod 29 = 5. **A**
13. Odd n: 50. **A**
14. 7^100 mod 100. 7^4=2401≡1. 100 mod 4=0. 7^100≡1. **A**
15. AP: 104 to 296, d=4. n=49. Sum=49/2(104+296)=9800. **A**
