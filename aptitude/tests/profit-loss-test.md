## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(B) -- `12%`**
- **Mathematical Proof:**
  - Let cost price $\text{CP} = 100$.
  - Marked price $\text{MP} = 100 \times 1.40 = 140$.
  - Selling price $\text{SP} = 140 \times (1 - 0.20) = 140 \times 0.80 = 112$.
  - Profit percentage $= \frac{112 - 100}{100} \times 100\% = 12\%$.
- **Distractor Analysis:**
  - Option (D) $20\%$ simply computes $40 - 20 = 20\%$.

#### Q2 Solution
- **Correct Option:** **(B) -- `INR 12,075`**
- **Mathematical Proof:**
  - Selling at $20\%$ loss: $\text{SP} = 0.80 \times \text{CP} = 8,400 \implies \text{CP} = \frac{8,400}{0.80} = \text{INR } 10,500$.
  - Required selling price for $15\%$ profit: $\text{SP}_{\text{target}} = 10,500 \times 1.15 = \text{INR } 12,075$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 11,500$ mistakenly marks up on $10,000$.

#### Q3 Solution
- **Correct Option:** **(C) -- `25.00%`**
- **Mathematical Proof:**
  - Profit $\% = \frac{\text{True Weight} - \text{False Weight}}{\text{False Weight}} \times 100\% = \frac{1000 - 800}{800} \times 100\% = \frac{200}{800} \times 100\% = 25\%$.
- **Distractor Analysis:**
  - Option (A) $20.00\%$ is the common error of dividing by the nominal base ($1000\text{ g}$).

#### Q4 Solution
- **Correct Option:** **(A) -- `28%`**
- **Mathematical Proof:**
  - Equivalent discount $= d_1 + d_2 - \frac{d_1 d_2}{100} = 20 + 10 - \frac{200}{100} = 30 - 2 = 28\%$.
- **Distractor Analysis:**
  - Option (B) $30\%$ directly adds discounts without successive compounding.

#### Q5 Solution
- **Correct Option:** **(B) -- `25.0%`**
- **Mathematical Proof:**
  - $15 \times \text{CP} = 12 \times \text{SP} \implies \frac{\text{SP}}{\text{CP}} = \frac{15}{12} = \frac{5}{4} = 1.25$.
  - Profit percentage $= (1.25 - 1) \times 100\% = 25\%$.
- **Distractor Analysis:**
  - Option (A) $20\%$ divides difference $3$ by $15$ instead of $12$.

#### Q6 Solution
- **Correct Option:** **(B) -- `8%`**
- **Mathematical Proof:**
  - Multiplier $= 1.50 \times (1 - 0.20) \times (1 - 0.10) = 1.50 \times 0.80 \times 0.90 = 1.20 \times 0.90 = 1.08$.
  - Net profit $= (1.08 - 1) \times 100\% = 8\%$.
- **Distractor Analysis:**
  - Option (D) $12\%$ neglects the second discount.

#### Q7 Solution
- **Correct Option:** **(C) -- `1% loss`**
- **Mathematical Proof:**
  - When two articles are sold at the same selling price, one at $x\%$ profit and other at $x\%$ loss:
  - Net result is always a loss of $\left(\frac{x}{10}\right)^2 \% = \left(\frac{10}{10}\right)^2 \% = 1\%$ loss.
- **Distractor Analysis:**
  - Option (A) is the classic trap of assuming $+10\%$ and $-10\%$ cancel out.

#### Q8 Solution
- **Correct Option:** **(C) -- `30.0%`**
- **Mathematical Proof:**
  - Multiplier $= \text{Markup} \times \text{Discount} \times \text{Weight Ratio} = 1.30 \times 0.90 \times \frac{1000}{900} = 1.17 \times \frac{10}{9} = 1.30$.
  - Net profit percentage $= (1.30 - 1) \times 100\% = 30\%$.
- **Distractor Analysis:**
  - Option (B) $28\%$ forgets the fraudulent weight multiplier.

#### Q9 Solution
- **Correct Option:** **(B) -- `INR 50,000`**
- **Mathematical Proof:**
  - $\text{CP} \times (1 + 0.20) \times (1 + 0.25) = 75,000$.
  - $\text{CP} \times 1.20 \times 1.25 = \text{CP} \times 1.50 = 75,000 \implies \text{CP} = \frac{75,000}{1.50} = \text{INR } 50,000$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 48,000$ computes successive deductions on final price.

#### Q10 Solution
- **Correct Option:** **(B) -- `INR 200/kg`**
- **Mathematical Proof:**
  - Total cost $= (60 \times 180) + (40 \times 130) = 10,800 + 5,200 = \text{INR } 16,000$.
  - Total weight $= 100\text{ kg} \implies \text{Weighted CP} = \text{INR } 160/\text{kg}$.
  - Target selling price $= 160 \times 1.25 = \text{INR } 200/\text{kg}$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 190/\text{kg}$ adds simple average markup.

#### Q11 Solution
- **Correct Option:** **(B) -- `20%`**
- **Mathematical Proof:**
  - Total outlay $\text{CP} = 120 \times 50 = \text{INR } 6,000$.
  - Saleable quantity $= 120 - 20 = 100\text{ sensors}$.
  - Total revenue $\text{SP} = 100 \times 72 = \text{INR } 7,200$.
  - Net profit percentage $= \frac{7,200 - 6,000}{6,000} \times 100\% = \frac{1,200}{6,000} \times 100\% = 20\%$.
- **Distractor Analysis:**
  - Option (C) $25\%$ computes gain on saleable quantity alone $(72-50)/50 = 44\%$.

#### Q12 Solution

- **Mathematical Proof:**

  - Effective discount $= \frac{\text{Free Articles}}{\text{Total Articles Delivered}} \times 100\% = \frac{3}{8} \times 100\% = 37.5\%$.
- **Distractor Analysis:**
  - Option (C) $60.0\%$ calculates $3/5$, which erroneously ignores the total article base.

#### Q13 Solution
- **Correct Option:** **(A) -- `INR 360`**
- **Mathematical Proof:**
  - Let original cost price be $\text{CP} = x$.
  - $\text{SP}_1 = 1.12x$.
  - Hypothetical case: New $\text{CP} = 0.90x$.
  - New $\text{SP} = 1.30 \times (0.90x) = 1.17x$.
  - Difference $\text{SP}_2 - \text{SP}_1 = 1.17x - 1.12x = 0.05x$.
  - $0.05x = 18 \implies x = \frac{18}{0.05} = \text{INR } 360$.
- **Distractor Analysis:**
  - Option (B) $\text{INR } 400$ calculates $0.05x = 20$.

#### Q14 Solution

  - Second discount reduces $\text{INR } 2,040 \to \text{INR } 1,734$.
  - Discount amount $= 2,040 - 1,734 = \text{INR } 306$.
  - Percentage $x = \frac{306}{2,040} \times 100\% = 15\%$.
- **Distractor Analysis:**
  - Option (A) $10\%$ results in $\text{SP} = 1,836$.

#### Q15 Solution
- **Correct Option:** **(C) -- `22.22%`**
- **Mathematical Proof:**
  - When buying, trader takes $1100\text{ g}$ while paying for $1000\text{ g} \implies \text{Factor} = \frac{1100}{1000} = \frac{11}{10}$.
  - When selling, trader delivers $900\text{ g}$ while charging for $1000\text{ g} \implies \text{Factor} = \frac{1000}{900} = \frac{10}{9}$.
  - Combined multiplier $= \frac{11}{10} \times \frac{10}{9} = \frac{11}{9} = 1 + \frac{2}{9}$.
  - Net gain percentage $= \frac{2}{9} \times 100\% = 22.22\%$.
- **Distractor Analysis:**
  - Option (B) $21.00\%$ naively applies successive percentage $(10 + 10 + 1 = 21\%)$, which fails for weight frauds.
