## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(B) -- `6 : 8 : 9`**
- **Mathematical Proof:**
  - $A : B = 3 : 4 = 6 : 8$.
  - $B : C = 8 : 9$.
  - Unifying across common term $B = 8$: $A : B : C = 6 : 8 : 9$.
- **Distractor Analysis:**
  - Option (A) $3:4:9$ forgets to balance $B$.

#### Q2 Solution
- **Correct Option:** **(C) -- `6 : 4 : 3`**
- **Mathematical Proof:**
  - Let $2A = 3B = 4C = k \implies A = k/2, B = k/3, C = k/4$.
  - Multiply through by $\text{LCM}(2, 3, 4) = 12$:
  - $A : B : C = 6 : 4 : 3$.
- **Distractor Analysis:**
  - Option (A) $2:3:4$ takes coefficients directly without inverting.

#### Q3 Solution
- **Correct Option:** **(C) -- `27`**
- **Mathematical Proof:**
  - In proportion: $\frac{4}{9} = \frac{12}{x} \implies 4x = 108 \implies x = 27$.
- **Distractor Analysis:**
  - Option (A) $18$ calculates $9 \times 2$.

#### Q4 Solution
- **Correct Option:** **(B) -- `28`**
- **Mathematical Proof:**
  - Mean proportional $x = \sqrt{a \times b} = \sqrt{16 \times 49} = \sqrt{784} = 28$.
- **Distractor Analysis:**
  - Option (A) $24$ computes arithmetic mean $(16+49)/2 \approx 32.5$.

#### Q5 Solution
- **Correct Option:** **(B) -- `INR 1,440`**
- **Mathematical Proof:**
  - $A : B = 2 : 3 = 8 : 12$.
  - $B : C = 4 : 5 = 12 : 15$.
  - $A : B : C = 8 : 12 : 15$.
  - Total parts $= 8 + 12 + 15 = 35$.
  - $B$'s share $= \frac{12}{35} \times 4,200 = 12 \times 120 = \text{INR } 1,440$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 1,200$ is $A$'s share $(8 \times 120 = 960)$.

#### Q6 Solution
- **Correct Option:** **(B) -- `30`**
- **Mathematical Proof:**
  - Let numbers be $5x$ and $7x$.
  - $\frac{5x + 6}{7x + 6} = \frac{3}{4} \implies 20x + 24 = 21x + 18 \implies x = 6$.
  - Smaller number $= 5 \times 6 = 30$.
- **Distractor Analysis:**
  - Option (C) $35$ is $5 \times 7$.

#### Q7 Solution
- **Correct Option:** **(C) -- `160`**
- **Mathematical Proof:**
  - Let coin counts be $3x, 4x, 8x$.
  - Value in INR: $(3x \times 1.00) + (4x \times 0.50) + (8x \times 0.25) = 3x + 2x + 2x = 7x$.
  - $7x = 280 \implies x = 40$.
  - Number of $50\text{p}$ coins $= 4x = 4 \times 40 = 160$.
- **Distractor Analysis:**
  - Option (A) $120$ is the number of $\text{INR } 1$ coins.

#### Q8 Solution
- **Correct Option:** **(B) -- `INR 20,000`**
- **Mathematical Proof:**
  - Profit ratio $= (C_A \times T_A) : (C_B \times T_B) = (50,000 \times 6) : (40,000 \times 9) = 300,000 : 360,000 = 5 : 6$.
  - Total parts $= 5 + 6 = 11$.
  - $A$'s share $= \frac{5}{11} \times 44,000 = \text{INR } 20,000$.
- **Distractor Analysis:**
  - Option (D) $\text{INR } 24,000$ is $B$'s share.

#### Q9 Solution
- **Correct Option:** **(B) -- `INR 15,000`**
- **Mathematical Proof:**
  - Incomes: $5x, 4x$. Expenditures: $3y, 2y$.
  - $5x - 3y = 6,000$ and $4x - 2y = 6,000 \implies 2x - y = 3,000 \implies y = 2x - 3,000$.
  - Substitute into 1st: $5x - 3(2x - 3,000) = 6,000 \implies 5x - 6x + 9,000 = 6,000 \implies x = 3,000$.
  - $A$'s income $= 5 \times 3,000 = \text{INR } 15,000$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 12,000$ is $B$'s income.

#### Q10 Solution
- **Correct Option:** **(B) -- `INR 48,000`**
- **Mathematical Proof:**
  - Original: $C = k W^2 \implies 100,000 = k (10^2) \implies k = 1,000$.
  - Broken pieces weights: $\frac{2}{5} \times 10 = 4\text{ carats}$, $\frac{3}{5} \times 10 = 6\text{ carats}$.
  - Combined broken value $= 1,000(4^2) + 1,000(6^2) = 16,000 + 36,000 = \text{INR } 52,000$.
  - Financial loss $= 100,000 - 52,000 = \text{INR } 48,000$.
- **Distractor Analysis:**
  - Option (D) $\text{INR } 52,000$ is the remaining value, not the loss.

#### Q11 Solution
- **Correct Option:** **(A) -- `7 / 29`**
- **Mathematical Proof:**
  - Divide numerator and denominator by $y$:
  - $\frac{5(x/y) - 2}{7(x/y) + 2} = \frac{5(3/4) - 2}{7(3/4) + 2} = \frac{15/4 - 2}{21/4 + 2} = \frac{7/4}{29/4} = \frac{7}{29}$.
- **Distractor Analysis:**
  - Option (B) $7/33$ evaluates denominator incorrectly.

#### Q12 Solution
- **Correct Option:** **(B) -- `121 : 59`**
- **Mathematical Proof:**
  - Total parts in 3 containers: $4, 3, 5$. Take vessel volume $\text{LCM}(4, 3, 5) = 60\text{ liters}$ each.
  - Container 1 ($3:1$): Milk $= \frac{3}{4} \times 60 = 45$, Water $= 15$.
  - Container 2 ($2:1$): Milk $= \frac{2}{3} \times 60 = 40$, Water $= 20$.
  - Container 3 ($3:2$): Milk $= \frac{3}{5} \times 60 = 36$, Water $= 24$.
  - Total Milk $= 45 + 40 + 36 = 121\text{ liters}$.
  - Total Water $= 15 + 20 + 24 = 59\text{ liters}$.
  - Ratio $= 121 : 59$.
- **Distractor Analysis:**
  - Option (A) $71:39$ simply adds the raw numerators and denominators.

#### Q13 Solution
- **Correct Option:** **(B) -- `INR 50,000`**
- **Mathematical Proof:**
  - Capital ratio $A : B = 20,000 : 30,000 = 2 : 3$.
  - Management fee to $A = 0.10 P$.
  - Remaining profit distributed $= 0.90 P$.
  - $A$'s investment share $= \frac{2}{5} \times 0.90 P = 0.36 P$.
  - $A$'s total earnings $= 0.10 P + 0.36 P = 0.46 P$.
  - $0.46 P = 23,000 \implies P = \frac{23,000}{0.46} = \text{INR } 50,000$.
- **Distractor Analysis:**
  - Option (D) $\text{INR } 60,000$ computes $23,000 / 0.38$.

#### Q14 Solution
- **Correct Option:** **(B) -- `3.0`**
- **Mathematical Proof:**
  - $z = k \frac{x}{y^2} \implies 3 = k \frac{8}{4^2} = k \frac{8}{16} = 0.5 k \implies k = 6$.
  - For $x = 18$ and $y = 6$:
  - $z = 6 \times \frac{18}{6^2} = 6 \times \frac{18}{36} = 6 \times 0.5 = 3.0$.
- **Distractor Analysis:**
  - Option (A) $2.5$ forgets constant $k$.

#### Q15 Solution
- **Correct Option:** **(B) -- `3 : 2`**
- **Mathematical Proof:**
  - Let mass ratio of Gold to Copper be $g : c$.
  - Applying Alligation on specific gravities:
    - Gold $= 19$, Copper $= 9$, Mixture $= 15$.
    - $\frac{\text{Gold}}{\text{Copper}} = \frac{15 - 9}{19 - 15} = \frac{6}{4} = \frac{3}{2}$.
- **Distractor Analysis:**
  - Option (A) $2 : 3$ inverts the ratio.
