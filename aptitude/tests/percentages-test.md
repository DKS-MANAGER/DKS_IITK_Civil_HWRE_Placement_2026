| **Q2** | **C** | Base conversion: Let $C = 100 \implies B = 125 \implies A = 125 \times 0.6 = 75 \implies 25\%$ less than $C$ |
| **Q3** | **A** | Successive multiplier: $1.20 \times 0.85 = 1.02 \implies 2\%$ net increase |

| **Q5** | **B** | Multiplicative growth: $120,000 \times 1.10 \times 1.20 = 120,000 \times 1.32 = 158,400$ |

| **Q7** | **C** | $T \times 0.90 \times 0.90 \times (0.54 - 0.46) = 1,620 \implies 0.81T \times 0.08 = 1,620 \implies 0.0648T = 1,620 \implies T = 25,000$ |

| **Q10** | **C** | $20\%$ saving on $12,000 = \text{INR } 2,400$ buys $5$ barrels $\implies \text{New price} = 480$. $\text{Original price} = \frac{480}{0.8} = \text{INR } 600$ |

## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(B) -- `20.00%`**
- **Mathematical Proof:**
  - Expenditure $E = P \times Q$.
  - When $P$ increases by $25\%$ ($P \to \frac{5}{4}P$), $Q$ must scale by $\frac{4}{5}Q$ to keep $E$ constant.
  - Reduction $= 1 - \frac{4}{5} = \frac{1}{5} = 20.00\%$.
- **Distractor Analysis:**
  - Option (C) $25\%$ is the naive symmetry error.

#### Q2 Solution
- **Correct Option:** **(C) -- `25%`**
- **Mathematical Proof:**
  - Let $C = 100$.
  - $B = 1.25 \times 100 = 125$.
  - $A = (1 - 0.40) \times 125 = 0.60 \times 125 = 75$.
  - Percentage by which $A$ is less than $C = \frac{100 - 75}{100} \times 100\% = 25\%$.
- **Distractor Analysis:**
  - Option (A) $15\%$ directly subtracts percentages $(40 - 25)$, which is mathematically invalid across differing bases.

#### Q3 Solution
- **Correct Option:** **(A) -- `2% increase`**
- **Mathematical Proof:**
  - Net multiplier $= (1 + 0.20)(1 - 0.15) = 1.20 \times 0.85 = 1.02$.
  - Net change $= (1.02 - 1) \times 100\% = +2\%$ (increase).
- **Distractor Analysis:**
  - Option (B) $+5\%$ simply computes $20 - 15 = 5$.

#### Q4 Solution
- **Correct Option:** **(B) -- `500`**
- **Mathematical Proof:**
  - Required pass marks $= 175 + 25 = 200$.
  - $40\% \text{ of Maximum} = 200 \implies \text{Maximum} = \frac{200}{0.40} = 500$.
- **Distractor Analysis:**
  - Option (A) $400$ occurs if $25$ is subtracted instead of added.

#### Q5 Solution
- **Correct Option:** **(B) -- `158,400`**
- **Mathematical Proof:**
  - Final population $= 120,000 \times 1.10 \times 1.20 = 120,000 \times 1.32 = 158,400$.
- **Distractor Analysis:**
  - Option (A) $156,000$ computes simple interest addition ($30\%$).

#### Q6 Solution
- **Correct Option:** **(B) -- `25 kg`**
- **Mathematical Proof:**
  - Fresh dates: $80\%$ water $\implies 20\%$ dry solid pulp.
  - Pulp mass $= 20\% \times 100\text{ kg} = 20\text{ kg}$.
  - In dried dates, water is $20\% \implies$ pulp is $80\%$.
  - $0.80 \times W_{\text{dry}} = 20\text{ kg} \implies W_{\text{dry}} = \frac{20}{0.80} = 25\text{ kg}$.
- **Distractor Analysis:**
  - Option (A) $20\text{ kg}$ assumes the total dry weight equals the pulp weight.

#### Q7 Solution
- **Correct Option:** **(C) -- `25,000`**
- **Mathematical Proof:**
  - Let enrolled voters be $T$.
  - Votes polled $= 0.90T$.
  - Valid votes $= 0.90 \times 0.90T = 0.81T$.
  - Margin $= (54\% - 46\%) \text{ of valid votes} = 8\% \times 0.81T = 0.0648T$.
  - $0.0648T = 1,620 \implies T = \frac{1,620}{0.0648} = 25,000$.
- **Distractor Analysis:**
  - Option (A) $20,000$ ignores the non-voter or invalid voter discount factor.

#### Q8 Solution
- **Correct Option:** **(A) -- `4% increase`**
- **Mathematical Proof:**
  - $\Delta A\% = a + b + \frac{ab}{100} = +30 - 20 + \frac{(30)(-20)}{100} = 10 - 6 = +4\%$.
- **Distractor Analysis:**
  - Option (C) $10\%$ forgets the cross-product term $-6\%$.

#### Q9 Solution
- **Correct Option:** **(C) -- `30%`**
- **Mathematical Proof:**
  - Total students passing in at least one subject $= 100\% - 10\% = 90\%$.
  - $n(ML \cup LA) = n(ML) + n(LA) - n(ML \cap LA)$.
  - $90\% = 65\% + 55\% - n(ML \cap LA) \implies n(ML \cap LA) = 120\% - 90\% = 30\%$.
- **Distractor Analysis:**
  - Option (A) $20\%$ neglects the $10\%$ dual-failure cohort.

#### Q10 Solution
- **Correct Option:** **(C) -- `INR 600`**
- **Mathematical Proof:**
  - $20\%$ saving on $\text{INR } 12,000 = \text{INR } 2,400$.
  - This saving purchases $5$ extra barrels $\implies \text{Reduced price} = \frac{2,400}{5} = \text{INR } 480/\text{barrel}$.
  - Original price $= \frac{480}{1 - 0.20} = \frac{480}{0.80} = \text{INR } 600/\text{barrel}$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 480$ is the reduced price, not the original price.

#### Q11 Solution
- **Correct Option:** **(B) -- `INR 50,000`**
- **Mathematical Proof:**
  - Remaining fraction $= (1 - 0.30)(1 - 0.25)(1 - 0.20) = 0.70 \times 0.75 \times 0.80 = 0.42$.
  - $0.42 \times I = 21,000 \implies I = \frac{21,000}{0.42} = \text{INR } 50,000$.
- **Distractor Analysis:**
  - Option (D) $\text{INR } 60,000$ computes linear deductions $(30+25+20 = 75\% \implies 25\% \text{ left})$.

#### Q12 Solution
- **Correct Option:** **(B) -- `2,000`**
- **Mathematical Proof:**
  - Candidate $C$ percentage $= 100\% - (45\% + 35\%) = 20\%$.
  - $20\% \text{ of Total} = 4,000 \implies \text{Total votes} = 20,000$.
  - Margin of $A$ over $B = (45\% - 35\%) \times 20,000 = 10\% \times 20,000 = 2,000\text{ votes}$.
- **Distractor Analysis:**
  - Option (D) $3,000$ calculates $(45\% - 20\%)$ instead of $(A - B)$.

#### Q13 Solution
- **Correct Option:** **(B) -- `52.5 kg`**
- **Mathematical Proof:**
  - Tin percentage $= 100\% - (35\% + 45\%) = 20\%$.
  - $20\% \text{ of Total} = 30\text{ kg} \implies \text{Total weight} = 150\text{ kg}$.
  - Zinc weight $= 35\% \times 150\text{ kg} = 52.5\text{ kg}$.
- **Distractor Analysis:**
  - Option (C) $60.0\text{ kg}$ calculates copper weight instead of zinc.

#### Q14 Solution
- **Correct Option:** **(C) -- `60%`**
- **Mathematical Proof:**
  - Revenue $R = \text{Price } P \times \text{Visitors } V$.
  - $1.28 R = (0.80 P) \times V_{\text{new}} \implies \frac{V_{\text{new}}}{V} = \frac{1.28}{0.80} = 1.60$.
  - Attendance increased by $(1.60 - 1) \times 100\% = 60\%$.
- **Distractor Analysis:**
  - Option (A) $48\%$ naively adds $28\% + 20\%$.

#### Q15 Solution
- **Correct Option:** **(B) -- `8,000`**
- **Mathematical Proof:**
  - Total failing in at least one subject $= 40\% + 35\% - 15\% = 60\%$.
  - Percentage passing in both subjects $= 100\% - 60\% = 40\%$.
  - $40\% \text{ of Total} = 3,200 \implies \text{Total} = \frac{3,200}{0.40} = 8,000$.
- **Distractor Analysis:**
  - Option (A) $7,500$ mistakenly evaluates pass rate as $45\%$.
