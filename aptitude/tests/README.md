## 1. Pedagogical Architecture & Diagnostic Function

Topic tests constitute **Layer 2** of the IIT Kanpur Placement Testing System. Unlike full mixed mocks (which test multi-domain cognitive switching and speed endurance), topic tests diagnose **granular mathematical and logical competency** within isolated functional modules.

```
+----------------------------------------------------------------------------------------------------+
|                               THE CAT-8 COGNITIVE DIAGNOSTIC ARCHITECTURE                          |
+--------------------------+------------------------------------------+------------------------------+
| Question Band            | Cognitive Objective                      | Target Evaluation Metric     |
+--------------------------+------------------------------------------+------------------------------+
| Q1 – Q3: Foundation      | Rapid baseline theorem recall            | Speed & arithmetic accuracy  |
| Q4 – Q7: Intermediate    | Standard two-step parametric modeling    | Multiplier & formula balance |
| Q8 – Q10: Hard           | Constraint coupling & multi-variable AP  | Algebraic simplification     |
| Q11 – Q12: Very Hard     | Inverse systems & recursive boundaries   | Advanced analytical depth    |
| Q13 – Q14: Expert        | Non-linear distributions & Bayes priors  | Mathematical rigor           |
| Q15: Trap / Multi-Concept| Deceptive distractors & unit inversions  | Attentiveness & precision    |
+--------------------------+------------------------------------------+------------------------------+
```
