# ⚡ Aptitude Rapid Revision

> Final 1–3 day revision. Must-know formulas, shortcuts, traps, common question types, and solving strategy for each major area.

---

## 1. Quantitative Aptitude

### Percentages
- **Must-know:** Fraction↔% table (1/2=50%, 1/3=33.3%, 1/4=25%, 1/5=20%, 1/8=12.5%, 1/10=10%)
- **Shortcut:** Successive change `a+b+ab/100`
- **Trap:** Base value changes — "more than" vs "less than" use different denominators
- **Common Q:** Product stability, election votes, population growth

### Ratio & Proportion
- **Must-know:** `a:b=c:d ⟹ ad=bc`
- **Shortcut:** Partnership split by `Capital×Time`
- **Trap:** Ratio vs actual value — always find the unit value
- **Common Q:** Divide amount in ratio, partnership profit

### Averages
- **Must-know:** Average = Sum/Count
- **Shortcut:** AP average = `(first+last)/2`
- **Trap:** Weighted average when groups have different sizes
- **Common Q:** Average of series, alligation

### Profit, Loss & Discount
- **Must-know:** Profit% = `(SP-CP)/CP × 100`
- **Shortcut:** Successive discounts `d₁+d₂-d₁d₂/100`
- **Trap:** Discount is on MP, not CP
- **Common Q:** Dishonest dealer, successive discounts

### Time & Work
- **Must-know:** Rate = 1/Time; combined = `xy/(x+y)`
- **Shortcut:** LCM method (total work = LCM of times)
- **Trap:** Pipes — outlet is negative work
- **Common Q:** A leaves early, pipes & cisterns

### Speed, Time & Distance
- **Must-know:** Speed = Distance/Time; km/h→m/s ×5/18
- **Shortcut:** Average speed (equal dist) = `2xy/(x+y)`
- **Trap:** Relative speed direction (add/subtract)
- **Common Q:** Train crossing, boats & streams

### Number System
- **Must-know:** Divisibility rules, unit digit cyclicity
- **Shortcut:** Number of factors `(a+1)(b+1)`
- **Trap:** 1 is neither prime nor composite
- **Common Q:** Remainders, factors, unit digits

## 2. Logical Reasoning

### Series
- **Strategy:** Check arithmetic → geometric → alternating → square/cube
- **Trap:** Two interleaved series hidden in one
- **Common Q:** Number series, letter series

### Seating Arrangement
- **Strategy:** Draw cases, place solid clues first
- **Trap:** Facing direction changes left/right
- **Common Q:** Linear, circular, two-row

### Coding-Decoding
- **Strategy:** Find the shift/pattern
- **Trap:** Reverse alphabet, position sums
- **Common Q:** Letter shift, number coding

### Blood Relations
- **Strategy:** Draw family tree, work backwards
- **Trap:** Maternal vs paternal side
- **Common Q:** Pointing problems, coded relations

### Direction Sense
- **Strategy:** Track turns, use Pythagoras for distance
- **Trap:** Left/right flips when facing south
- **Common Q:** Path tracing, shortest distance

### Syllogism
- **Strategy:** Draw all possible Venn diagrams
- **Trap:** "Some" vs "All" vs "No" — check all diagrams
- **Common Q:** Definite vs possible conclusions

---

## 3. Data Interpretation

- **Strategy:** Read the question, identify what's asked, approximate
- **Shortcut:** Percentage = Part/Total × 100
- **Trap:** Units (thousands, lakhs, %) — read the axis labels
- **Common Q:** Growth rate, ratio comparison, pie chart angles

---

## 4. Verbal Ability

### Reading Comprehension
- **Strategy:** Read the passage, identify main idea, answer inference carefully
- **Trap:** Options that are too broad/narrow, or copied directly
- **Common Q:** Main idea, inference, tone

### Grammar
- **Must-know:** Subject-verb agreement, tense consistency
- **Trap:** Singular/plural mismatch, pronoun reference
- **Common Q:** Error spotting, sentence correction

---

## 5. Solving Strategy (Test Day)

1. **Scan the paper** — identify easy questions first
2. **Question selection** — skip anything you can't solve in 90 sec
3. **Approximation** — estimate before calculating
4. **Elimination** — rule out obviously wrong options
5. **Time allocation** — spend time where marks are easiest
6. **Accuracy first** — never rush easy questions
