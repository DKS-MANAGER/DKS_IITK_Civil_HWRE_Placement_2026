## 1. Mathematical & Theoretical Framework

### 1.1 The Epistemology of Quantitative Caselets
Unlike traditional table or chart DI where data is pre-tabulated, **Quantitative Caselets** present data as unstructured narrative prose. The candidate's primary task is **algebraic information extraction**: formalizing word statements into simultaneous equations, Venn set partitions, or matrix arrays before executing computations.

```
+-----------------------------------------------------------------------------------+
|                     THE 4-STAGE CASELET DECONSTRUCTION PIPELINE                   |
+-----------------------------------------------------------------------------------+
| Stage 1: Anchor Identification | Locate explicit global constants (e.g., Total N) |
| Stage 2: Structural Mapping    | Choose tool: Venn diagram, grid matrix, or tree  |
| Stage 3: Algebraic Modeling    | Translate "x exceeds y by k" into $x - y = k$    |
| Stage 4: Closed-Form Infill    | Solve simultaneous equations; populate grid      |
+-----------------------------------------------------------------------------------+
```

### 1.2 Core Mathematical Formulations

#### 1. The 3-Set Venn Partition Formulation
When data describes elements belonging to three overlapping groups $A, B,$ and $C$:
$$|A \cup B \cup C| = s_1 + s_2 + s_3 + n_{\text{none}}$$
Where:
- $s_1 = |A_{\text{only}}| + |B_{\text{only}}| + |C_{\text{only}}|$ (exactly one)
- $s_2 = |(A \cap B)_{\text{only}}| + |(B \cap C)_{\text{only}}| + |(C \cap A)_{\text{only}}|$ (exactly two)
- $s_3 = |A \cap B \cap C|$ (all three)
- Singletons: $\sum |A| = s_1 + 2s_2 + 3s_3$

#### 2. Multi-Tier Markup & Cascade Discounting
$$\text{Marked Price (MP)} = \text{Cost Price (CP)} \times (1 + m)$$
$$\text{Selling Price (SP)} = \text{MP} \times (1 - d_1) \times (1 - d_2)$$
$$\text{Net Profit Margin} = \frac{\text{SP} - \text{CP}}{\text{CP}} \times 100\%$$

## 5. Rapid Revision & Strategic Exam Traps

```
+-----------------------------------------------------------------------------------+
|                        TOP 5 QUANTITATIVE CASELET EXAM TRAPS                      |
+-----------------------------------------------------------------------------------+
| 1. The "Only" vs. "Total Set" Inclusion Ambiguity:                                |
|    Never add Venn cardinalities directly! Always subtract overlapping subsets to |
|    isolate mutually exclusive components before computing totals.                 |
|-----------------------------------------------------------------------------------|
| 2. Base Shifting in Compounded Discounts:                                         |
|    Successive discounts of 20% and 10% do NOT equal a 30% discount! Total discount   |
|    equals $1 - (0.80 \times 0.90) = 1 - 0.72 = 28\%$.                             |
|-----------------------------------------------------------------------------------|
| 3. Unspecified Set Universe Exclusions:                                           |
|    Always check whether the problem specifies that every person belongs to at     |
|    least one group, or if a non-participant subset $n_{\text{none}}$ exists!      |
|-----------------------------------------------------------------------------------|
| 4. Percentage Points vs. Relative Percentage Movement:                            |
|    A shift from 40% to 50% is +10 percentage points, but a +25% relative increase!|
|-----------------------------------------------------------------------------------|
| 5. Flow Conservation Invariants:                                                  |
|    In multi-stage transformation models (refining, chemical processing), check that|
|    Input Mass = Output Mass + Process Shrinkage Loss!                             |
+-----------------------------------------------------------------------------------+
```
