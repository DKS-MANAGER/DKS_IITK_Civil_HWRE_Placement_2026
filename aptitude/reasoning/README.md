## 1. Curriculum Architecture & Directory Map

The Logical Reasoning suite trains candidates in algorithmic deduction, relational constraints, conditional elimination, and pattern extraction required for campus placement screening tests (Consulting, High-Frequency Trading, Analytics, Software Engineering, and Core Engineering Leadership).

```
aptitude/reasoning/
├── README.md                      # Master Curriculum Map & Diagnostic Matrix (This file)
├── seating-arrangement.md         # Linear, circular, rectangular, bidirectional facing, and multi-attribute arrangements
├── puzzles-scheduling.md          # Multi-variable floor puzzles, day/month scheduling, and priority matrices
├── syllogism.md                   # Venn-diagram analytics, 'only a few', possibility cases, and reverse syllogisms
├── blood-relations.md             # Coded relations, family trees, generational mapping, and relational deductions
├── coding-decoding.md             # Alphabet-to-number shift, symbol substitution, matrix coding, and algorithmic logic
├── direction-sense.md             # Cardinal trajectories, shadow projections, shortest path vectors, and angular turns
├── order-ranking.md               # Linear ranking, overlapping positions, maximum/minimum capacity, and sequence logic
├── series.md                      # Number, letter, alpha-numeric patterns, difference-of-differences, and alternating series
├── input-output.md                # Machine step rearrangements, shifting words/numbers, and algorithmic batch operations
└── clocks-calendars.md            # Coinciding/orthogonal clock hands, faulty clocks, leap year drift, and reference days
```
