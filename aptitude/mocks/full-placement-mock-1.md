**Read the passage for Q41–Q45.**

The rapid urbanization of developing nations has exposed a critical gap between infrastructure demand and delivery capacity. By 2030, an estimated 60% of the global population will reside in urban areas, yet the infrastructure pipelines of most developing cities are designed for populations half that size. This mismatch manifests not only in overcrowded transportation networks and inadequate water supply systems but also in the subtler erosion of urban livability — longer commute times, deteriorating air quality, and the progressive displacement of low-income communities to the periphery. Engineering solutions alone cannot bridge this gap; what is required is an integrated approach that combines civil engineering innovation with policy reform, community engagement, and sustainable financing models. The challenge is not merely technical — it is fundamentally a question of political will and equitable resource allocation.

## SOLUTIONS

### Section A — Quantitative
1. 12.5% = 1/8; 800/8 = **100**. → C
2. 30 / 30 = **1 hour**. → A
3. 20 × 5 = **100**. → D
4. 1.40 × 0.90 = 1.26 ⇒ **26%**. → B
5. 15·20 / 35 = 300/35 = **8.57 days**. → A
6. a : b = 6 : 10, b : c = 10 : 15 ⇒ a : c = 6 : 15 = **2 : 5**. → D
7. 150 / 15 = 10 m/s = 10 × 18/5 = **36 km/h**. → B
8. 20 / (100 + 20) = 20/120 = **16.67%**. → C
9. 1/B = 1/12 − 1/18 = 1/36 ⇒ B = **36 days**. → A
10. Relative speed 90 km/h = 25 m/s; distance 220 m; 220/25 = **8.8 s**. → D
11. Sells 1000 g for the price of 900 g: 100/900 = **11.11%**. → C
12. x × 1.2 × 0.8 = 0.96x = 96 ⇒ x = **100**. → B
13. 5000[(1.1)² − 1] = 5000 × 0.21 = **1050**. → A
14. 3⁵⁰: cycle (3,9,7,1), 50 mod 4 = 2 ⇒ 9. 7⁵⁰: cycle (7,9,3,1) ⇒ 9. 9 + 9 = 18 ⇒ unit digit **8**. → C
15. 62% − 38% = 24% = 7200 ⇒ total = 7200 / 0.24 = **30000**. → B

### Section B — Reasoning
16. Arithmetic +4 ⇒ **19**. → A
17. A, B, C are siblings; C is D's father ⇒ A is D's **uncle**. → B
18. √(5² + 4²) = √41 ≈ **6.4 km**. → B
19. Differences 3, 5, 7, 9; next +11 ⇒ 26 + 11 = **37**. → C
20. T + I + G + E + R = 20 + 9 + 7 + 5 + 18 = **59**. → A
21. Pairs with equal word-gap and alphabet-gap: PO (gap 1) and DE (gap 1) ⇒ **2**. → B
22. Substitute: 12 ÷ 3 + 5 − 2 = 4 + 5 − 2 = **7**. → D
23. A = 1, C = 2, B = 3, E = 4, D = 5 ⇒ middle (3rd) = **B**. → A
24. Circle of 6: P = 1, S = 4, Q = 2, R = 6, T (opposite Q) = 5 ⇒ U = 3 = opposite R. → B
25. Some cats are dogs + all dogs are birds ⇒ **some cats are birds** (conclusion 1). → A
26. Fibonacci: 5 + 8 = **13**. → D
27. N 3, E 4, S 3 (net N–S = 0), W 1 (net E–W = 3) ⇒ distance **3 km**. → B
28. Rule ×2 + 1: 5, 11, 23, 47, **95**, 191 — so 94 is wrong. → C
29. Opposite = +4 seats. Q = P − 2; R = Q + 4 = P + 2; S = P + 4. 2nd right of S = S + 2 = P + 6 = P − 2 = **Q**. → A
30. C = 6, A = 2, B = 4 ⇒ sum = **12**. → C

### Section C — Data Interpretation
Row totals: A = 650, B = 410, C = 690, D = 335, E = 490. Column totals: Q1 590, Q2 635, Q3 660, Q4 690.
31. C = 690 is the highest. → C
32. (200 − 120)/120 = **66.67%**. → A
33. Q4 total 690 is the highest. → D
34. 200 : 130 = **20 : 13**. → A
35. C: 200 → 180 → 160 → 150 — declining every quarter (E rises Q1→Q2). → C
36. 20% of 50 = **10 ML**. → B
37. 15% of 360° = **54°**. → B
38. 45 : 20 = **9 : 4**. → A
39. 20% of 45 = 9; split ⇒ +4.5 to Agriculture: 15 + 4.5 = **19.5%**. → B
40. 45% of 60 = 27; 45% of 50 = 22.5; increase = **4.5 ML**. → D

### Section D — Verbal
41. The thesis is the "integrated approach … beyond engineering." → C
42. "Subtler" = less obvious but still real. → B
43. Directly supported: technical solutions must be complemented by policy/social reform. → A
44. Crime rates are never mentioned. → D
45. Concerned and pressing, not neutral or hopeless: analytically urgent. → B
46. "Neither … nor" — verb agrees with the nearer subject "students" (plural) ⇒ "were". → A
47. Mitigate = alleviate = lessen. → C
48. Warning → ignored → collapse → investigation: 2-3-1-4. → C
49. "Despite … kind" needs a contrasting look ⇒ "rugged". → D
50. Redundant = superfluous; opposite = essential. → A
