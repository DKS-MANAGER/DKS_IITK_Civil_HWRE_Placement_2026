# 🎯 Aptitude System

> A complete **learn → understand → solve → time → test → analyse → improve → repeat** system for placement aptitude screening across ALL roles (Core Civil, HWRE, CFD, Consulting, Product, Analytics, Data, Software, Finance, Operations, General Management).

Aptitude is the **common screening layer** for every placement role. This system treats it as a first-class component — not just a list of topics.

## 🔁 The Aptitude Loop

```
LEARN → UNDERSTAND → SOLVE → TIME → TEST → ANALYSE → IMPROVE → REPEAT
```

1. **LEARN** — read the topic module (concepts + formulas)
2. **UNDERSTAND** — study the worked examples
3. **SOLVE** — attempt practice questions (basic → advanced)
4. **TIME** — solve timed questions under pressure
5. **TEST** — take the topic test / mock
6. **ANALYSE** — log errors in [ERROR_LOG.md](ERROR_LOG.md)
7. **IMPROVE** — reattempt wrong questions (1/3/7 days)
8. **REPEAT** — move to next topic
