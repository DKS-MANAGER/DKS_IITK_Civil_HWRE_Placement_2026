# 📓 Aptitude Error Log

> Track every mistake to identify patterns and fix them.
> Reattempt wrong questions after **1 day, 3 days, 7 days**.

---

## Error Types

| Type | Meaning |
|:-----|:--------|
| **Conceptual** | Don't understand the underlying concept |
| **Calculation** | Understood but made an arithmetic error |
| **Misread** | Read the question wrong |
| **Formula** | Used the wrong formula |
| **Time pressure** | Knew it but ran out of time |
| **Guessing** | Random guess |
| **Question selection** | Spent too long on a hard question |

---

## How to Use

1. After every test/practice set, log each wrong question.
2. Identify the **error type** and **cause**.
3. Write the **correct method**.
4. Set a **reattempt date** (1/3/7 days).
5. Reattempt and mark ✅/❌.

## Diagnosis Framework

Use this to identify *what kind* of intervention you need:

| Symptom | Diagnosis | Intervention |
|:--------|:----------|:-------------|
| "I know the topic but take too long" | Speed/calculation weakness | Timed practice, shortcuts, approximation |
| "I don't understand the concept" | Conceptual weakness | Re-study the topic module |
| "I keep making arithmetic errors" | Calculation weakness | Slow down, verify, practice mental math |
| "I pick the wrong questions" | Question-selection weakness | Practice scanning + skipping in timed sets |
| "I run out of time" | Time management | Mock tests + time allocation strategy |
