# Resume & CV Guide

## Resume Structure

### For Civil Engineering Roles (Core)

**Header**
```
[Your Name]
[Phone Number] | [Email Address] | [LinkedIn/GitHub/Portfolio]
[City, State] | [Optional: Personal website/website]
```

**Education**
```
Degree Name, Major | University Name, City, State
Month Year – Month Year (Expected/Passed)
- CGPA: X.XX/10.00 (or equivalent)
- Relevant coursework: [List 3-5 key subjects]
- Academic achievements: [Awards, scholarships, distinctions]
```

**Technical Skills**
```
Programming Languages: Python, MATLAB, C++, SQL
Software: AutoCAD, Revit, ETABS, SAP2000, OpenFOAM, HEC-RAS
Tools: Git, LaTeX, MS Office (Advanced Excel, Power BI)
```

**Experience**
```
Job Title | Company Name, City, State
Month Year – Month Year
- Led/Responsible for [action] which resulted in [quantified outcome]
- Developed/Implemented [project/tool] using [technology] for [purpose]
- [Action verb] + [what you did] + [result/achievement]
```

**Projects**
```
Project Title | Technologies Used
- Brief 1-2 line description of the problem and solution
- Key contribution: [specific technical work]
- Outcome: [quantified if possible]
```

**Certifications & Training**
```
[Certification Name], [Issuing Organization], [Date]
- Relevant coursework/skills gained
```

**Achievements & Activities**
```
[Award/Recognition Name], [Organization], [Year]
- Brief description of significance
```

### For Analytics/Tech Roles (Transition)

**Header** (same as above)

**Education**
```
Same structure, emphasize relevant coursework:
- Data Structures & Algorithms
- Probability & Statistics
- Machine Learning
- Database Systems
- Numerical Methods
```

**Technical Skills**
```
Languages: Python, R, SQL, JavaScript
Libraries/Frameworks: NumPy, Pandas, Matplotlib, Scikit-learn, TensorFlow
Analytics Tools: Excel (Advanced), Tableau, Power BI
Software: MATLAB, Git, LaTeX, Jupyter Notebook
Civil Engineering Tools: AutoCAD, Revit, ETABS, SAP2000, OpenFOAM (relevant for HWRE transition)
```

**Projects**
```
Prioritize analytics/data projects. Include 1-2 civil engineering projects with data/analytics components.
Example format:

Project Title | Python, Pandas, Scikit-learn
- Problem: [Brief description of business/engineering problem]
- Solution: [Approached with data analysis/ML techniques]
- Result: [Quantified impact or key finding]
```

**Experience**
```
Use same structure but emphasize:
- Data-driven decision making
- Process improvement with metrics
- Cross-functional collaboration
- Technical problem-solving
```

**Internships**
```
Include any research, internships, or collaborations that involved:
- Data analysis or modeling
- Programming or automation
- Technical writing or documentation
```

## Resume Writing Tips

### Content Guidelines
1. **One page** for <10 years experience; two pages maximum
2. **Use action verbs**: Led, developed, designed, implemented, optimized, analyzed
3. **Quantify achievements**: "reduced" by X%, "improved" by Y seconds, "increased" by Z
4. **Tailor each resume** to specific job description
5. **Use keywords** from the job posting (ATS optimization)

### Formatting Guidelines
1. **Consistent formatting**: Same style for all entries
2. **Clear hierarchy**: Bold headings, consistent fonts (10-12pt)
3. **Bullet points**: 4-6 per section, each 1-2 lines
4. **White space**: Good balance, not cramped
5. **No photos, age, marital status, religion** (for Indian applications)

### Action Verbs by Category

| Technical | Leadership | Communication |
|-----------|------------|---------------|
| Developed | Led | Presented |
| Designed | Managed | Authored |
| Implemented | Mentored | Negotiated |
| Optimized | Coordinated | Facilitated |
| Analyzed | Directed | Collaborated |
| Engineered | Supervised | Published |
| Modeled | Influenced | Communicated |
| Programmed | Organized | Consulted |

## CV Structure (Academia/Further Studies)

### Extended Education History
```
Detailed CV with:
1. Personal Statement/Research Interests
2. Full Education History (with thesis titles)
3. Publications & Conference Papers
4. Research Experience
5. Teaching Experience
6. Presentations & Talks
7. Awards & Honors
8. Professional Memberships
9. References (with details)
```

## LinkedIn Profile Optimization

1. **Profile photo**: Professional headshot
2. **Headline**: "[Your role] | [Key skills] | [Value proposition]"
3. **About section**: 2-3 paragraph summary of experience and goals
4. **Featured section**: Add portfolio, GitHub, key projects
5. **Experience**: Same quantification approach as resume
6. **Skills**: Endorsements from colleagues or supervisors
7. **Activity**: Share articles, comment on industry news

## Portfolio Website (Optional)

For analytics/tech roles:
1. **Projects page**: Detailed write-ups with code links
2. **Blog section**: Write about problems you've solved
3. **Resume/CV download**: PDF version
4. **Contact information**: Easy to find

## Common Resume Mistakes

1. ✗ Using first person ("I", "me", "my")
2. ✗ Irrelevant work experience (part-time jobs in unrelated fields)
3. ✗ Generic descriptions without quantification
4. ✗ Typos and grammatical errors
5. ✗ Inconsistent date formats or margins
6. ✗ Including high school education if graduated college
7. ✗ Using creative fonts or colors (not ATS-friendly)
8. ✗ Listing too many technologies without proficiency level

## Resume Review Checklist

Before submitting:
- [ ] One page (or two pages max with 10+ years experience)
- [ ] Contact information is current and correct
- [ ] No typos or grammatical errors
- [ ] All dates in consistent format (Month Year - Month Year)
- [ ] Every bullet point uses action verb + quantified result
- [ ] Keywords from job description included
- [ ] Relevant coursework/projects highlighted for career changers
- [ ] No personal information (age, photo, marital status) on resume
- [ ] File saved as PDF with professional filename
