# Placement Roadmap

## Purpose

This roadmap translates the IIT Kanpur Civil/HWRE preparation plan into a phased timeline from August 2026 through December 2026. It aligns technical depth, behavioral readiness, and company-specific execution so that progress can be tracked, audited, and repeated.

## Phased Timeline

### Phase 0: Bootstrap (Aug 21 – Sep 7) — Priority P0

| Focus | Deliverable | Evidence |
|---|---|---|
| Repository bootstrap, syllabus map, resume/CV audit, self onboarding | `/resumes` templates, folder taxonomy, issue labels | Self-reviewed resumes, taxonomy signed off |
| Execution targets | Core, HWRE, PSU, Analytics skill matrices | Completed target checklist |

**Actions:**
- Finalize resume in both single-page and detailed formats.
- Map each core topic to a source and owner.
- Set up weekly self-study cadence and mock-interview schedule.

---

### Phase 1: Core Revision (Sep 8 – Sep 30) — Priority P0

| Focus | Deliverable | Evidence |
|---|---|---|
| Fluid mechanics, turbulence, hydraulics, hydrology, SOM, geotech | Topic notes in `/civil`, formula sheets, derivation logs | Closed-book oral tests, derivation logs |

**Actions:**
- Complete topic notes for Bernoulli, continuity, momentum, dimensional analysis, and pipe friction.
- Build turbulence modeling notes: RANS closures (k-ε, k-ω, SST), wall functions, y+.
- Finish hydrology notes: unit hydrograph, flood routing, hydrograph separation.
- Practice 3–5 numericals daily from each sub-topic.

**Milestone Rubric:**
- Core concept recall: 90%+ active recall
- Numerical speed: 15–20 minutes per problem

---

### Phase 2: Mock Interviews & Coding (Oct 1 – Oct 20) — Priority P0

| Focus | Deliverable | Evidence |
|---|---|---|
| Mock interviews, viva-style grilling, design-code numericals, coding drills | `/mock-interviews`, answer bank, error log | PR-linked transcripts, 8+ mocks per company track |

**Actions:**
- Run paired mock interviews twice weekly; rotate interviewer and interviewee roles.
- Build a behavioral answer bank with STAR/CAR stories for leadership, teamwork, failure, and conflict.
- Complete coding drills: 3–5 scripts/week (Python/MATLAB) on Git.
- Practice design-code numericals: IS code checks, load combinations, concrete mix design.

**Milestone Rubric:**
- Coding fluency: 3–5 scripts/week
- Mock readiness: 8+ mocks/company track

---

### Phase 3: Company-Wise Prep (Oct 21 – Nov 10) — Priority P1

| Focus | Deliverable | Evidence |
|---|---|---|
| PSUs, core design/consulting, analytics, shortlists | PRs in `/company-profiles`, role matrices | Updated profile files, shortlist probability matrix |

**Actions:**
- Draft company profiles for target firms: BPCL, EIL, L&T, AECOM, Tata Projects.
- Prepare technical question banks per company based on past interview themes.
- Practice GD and HR mock rounds for PSUs and analytics firms.
- Finalize shortlist strategy: apply to 2–3 PSUs, 2–3 core firms, 1–2 analytics roles.

---

### Phase 4: Final Revision (Nov 11 – Dec 1) — Priority P0

| Focus | Deliverable | Evidence |
|---|---|---|
| Rapid recall, GD/HR, aptitude, case-study reps | Consolidated cheat-sheets, flashcards, mock scores | Completed flashcard deck, final mock score report |

**Actions:**
- Create one-page cheat-sheets per core topic.
- Drill aptitude daily (20–30 min) and SQL/Python (20 min).
- Conduct final round mocks: technical, HR, and case-study reps.
- Review interview-experience logs and fill knowledge gaps.

**Milestone Rubric:**
- Rapid recall: 90%+ on flashcard deck
- GD/HR readiness: 5+ mocks completed

---

### Phase 5: Live Interviews & Postmortems (Dec 2026) — Priority P0

| Focus | Deliverable | Evidence |
|---|---|---|
| Live interview logging, offer tracking, postmortems, referral notes | `/interview-experiences` updated in real time | Real-time logs, offer tracking sheet |

**Actions:**
- Log each interview within 48 hours: exact questions, answers, gaps, and postmortem.
- Track offers, deadlines, and referral notes in a shared spreadsheet.
- Conduct debrief sessions after every interview to refine preparation for the next.

---

## Execution Targets

- **Core:** Fluency in derivations, assumptions, scaling laws, code-level design checks, and model limitations.
- **HWRE:** CFD fundamentals, OpenFOAM case logic, RANS/LES selection, open-channel flow, hydrology, sediment transport, and scour.
- **PSUs:** GATE-adjacent technical recall, IS code familiarity, project/site awareness, and HR/GK.
- **Analytics:** Python, SQL, probability, statistics, data structures, optimization, and business framing.

## Milestone Rubric

| Metric | Threshold | Evidence |
|---|---|---|
| Core concept recall | 90%+ active recall | Closed-book oral tests |
| Numerical speed | 15–20 min/problem | Timed worksheets |
| Coding fluency | 3–5 scripts/week | Git commits + notebooks |
| Mock readiness | 8+ mocks/company track | PR-linked transcripts |
| Interview depth | 2-layer answers minimum | Concept + application + caveat |
