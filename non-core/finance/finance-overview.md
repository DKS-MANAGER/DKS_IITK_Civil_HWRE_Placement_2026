## What Finance Roles Do

Finance roles in corporate/analyst settings involve analyzing financial data, supporting investment decisions, and managing budgets.

**Core responsibilities:**
- Financial analysis and modeling
- Valuation
- Budgeting and forecasting
- Reporting
- Cost analysis
- Investment decisions

| Task | Example | % of Time |
|:-----|:--------|:---------:|
| **Financial modeling** | "Build revenue forecast model" | 25% |

| **Reporting** | "Prepare monthly financial reports" | 20% |
| **Budgeting** | "Create annual budget" | 15% |
| **Decision support** | "Evaluate investment options" | 15% |

## Key Concepts & Formulas

### Income Statement
```
Revenue
- COGS
= Gross Profit
- Operating Expenses
= Operating Profit (EBIT)
- Interest
- Taxes
= Net Profit
```

### Balance Sheet
```
Assets = Liabilities + Equity
```

### Cash Flow
```
Free Cash Flow = Operating Cash Flow - Capital Expenditures
```

### Key Ratios

| Ratio | Formula | Meaning |
|:------|:--------|:--------|
| **Gross margin** | Gross Profit / Revenue | Production efficiency |
| **Operating margin** | EBIT / Revenue | Operating efficiency |
| **Net margin** | Net Profit / Revenue | Overall profitability |
| **Current ratio** | Current Assets / Current Liabilities | Liquidity |
| **Debt/Equity** | Total Debt / Equity | Leverage |
| **ROE** | Net Profit / Equity | Return to shareholders |
| **ROA** | Net Profit / Total Assets | Asset efficiency |

### Investment Metrics

| Metric | Formula | Decision Rule |
|:-------|:--------|:--------------|
| **NPV** | Σ(CFt / (1+r)^t) - Initial Investment | Accept if NPV > 0 |
| **IRR** | Rate where NPV = 0 | Accept if IRR > cost of capital |
| **ROI** | (Gain - Cost) / Cost × 100 | Higher is better |
| **Payback** | Initial Investment / Annual Cash Flow | Shorter is better |

## Numerical Problems

### Problem 1: NPV
**Prompt:** "Investment of ₹10 lakh. Cash flows: ₹4 lakh/year for 3 years. Discount rate 10%. Calculate NPV."

**Solution:**
- Year 1: 4,00,000 / 1.1 = 3,63,636
- Year 2: 4,00,000 / 1.21 = 3,30,579
- Year 3: 4,00,000 / 1.331 = 3,00,526
- Total PV = 9,94,741
- NPV = 9,94,741 - 10,00,000 = **-5,259** (Reject — slightly negative)

### Problem 2: Payback
**Prompt:** "Investment of ₹5 lakh. Annual cash flow ₹1.5 lakh. Calculate payback."

**Solution:**
Payback = 5,00,000 / 1,50,000 = **3.33 years**

### Problem 3: ROI
**Prompt:** "Invested ₹2 lakh, gained ₹2.5 lakh. Calculate ROI."

**Solution:**
ROI = (2,50,000 - 2,00,000) / 2,00,000 × 100 = **25%**

### Problem 4: Break-Even
**Prompt:** "Fixed costs ₹10 lakh. Price ₹500. Variable cost ₹300. Calculate break-even units."

**Solution:**
Break-even = 10,00,000 / (500 - 300) = **5,000 units**
