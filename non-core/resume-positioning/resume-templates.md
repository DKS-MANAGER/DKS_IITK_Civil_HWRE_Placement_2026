# Non-Core Resume Templates

> Role-specific resume guidance for Consulting, Analyst, Data Analyst, PM, Operations, and Generalist roles. Never invent achievements — reframe honestly.

---

## Universal Structure (1 Page)

```
[NAME]
[Phone] | [Email] | [LinkedIn] | [GitHub (if relevant)]

EDUCATION
IIT Kanpur — M.Tech/B.Tech Civil Engineering | GPA | Year

EXPERIENCE / INTERNSHIPS
Role — Company | Duration
• Bullet 1 (quantified)
• Bullet 2 (quantified)

PROJECTS / RESEARCH
Project Name — Context | Duration
• What you did → What resulted

SKILLS
Technical: [relevant tools]
Business: [relevant frameworks]

POSITIONS OF RESPONSIBILITY
Role — Organization | Duration
• Impact achieved
```

## Template 1: Consulting Resume

### Emphasize
- Structured problem solving
- Leadership and teamwork
- Quantitative analysis
- Communication

### Sample Bullets
- "Led 4-member team to analyze urban flood risk, developing a quantitative framework that identified 3 high-priority zones — presented to 50+ audience"
- "Structured and delivered open-ended research project, managing ambiguity and deriving insights from incomplete data"
- "Mentored [X] junior students, simplifying complex technical concepts"

### Reduce
- Technical jargon (RANS, FEM, PLAXIS)
- Software lists (OpenFOAM, SAP2000)
- Course details

## Template 2: Analyst Resume (BA)

### Emphasize
- SQL/Python skills
- Data analysis
- Dashboard/reporting
- Business communication

### Sample Bullets
- "Analyzed 50,000+ data points using SQL and Python to identify [insight], informing [decision]"
- "Built automated reporting dashboard reducing manual work by 60%"
- "Processed and cleaned [X] records, handling missing data and outliers"

### Reduce
- Purely theoretical work
- Engineering-specific methodologies

## Template 3: Data Analyst Resume

### Emphasize
- Python/Pandas
- Statistics
- Data visualization
- SQL

### Sample Bullets
- "Cleaned and analyzed 100,000+ data points using Python (Pandas, NumPy), identifying [insight] with statistical significance"
- "Built predictive model (R² = 0.87) to forecast [outcome], improving decision accuracy"
- "Designed and analyzed A/B test, determining [result] with statistical confidence"

### Reduce
- Non-data engineering work
- Unrelated coursework

## Template 4: Product Manager Resume

### Emphasize
- User/stakeholder understanding
- Cross-functional coordination
- Decision-making
- Outcomes and metrics

### Sample Bullets
- "Led cross-functional research project, defining requirements and coordinating 3 departments, delivering 2 weeks ahead of schedule"
- "Prioritized features based on user feedback and impact analysis, improving [metric] by X%"
- "Gathered requirements from [X] stakeholders, translating needs into actionable specifications"

### Reduce
- Technical implementation details
- Domain-specific methods

## Template 5: Operations Resume

- Process improvement

## Template 6: Generalist Resume

### Emphasize
- Balanced skills (analytical + communication + leadership)
- Transferable competencies
- Versatility

### Sample Bullets

- Overly technical content

## Bullet Writing Guide

### The Formula
```
[Action verb] + [What you did] + [Method/tool] + [Quantified result]
```

### Power Verbs

| Category | Verbs |
|:---------|:------|
| Analysis | Analyzed, Quantified, Evaluated, Modeled, Forecasted |
| Leadership | Led, Coordinated, Managed, Mentored |
| Improvement | Optimized, Streamlined, Reduced, Improved |
| Communication | Presented, Published, Trained, Simplified |
| Technical | Developed, Programmed, Automated, Designed |

### Weak vs. Strong Bullets

**Weak:** "Worked on a CFD project"
**Strong:** "Developed computational model simulating flood scenarios, reducing analysis time by 40%"

**Weak:** "Did data analysis"
**Strong:** "Analyzed 50,000+ data points using Python, identifying trends that informed [decision]"

**Weak:** "Led a team"
**Strong:** "Led 4-member team to deliver [project], coordinating schedules and resources to meet deadline"

---

## Honest Quantification

| If You Have | Use |
|:------------|:----|
| Real numbers | Use them (team size, data points, % improvement) |
| No hard numbers | "Significantly", "Substantially", "Consistently" |
| Approximate numbers | Round to a defensible figure |

**Never fabricate.** Interviewers probe resume claims. A fabricated metric is a career-ending risk.

## Resume Checklist

- [ ] 1 page maximum
- [ ] Contact info with LinkedIn
- [ ] Education with GPA (if > 7.0)
- [ ] 3-4 quantified bullets per role/project
- [ ] Skills tailored to target role
- [ ] No Civil jargon without business translation
- [ ] Every bullet starts with a power verb
- [ ] No spelling/grammar errors
- [ ] Consistent formatting
- [ ] PDF format
