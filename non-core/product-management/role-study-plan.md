# Product Manager — Study Plan

> 4-week preparation roadmap for civil/M.Tech students targeting PM roles at tech companies.

---

## Role Overview

**What PMs do:** Define what gets built, why, and for whom. Own the product vision, roadmap, and cross-functional coordination.

**Day-to-day:** User research, prioritization, stakeholder alignment, metrics tracking, spec writing, launch coordination.

**Civil/M.Tech advantage:** Project management from thesis/capstone, user-centric thinking from lab/stakeholder work, technical depth for engineering coordination.

**Target companies:** Abacus.AI, Merilytics, startup PM roles, tech-adjacent PM at infrastructure companies (L&T Digital, Tata Projects).

## Topic 1: Product Sense (User → Need → Solution)

### Why This Matters
Product sense is the #1 thing PM interviewers test. It determines whether you can think from the user's perspective and translate needs into solutions.

### What to Learn
- [ ] User → Need → Solution framework
- [ ] "Design X" question structure (Clarify → User → Need → Solution → Metrics)
- [ ] "Improve X" question structure (Current State → Areas → Prioritize → Solution → Metrics)
- [ ] MVP definition and trade-offs
- [ ] How to identify user segments

### Study Material
| Topic | File | Depth |
|:------|:-----|:------|
| Product Sense Framework | [product-sense.md](product-sense.md) | Full framework + 3 worked examples |
| Product Overview | [pm-overview.md](pm-overview.md) | Role context + question bank |

### Worked Example
> **"Design a mobile app for college students to find study groups."**
>
> Structure: Clarify (30s) → User (1min) → Need (1min) → Solution (2min: MVP features + differentiation) → Metrics (1min: North Star + supporting + guardrail) → Recommendation (30s)
>
> → Full walkthrough in [product-sense.md](product-sense.md)

### Practice
- [ ] Basic: 3 "Design X" questions (design a feature for elderly users, design a food delivery improvement, design a study tool)
- [ ] Intermediate: 3 "Improve X" questions (improve WhatsApp, improve YouTube, improve IRCTC)
- [ ] Interview-level: 5 timed practice sessions (6 min each)

### Interview Questions
1. Design a product for college students to manage assignments. — *Tests: user empathy, feature prioritization*
2. How would you improve Google Maps for Indian users? — *Tests: localization thinking, improvement framework*
3. Design a feature for a fitness app that increases retention. — *Tests: metrics-driven design*
4. What would you add to Swiggy's delivery experience? — *Tests: end-to-end user journey*
5. Design a product for construction site safety monitoring. — *Tests: civil domain advantage*

### Completion Criterion
- [ ] Can explain User → Need → Solution framework in 30 seconds
- [ ] Can structure a "Design X" answer in 6 minutes
- [ ] Can identify 3 user segments for any product
- [ ] Can propose MVP features with clear trade-offs
- [ ] Can answer 5 product sense questions confidently

## Topic 2: Product Metrics & Analytics

### Why This Matters
20% of PM interview weight. Every PM must understand what metrics to track, how to diagnose metric changes, and how to define success.

### What to Learn
- [ ] North Star Metric concept
- [ ] Metric hierarchy: Acquisition → Activation → Retention → Revenue → Referral (AARRR)
- [ ] Key metrics by product type (social, e-commerce, SaaS, content, marketplace)
- [ ] Funnel analysis
- [ ] Retention & cohort analysis
- [ ] DAU/MAU, stickiness, session length
- [ ] ARPU, LTV, CAC

### Study Material
| Topic | File | Depth |
|:------|:-----|:------|
| Metrics Deep Dive | [pm-metrics-strategy.md](pm-metrics-strategy.md) | Full metric taxonomy + formulas |
| Product Overview | [pm-overview.md](pm-overview.md) | Question bank + scenarios |

### Worked Example
> **"DAU dropped 15% last week. Diagnose."**
>
> Structure: Define DAU → Segment the drop (platform? region? new vs returning?) → Check external factors (outages, competitors) → Check internal factors (product changes, bugs) → Form hypothesis → Test → Validate
>
> → Full walkthrough in [pm-metrics-strategy.md](pm-metrics-strategy.md)

### Practice
- [ ] Basic: Define North Star metrics for 5 products (Instagram, Uber, Zomato, Notion, LinkedIn)
- [ ] Intermediate: Diagnose 3 metric drops (DAU drop, conversion drop, retention drop)
- [ ] Interview-level: 5 timed metric questions (3 min each)

### Interview Questions
1. What's the North Star metric for Amazon? Why? — *Tests: metric selection reasoning*
2. DAU dropped 15%. How do you investigate? — *Tests: structured diagnosis*
3. Conversion improved 2% but revenue dropped. What happened? — *Tests: metric interaction understanding*
4. How would you measure success for a new feature? — *Tests: metric design*
5. What metrics would you track for a construction project management app? — *Tests: civil domain + metrics*

### Completion Criterion
- [ ] Can name North Star metrics for 10 different products
- [ ] Can diagnose a metric drop in 3 minutes
- [ ] Can explain AARRR funnel with examples
- [ ] Can differentiate between vanity metrics and actionable metrics
- [ ] Can answer 5 metrics questions confidently

## Topic 3: Prioritization & Execution

### Why This Matters
15% of PM interview weight. PMs must make trade-off decisions under constraints.

### What to Learn
- [ ] RICE framework (Reach × Impact × Confidence / Effort)
- [ ] MoSCoW method (Must/Should/Could/Won't)
- [ ] ICE framework (Impact × Confidence × Ease)
- [ ] Impact vs. Effort matrix
- [ ] How to handle stakeholder conflicts
- [ ] MVP scoping and iteration

### Study Material
| Topic | File | Depth |
|:------|:-----|:------|
| Prioritization Frameworks | [pm-metrics-strategy.md](pm-metrics-strategy.md) | Strategy section |
| Execution Scenarios | [pm-overview.md](pm-overview.md) | Scenario questions |

### Worked Example
> **"You have 3 features and time for 1. Which do you build?"**
>
> Step 1: List all 3 with reach, impact, confidence, effort scores
> Step 2: Calculate RICE score for each
> Step 3: Consider strategic alignment and dependencies
> Step 4: Recommend the highest RICE score with reasoning
> Step 5: Propose timeline for the other 2

### Practice
- [ ] Basic: Apply RICE to 3 feature lists
- [ ] Intermediate: Prioritize features for a given product constraint
- [ ] Interview-level: 3 timed prioritization scenarios

### Interview Questions
1. You have resources for 1 of 3 features. Which do you choose? — *Tests: framework application*
2. A stakeholder insists on a feature you disagree with. What do you do? — *Tests: stakeholder management*
3. Your team is capacity-constrained. How do you prioritize? — *Tests: resource management*
4. How do you decide between building vs. buying? — *Tests: strategic thinking*
5. A feature shipped but nobody uses it. What's your process? — *Tests: iteration mindset*

### Completion Criterion
- [ ] Can apply RICE framework in 2 minutes
- [ ] Can handle stakeholder conflict scenarios
- [ ] Can explain MVP trade-offs clearly
- [ ] Can answer 3 prioritization questions confidently

## Topic 4: Product Strategy & Business Sense

### Why This Matters
20% of PM interview weight. PMs must understand markets, competition, and business models.

### What to Learn
- [ ] Market entry analysis
- [ ] Competitive analysis (Porter's Five Forces, positioning)
- [ ] Business model fundamentals (revenue models, unit economics)
- [ ] TAM/SAM/SOM
- [ ] Growth frameworks (AARRR, viral loops, network effects)

### Study Material
| Topic | File | Depth |
|:------|:-----|:------|
| Strategy Frameworks | [pm-metrics-strategy.md](pm-metrics-strategy.md) | Strategy section |
| Business Fundamentals | [business-fundamentals.md](../common/business-fundamentals.md) | Core business concepts |

### Worked Example
> **"Should Google enter the Indian education market?"**
>
> Structure: Market attractiveness (size, growth, competition) → Company fit (capabilities, brand) → Entry mode (organic, acquisition, partnership) → Financial viability → Recommendation

### Practice
- [ ] Basic: Analyze 3 market entry scenarios
- [ ] Intermediate: Build competitive analysis for 2 industries
- [ ] Interview-level: 2 timed strategy cases

### Interview Questions
1. Should Uber enter grocery delivery? — *Tests: market analysis*
2. How would you compete with Instagram Reels for a new short-video app? — *Tests: competitive thinking*
3. What's the biggest risk for Netflix in India? — *Tests: business judgment*
4. How would you price a new SaaS product? — *Tests: pricing strategy*
5. Should a construction company build a PM software product? — *Tests: civil domain + strategy*

### Completion Criterion
- [ ] Can structure a market entry analysis in 5 minutes
- [ ] Can explain 3 business models with examples
- [ ] Can answer 3 strategy questions confidently

## Rapid Revision

### Must-Memorize Frameworks
1. **User → Need → Solution** (Product Sense)
2. **AARRR** (Acquisition → Activation → Retention → Revenue → Referral)
3. **RICE** (Reach × Impact × Confidence / Effort)
4. **North Star Metric** (the one metric that captures core value)
5. **MVP** (Minimum Viable Product — smallest thing that tests hypothesis)

### Key Metrics Quick Reference
| Category | Metric | Formula |
|:---------|:-------|:--------|
| Engagement | DAU/MAU Stickiness | DAU ÷ MAU |
| Retention | Day N Retention | Active on Day N ÷ Active on Day 0 |
| Revenue | ARPU | Revenue ÷ Users |
| Growth | Viral Coefficient | Invites × Conversion Rate |
| Health | LTV/CAC Ratio | LTV ÷ CAC (target: >3) |

### Last-Minute Checklist (1 hour before interview)
- [ ] Reviewed User → Need → Solution framework
- [ ] Practiced 3 "Design X" questions out loud
- [ ] Reviewed metric taxonomy (AARRR + key metrics)
- [ ] Prepared 4 STAR stories (leadership, conflict, failure, success)
- [ ] Researched [company] recent product launches
- [ ] Reviewed company's product and noted 2 improvements
