# Non-Core Resume Guide

> How to write a resume for non-core roles from a Civil Engineering / M.Tech background. Never fabricate — reframe.

---

## Why Your Resume Needs Rethinking

A Civil Engineering resume emphasizes technical depth. A non-core resume must emphasize:
- **Transferable skills** (not just technical knowledge)
- **Impact and outcomes** (not just activities)
- **Business relevance** (not just academic rigor)
- **Breadth of thinking** (not just domain expertise)

---

## Universal Resume Rules

### Structure (1 Page Mandatory)

```
Name | Contact | LinkedIn | GitHub (if relevant)
─────────────────────────────────────────────────
EDUCATION
  IIT Kanpur — M.Tech/B.Tech Civil Engineering | GPA | Year
  
EXPERIENCE / INTERNSHIPS
  Role — Company | Duration
  • Achievement 1 (quantified)
  • Achievement 2 (quantified)
  • Achievement 3 (quantified)

PROJECTS / RESEARCH
  Project Name — Context | Duration
  • What you did → What resulted

SKILLS
  Technical: Python, SQL, MATLAB, Excel, [tools]
  Business: [relevant frameworks, analysis methods]
  
POSITIONS OF RESPONSIBILITY
  Role — Organization | Duration
  • Impact achieved
```

### Bullet Writing Formula

**Weak:** "Worked on CFD simulation project"
**Strong:** "Developed CFD model simulating flood scenarios, reducing computation time by 40% through mesh optimization"

**Formula:** Action verb + What you did + Method/tool + Quantified result

### Power Verbs by Category

| Category | Verbs |
|:---------|:------|
| Analysis | Analyzed, Quantified, Evaluated, Assessed, Modeled, Forecasted |
| Leadership | Led, Coordinated, Managed, Spearheaded, Facilitated, Mentored |
| Improvement | Optimized, Streamlined, Reduced, Increased, Improved, Enhanced |
| Communication | Presented, Published, Trained, Simplified, Documented, Reported |
| Technical | Developed, Programmed, Simulated, Automated, Designed, Built |

## Role-Specific Resume Emphasis

### Consulting Resume

**Emphasize:**
- Structured problem solving (thesis, research projects)
- Leadership and teamwork (organizational roles)
- Quantitative analysis (any data-driven work)
- Communication (presentations, publications, TA)

**Reduce:**
- Technical jargon (no one outside Civil knows what RANS means)
- Software lists (OpenFOAM, PLAXIS — not relevant unless reframed)
- Course details (no one cares about your hydraulics coursework)

**Bullet example:**
- "Led 4-member team to analyze urban flood risk, developing a quantitative framework that identified 3 high-priority zones — presented findings to 50+ audience"

### Analyst Resume (BA / DA)

**Emphasize:**
- Data analysis experience (any dataset you've worked with)
- Programming (Python, SQL, MATLAB → frame as data tools)
- Statistical methods used in research
- Visualization and reporting

**Reduce:**
- Purely theoretical work
- Engineering-specific methodologies

**Bullet example:**
- "Processed 50,000+ data points using Python (Pandas, NumPy) to identify sediment transport patterns, building predictive model with R² = 0.87"

### Product Manager Resume

**Emphasize:**
- User/stakeholder understanding (who benefited from your work?)
- Cross-functional coordination (who did you work with?)
- Decision-making and trade-offs
- Outcomes and metrics

**Bullet example:**
- "Coordinated research project across 3 departments, defining requirements, managing timeline, and delivering 2-week ahead of schedule"

### Operations Resume

**Emphasize:**
- Process improvement (any efficiency gains)
- Resource allocation and planning
- Quality management
- Site/facility management experience

**Bullet example:**
- "Optimized material procurement process for construction project, reducing waste by 15% and saving ₹2 lakhs through vendor negotiation"

### Finance Resume

**Emphasize:**
- Quantitative analysis
- Budget management (if any)
- Cost estimation experience
- Financial modeling (if learned)

**Bullet example:**
- "Estimated project costs for ₹50 lakh infrastructure project, tracking budget variance and identifying 10% cost savings through material substitution"

## How to Describe Technical Work in Business Language

| Technical Term | Business Translation |
|:---------------|:---------------------|
| CFD simulation | Quantitative modeling and analysis |
| Finite element analysis | Data-driven structural optimization |
| Mesh generation and refinement | Process optimization for computational efficiency |
| Turbulence modeling (k-ε) | Statistical modeling for complex systems |
| OpenFOAM / MATLAB | Python, data processing, automation tools |
| Thesis research | Independent problem-solving project with published outcomes |
| Lab experiments | Controlled testing and data collection methodology |
| GIS mapping | Spatial data analysis and visualization |
| Water quality monitoring | Data collection and quality assurance processes |
| Site visits | Field assessment and stakeholder engagement |
| Surveying | Data collection and precision measurement |

## Quantifying Legitimate Impact

You must quantify, but never fabricate. Use these legitimate quantifiers:

| What You Did | How to Quantify |
|:-------------|:----------------|
| Led a team | Team size, duration, outcome |
| Research project | Data points processed, methodology developed |
| Presentation | Audience size, feedback score |
| TA/teaching | Students taught, course improvement |
| Technical work | Time saved, accuracy improved, cost reduced |
| Organization | Members managed, events organized |
| Publication | Papers submitted/accepted, conference presentations |

### If You Genuinely Don't Have Numbers

- "Developed" → "Developed and validated"
- "Worked on" → "Contributed to completion of"
- "Assisted" → "Supported delivery of"
- Use relative terms: "significantly," "substantially," "consistently"

## Common Resume Mistakes for Civil → Non-Core

| Mistake | Fix |
|:--------|:----|
| Listing every Civil course | Only list courses relevant to the target role |
| Using only technical language | Translate to business language |
| Describing activities, not outcomes | Add result/impact to every bullet |
| Including irrelevant technical skills | Tailor skills section to role |
| No numbers anywhere | Add at least 2-3 quantified bullets |
| objective statement "Seeking a challenging role" | Remove entirely — use space for content |
| Listing "MS Office" as a skill | Only if you can demonstrate advanced use |
| Resume longer than 1 page | Cut ruthlessly — 1 page for campus placement |

---

## Resume Checklist

- [ ] 1 page maximum
- [ ] Contact info with LinkedIn
- [ ] Education with GPA (if > 7.0)
- [ ] 3-4 experience/project bullets with quantified impact
- [ ] Skills tailored to target role
- [ ] No Civil jargon without business translation
- [ ] Every bullet starts with a power verb
- [ ] No spelling/grammar errors
- [ ] Consistent formatting (fonts, spacing, alignment)
- [ ] PDF format (not Word)
