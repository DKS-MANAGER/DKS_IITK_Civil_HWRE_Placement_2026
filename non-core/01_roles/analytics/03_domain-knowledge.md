### 2. Sample Ratio Mismatch (SRM) Diagnosis
- **Test**: Chi-Square Goodness-of-Fit test on observed ($O$) vs expected ($E$) sample counts:
  $$\chi^2 = \sum rac{(O_i - E_i)^2}{E_i} \quad 	ext{with } df = 1$$
- If $p < 0.001$, significant SRM exists $\implies$ **test results are invalid** (selection bias caused by redirection latency, bot-filters, or hashing bugs).

### 3. Experimentation Traps
- **Peeking Problem**: Continuously monitoring test results and stopping early inflates false-positive rate from 5% to $>30\%$.
- **Novelty & Primacy Effects**: Users react to new UI purely due to curiosity (temporary lift) or initial confusion (temporary drop). Must run test for full weekly business cycles (minimum 14-21 days).
