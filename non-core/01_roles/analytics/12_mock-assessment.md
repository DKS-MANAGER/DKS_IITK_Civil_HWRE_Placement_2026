# 12. Analytics: Timed Mock Technical Assessment

> 90-minute timed test containing SQL querying, statistical inference, and a live metrics case study with full grading rubric.

---

## Section 1: SQL & Data Extraction (40 Marks)
1. Write a query calculating 7-day rolling average active users per region.
2. Write a query to detect user churn defined as zero transactions in the last 60 days following at least 3 historical transactions.

## Section 2: Experimentation & Statistics (30 Marks)
1. Calculate the required sample size for an A/B test with baseline conversion 5% and target relative lift 10% (MDE = 0.5%).
2. Explain how to detect Sample Ratio Mismatch (SRM) using a Chi-Square goodness-of-fit test.

## Section 3: Metric Case Study (30 Marks)
- Diagnose why user engagement increased while total transaction revenue dropped by 8%.
