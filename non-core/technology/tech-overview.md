## What "Tech-Adjacent" Means

Tech-adjacent roles use technology but aren't pure software engineering. They bridge technical and business teams. For Civil/M.Tech students, these are realistic, accessible paths.

**Accessible tech-adjacent roles:**
- Product Manager (tech companies)
- Business Analyst (tech companies)
- Data Analyst
- Technical Project Manager
- Solutions Engineer
- Analytics roles

**What you need (not a CS degree):**
- SQL and Python basics
- Understanding of how software is built
- Data literacy
- Product/analytics thinking

## Topic Checklist

### Must Know [P0]

- [ ] SQL: SELECT, JOIN, GROUP BY, window functions
- [ ] Python: Pandas, NumPy basics

### Agile / Scrum

| Concept | Meaning |
|:--------|:--------|
| **Sprint** | 2-4 week development cycle |
| **Backlog** | Prioritized list of work |
| **Stand-up** | Daily team sync |
| **Retrospective** | Post-sprint review |
| **Product Owner** | Represents user/business needs |
| **Scrum Master** | Facilitates the process |

### APIs (Application Programming Interfaces)

**What:** A way for software to talk to each other.
**Example:** A weather app calls a weather API to get data.
**Key idea:** APIs let you use functionality without knowing how it's built.

### Cloud Fundamentals

| Concept | Meaning |
|:--------|:--------|
| **IaaS** | Infrastructure (servers, storage) |
| **PaaS** | Platform (deploy apps) |
| **SaaS** | Software (use via browser) |

## Question Bank

### Basic
1. What is the difference between SQL and Python?
2. Explain what an API is.
3. What is a database?
4. Explain the difference between a primary key and a foreign key.
5. What is Agile development?

### Intermediate
6. Write a query to find top 5 products by revenue.
7. What's the difference between a relational and non-relational database?
8. Explain the software development lifecycle.
9. What is a REST API?
10. How do you handle a large dataset in Python?

### Advanced
11. A product metric fell. How do you investigate?
12. How would you design a database for an e-commerce site?
13. Explain the difference between on-premise and cloud.
14. How do you decide between building vs. buying software?
15. How do you translate technical requirements to business stakeholders?
