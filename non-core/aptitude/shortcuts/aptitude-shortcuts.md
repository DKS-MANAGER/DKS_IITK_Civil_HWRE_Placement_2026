## 🔢 1. Percentage Shortcuts

### Must-Know Fraction-Percentage Conversions

| Fraction | Percentage | | Fraction | Percentage |
|----------|-----------|-|----------|-----------|
| 1/2 | 50% | | 1/9 | 11.11% |
| 1/3 | 33.33% | | 1/10 | 10% |
| 1/4 | 25% | | 1/11 | 9.09% |
| 1/5 | 20% | | 1/12 | 8.33% |
| 1/6 | 16.67% | | 1/15 | 6.67% |
| 1/7 | 14.28% | | 1/20 | 5% |
| 1/8 | 12.5% | | 1/25 | 4% |

### Shortcut 1: Successive Percentage Change
If A changes by $a\%$ and B changes by $b\%$:
$$\text{Net change} = a + b + \frac{ab}{100}$$
**Example:** Price ↑ 20%, then ↓ 10% → Net = $20 - 10 + (20×(-10))/100 = 10 - 2 = 8\%$ increase

### Shortcut 2: Product Stability Rule
If $A \times B = C$ and A changes by $x\%$, B must change by:
$$\% \text{ change in B} = \frac{-x}{1 + x/100} \times 100$$
**Example:** If length ↑ 25%, breadth must ↓ 20% to keep area constant.

### Shortcut 3: Population Growth/Decay
$$\text{Final} = \text{Initial} \times \left(1 \pm \frac{r}{100}\right)^n$$
Growth: use $+$, Decay/Depreciation: use $-$

### Shortcut 4: Percentage to Fraction (Quick)
$37.5\% = 3/8$, $62.5\% = 5/8$, $87.5\% = 7/8$
$66.67\% = 2/3$, $14.28\% = 1/7$, $12.5\% = 1/8$

## ➕ 2. Number System Shortcuts

### Shortcut 5: Divisibility Rules

| Divisor | Rule |
|---------|------|
| 2 | Last digit even |
| 3 | Sum of digits divisible by 3 |
| 4 | Last 2 digits divisible by 4 |
| 5 | Last digit 0 or 5 |
| 6 | Divisible by both 2 and 3 |
| 8 | Last 3 digits divisible by 8 |
| 9 | Sum of digits divisible by 9 |
| 11 | Alternating sum of digits = 0 or ±11 |

### Shortcut 6: Unit Digit Cyclicity
- Digits 2, 3, 7, 8: cycle of 4
- Digits 4, 9: cycle of 2
- Digits 0, 1, 5, 6: always same digit
**Example:** $2^{123}$ → $123 \mod 4 = 3$ → unit digit = $2^3 = 8$

### Shortcut 7: Number of Factors
If $N = p_1^{a_1} \times p_2^{a_2} \times \ldots$
$$\text{Number of factors} = (a_1+1)(a_2+1)\ldots$$
**Example:** $360 = 2^3 \times 3^2 \times 5^1$ → factors = $(3+1)(2+1)(1+1) = 24$

## ⏱️ 3. Time, Speed & Distance Shortcuts

### Shortcut 8: Unit Conversion
- km/h → m/s: multiply by $5/18$
- m/s → km/h: multiply by $18/5$

### Shortcut 9: Relative Speed
- **Opposite direction:** Speeds add → $V_{rel} = V_1 + V_2$
- **Same direction:** Speeds subtract → $V_{rel} = V_1 - V_2$

### Shortcut 10: Average Speed
$$V_{avg} = \frac{2V_1V_2}{V_1 + V_2}$$ (for equal distances)
$$V_{avg} = \frac{V_1 + V_2}{2}$$ (for equal times)

### Shortcut 11: Train Crossing
- **Platform/building:** Time = $(L_{train} + L_{object}) / V_{train}$
- **Another train (opposite):** Time = $(L_1 + L_2) / (V_1 + V_2)$
- **Another train (same dir):** Time = $(L_1 + L_2) / |V_1 - V_2|$

### Shortcut 12: Boats & Streams
- **Downstream speed:** $V_{down} = V_{boat} + V_{stream}$
- **Upstream speed:** $V_{up} = V_{boat} - V_{stream}$
- **Speed in still water:** $V_{boat} = (V_{down} + V_{up})/2$
- **Stream speed:** $V_{stream} = (V_{down} - V_{up})/2$

## ⚙️ 4. Time & Work Shortcuts

### Shortcut 13: LCM Method
If A takes $a$ days and B takes $b$ days:
- Total work = LCM($a$, $b$) = $W$
- Efficiency of A = $W/a$, B = $W/b$
- Combined: $(W/a + W/b)$ per day
- Time together = $W / (W/a + W/b) = ab/(a+b)$

### Shortcut 14: Pipes & Cisterns
- Filling pipe rate = $1/x$ (fills in $x$ hours)
- Emptying pipe rate = $1/y$ (empties in $y$ hours)
- Both open: Net rate = $1/x - 1/y$
- Fill time = $xy/(y-x)$

### Shortcut 15: Chain Rule (Men-Women-Children-Days-Hours)
$$M_1 \times D_1 \times H_1 / W_1 = M_2 \times D_2 \times H_2 / W_2$$
Use when work capacity differs (e.g., men vs women vs children)

## 📐 5. Ratio & Proportion Shortcuts

### Shortcut 16: Componendo & Dividendo
If $a/b = c/d$:
$$\frac{a+b}{a-b} = \frac{c+d}{c-d}$$

### Shortcut 17: Partnership Profit Sharing
$$\text{Profit ratio} = \text{Capital}_1 \times \text{Time}_1 : \text{Capital}_2 \times \text{Time}_2$$

### Shortcut 18: Mean Proportional
If $a:x = x:b$ → $x = \sqrt{ab}$

### Shortcut 19: Alligation (Mixture)
$$\frac{\text{Quantity of cheaper}}{\text{Quantity of dearer}} = \frac{d - m}{m - c}$$
Where $c$ = cheaper price, $d$ = dearer price, $m$ = mean price

## 💰 6. Profit, Loss & Discount Shortcuts

### Shortcut 20: Successive Discounts
$$\text{Single equivalent} = d_1 + d_2 - \frac{d_1 d_2}{100}$$

### Shortcut 21: Profit/Loss on Cost
$$\text{Profit\%} = \frac{SP - CP}{CP} \times 100$$
$$\text{Loss\%} = \frac{CP - SP}{CP} \times 100$$

### Shortcut 22: Dishonest Dealer
$$\text{Gain\%} = \frac{\text{Error}}{\text{True value - Error}} \times 100$$

### Shortcut 23: Marked Price & Discount
$$MP = \frac{100 + \text{Profit\%}}{100 - \text{Discount\%}} \times CP$$

## 🔢 7. Simple & Compound Interest Shortcuts

### Shortcut 24: CI - SI Difference
For 2 years: $CI - SI = SI \times r/100$
For 3 years: $CI - SI = SI \times r/100 \times (3 + r/100)$

### Shortcut 25: Rule of 72 (Doubling Time)
$$\text{Time to double} \approx \frac{72}{r}$$
(Using compound interest)

### Shortcut 26: Effective Rate (Compounding)
$$\text{Effective rate} = \left(1 + \frac{r}{n}\right)^n - 1$$
Where $n$ = compounding frequency per year

## 📊 8. Average Shortcuts

### Shortcut 27: Average = Sum/Count
Quick sum: If numbers are close to a base $B$:
$$\text{Average} = B + \frac{\sum \text{deviations from } B}{n}$$

### Shortcut 28: Replacing One Value
If average of $n$ values is $A$, and one value $x$ is replaced by $y$:
$$\text{New average} = A + \frac{y - x}{n}$$

### Shortcut 29: Weighted Average
$$A_{weighted} = \frac{w_1x_1 + w_2x_2 + \ldots}{w_1 + w_2 + \ldots}$$

## 🎲 9. Permutation & Combination Shortcuts

### Shortcut 30: Key Formulas
- $nPr = n!/(n-r)!$ (order matters)
- $nCr = n!/[r!(n-r)!]$ (order doesn't matter)
- $nCr = nC(n-r)$
- $nCr + nC(r+1) = (n+1)C(r+1)$

### Shortcut 31: Circular Permutation
- Clockwise ≠ anticlockwise: $(n-1)!$
- Clockwise = anticlockwise: $(n-1)!/2$

### Shortcut 32: Derangements
$$D_n = n!\left(1 - \frac{1}{1!} + \frac{1}{2!} - \frac{1}{3!} + \ldots + \frac{(-1)^n}{n!}\right)$$

## 🎯 10. Probability Shortcuts

### Shortcut 33: Complement Rule
$$P(\text{not A}) = 1 - P(A)$$

### Shortcut 34: Conditional Probability
$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

### Shortcut 35: Independent Events
$$P(A \cap B) = P(A) \times P(B)$$

### Shortcut 36: Mutually Exclusive
$$P(A \cup B) = P(A) + P(B)$$

### Shortcut 37: Bayes' Theorem
$$P(A|B) = \frac{P(B|A) \times P(A)}{P(B)}$$

## 🧮 11. Mensuration Shortcuts

### Shortcut 38: Key Formulas

| Shape | Area | Volume |
|-------|------|--------|
| Triangle | $\frac{1}{2}bh$ | — |
| Circle | $\pi r^2$ | — |
| Sphere | $4\pi r^2$ | $\frac{4}{3}\pi r^3$ |

$$d = a\sqrt{3}$$

### Shortcut 40: Sphere Inscribed in Cube
If sphere diameter = cube side $a$:
$$V_{sphere}/V_{cube} = \pi/6 \approx 52.4\%$$

## ⏰ 12. Clock & Calendar Shortcuts

### Shortcut 41: Angle Between Hands
$$\theta = |30H - 5.5M|$$
where $H$ = hours, $M$ = minutes

### Shortcut 42: Overlap of Hands
Hands overlap 11 times in 12 hours (not 12)
Time between overlaps: $12/11$ hours = 65.45 minutes

### Shortcut 43: Calendar Trick
- Same day after 1 year: +1 day (non-leap), +2 days (leap year)
- Century divisible by 400 → leap year (2000: yes, 1900: no)

## 🧠 13. Miscellaneous Speed Tricks

### Shortcut 44: Squaring Numbers Near 50
$$(50 \pm x)^2 = 2500 \pm 100x + x^2$$
**Example:** $48^2 = 2500 - 200 + 4 = 2304$

### Shortcut 45: Squaring Numbers Ending in 5
$$(\text{xy5})^2 = xy \times (xy+1) \text{ followed by } 25$$
**Example:** $35^2 = 3 \times 4 = 12$, so $1225$

### Shortcut 46: Multiplication by 11
For 2-digit number $ab$: result = $a(a+b)b$ (carry if sum > 9)
**Example:** $47 \times 11 = 4(4+7)7 = 4 \, 11 \, 7 = 517$

### Shortcut 47: Squaring Near 100
$(100 \pm x)^2 = 10000 \pm 200x + x^2$
**Example:** $97^2 = 10000 - 600 + 9 = 9409$

### Shortcut 48: Multiplication by 5
$$n \times 5 = n \times 10 / 2$$
**Example:** $48 \times 5 = 480/2 = 240$

### Shortcut 49: Difference of Squares
$$a^2 - b^2 = (a+b)(a-b)$$
**Example:** $97 \times 103 = (100-3)(100+3) = 10000 - 9 = 9991$

### Shortcut 50: Sum of First n Natural Numbers
$$S = \frac{n(n+1)}{2}$$
First 100: $S = 5050$

### Shortcut 51: Sum of Squares
$$S = \frac{n(n+1)(2n+1)}{6}$$

### Shortcut 52: HCF × LCM
$$HCF \times LCM = \text{Product of two numbers}$$

### Shortcut 53: Last Two Digits of Large Powers
Find pattern in last 2 digits; cycle repeats.
- $7^{4}$ ends in 01 → use cycle of 4 for last 2 digits

### Shortcut 54: Unit Digit of Large Powers
Cycle lengths: 2→4, 3→4, 4→2, 5→1, 6→1, 7→4, 8→4, 9→2

### Shortcut 55: Casting Out 9s (Digital Root)
Sum digits repeatedly until single digit → remainder when divided by 9
Use to verify multiplication results quickly.
