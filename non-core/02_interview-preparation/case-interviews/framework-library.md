# Case Interview Framework Library

> The complete library of consulting frameworks — structure, questions to ask, data required, analysis, insights, and recommendations for each.

## How to Use This Library

1. **Learn the logic** behind each framework (not the words)
2. **Practice adapting** frameworks to specific cases
3. **Combine frameworks** when a case needs it
4. **Never recite** a framework mechanically

## Framework 1: Profitability

**Use when:** "Profits are declining" / "How to improve profitability?"

### Structure
```
Profit = Revenue - Costs

Revenue = Price × Volume
Costs = Fixed + Variable
```

### Questions to Ask
- Is the issue revenue or cost driven?
- Is this recent or a trend?
- Is it company-specific or industry-wide?
- What's the magnitude of the change?

### Data Required
- Revenue breakdown (by product, region, segment)
- Cost breakdown (fixed vs. variable)
- Historical trends (3+ years)
- Industry benchmarks

### Analysis
1. Calculate profit = Revenue - Costs
2. Identify which component changed
3. Dig into the driver (price, volume, cost)
4. Compare to benchmarks

### Possible Insights
- Revenue decline is usually volume, not price
- Cost increases are often variable costs
- The fix depends on which component drives the gap

### Recommendation
- If volume issue: marketing, distribution, product
- If price issue: pricing strategy, value communication
- If cost issue: procurement, efficiency, waste reduction

## Framework 2: Market Entry

**Use when:** "Should we enter [market]?"

### Structure
```
Market Attractiveness
├── Size & Growth
├── Competition
├── Customers
└── Regulation

Company Capabilities
├── Product fit
├── Distribution
├── Brand
└── Capital

Entry Mode
├── Organic
├── Acquisition
├── Partnership
└── Franchise

Financial Viability
├── Investment
├── Returns
└── Risks
```

### Questions to Ask
- What's the market size and growth?
- Who are the competitors?
- What's our competitive advantage?
- What's the entry cost?
- What's the regulatory environment?

### Data Required
- Market size and growth rate
- Competitive landscape
- Customer segments
- Entry costs
- Regulatory requirements

### Analysis
1. Assess market attractiveness
2. Assess company fit
3. Choose entry mode
4. Evaluate financial viability

### Possible Insights
- Attractive market ≠ right market (need capability fit)
- Entry mode matters as much as entry decision
- First-mover vs. fast-follower trade-off

### Recommendation
- Enter / Don't enter
- Entry mode
- Timeline and investment
- Key risks

## Framework 3: Market Sizing

**Use when:** "Estimate X" / "How many Y?"

### Structure
```
Top-Down: Population → Filters → Estimate
Bottom-Up: Unit → Multiply → Scale
Demand: Users × Frequency × Amount
Supply: Capacity × Utilization
```

### Questions to Ask
- What exactly are we estimating?
- What's the geography and time period?
- What segment?

### Data Required
- Population / market size
- Penetration rates
- Usage frequency
- Unit economics

### Analysis
1. Choose method (top-down, bottom-up, demand, supply)
2. Break into components
3. State assumptions
4. Calculate
5. Sanity check

### Possible Insights
- Order of magnitude matters more than precision
- Assumptions drive the answer
- Sanity check validates reasonableness

### Recommendation
- Give a clean estimate with range
- State key assumptions
- Note confidence level

## Framework 4: Growth Strategy

**Use when:** "How to grow?" / "Revenue is flat"

### Structure
```
Organic Growth
├── Market Penetration (existing product, existing market)
├── Market Development (existing product, new market)
├── Product Development (new product, existing market)
└── Diversification (new product, new market)

Inorganic Growth
├── Acquisitions
├── Joint Ventures
├── Partnerships
└── Licensing
```

### Questions to Ask
- What's the current growth rate?
- What's the market potential?
- What are the constraints (capital, capability)?
- What's the risk appetite?

### Data Required
- Current revenue and growth
- Market size and penetration
- Competitive landscape
- Capability assessment

### Analysis
1. Assess current position
2. Evaluate growth options
3. Prioritize based on fit and impact
4. Consider inorganic options

### Possible Insights
- Exhaust organic options before inorganic
- Growth should match capabilities
- Prioritize highest-impact, lowest-risk options

### Recommendation
- Specific growth strategy
- Prioritized initiatives
- Timeline and investment

## Framework 5: Pricing

**Use when:** "How to price X?" / "Should we change price?"

### Structure
```
Cost-Based (floor)
├── Production cost
├── Required margin
└── Break-even

Value-Based (ceiling)
├── Customer value
├── Willingness to pay
└── Alternatives

Competition-Based (anchor)
├── Competitor prices
├── Positioning
└── Elasticity

Pricing Strategy
├── Cost-plus
├── Value-based
├── Penetration
├── Skimming
├── Dynamic
└── Freemium
```

### Questions to Ask
- What's the cost structure?
- What's the customer value?
- What do competitors charge?
- How price-sensitive are customers?

### Data Required
- Cost structure
- Customer willingness to pay
- Competitor pricing
- Price elasticity

### Analysis
1. Determine cost floor
2. Determine value ceiling
3. Anchor on competition
4. Choose strategy

### Possible Insights
- Elasticity determines if price changes help
- Value-based pricing captures more revenue
- Tiered pricing captures multiple segments

### Recommendation
- Specific price or pricing structure
- Rationale
- Expected impact

## Framework 6: Operations Improvement

**Use when:** "How to improve efficiency?" / "Process is slow"

### Structure
```
Current State
├── Process map
├── Bottlenecks
├── Cycle time
└── Waste

Root Cause
├── 5 Whys
├── Fishbone
└── Pareto

Improvement
├── Eliminate waste
├── Automate
├── Redesign
└── Cross-train
```

### Questions to Ask
- What's the current process?
- Where's the bottleneck?
- What's the cycle time?
- What's the waste?

### Data Required
- Process map
- Cycle times
- Resource utilization
- Quality metrics

### Analysis
1. Map the process
2. Identify bottlenecks
3. Find root causes
4. Design improvements

### Possible Insights
- Bottlenecks determine throughput
- Waste is often hidden in waiting/transport
- Small changes can have big impact

### Recommendation
- Specific improvements
- Expected impact
- Implementation plan

## Framework 7: M&A

**Use when:** "Should we acquire X?"

### Structure
```
Strategic Fit
├── Complementarity
├── Capabilities
├── Market access
└── Synergies

Target Assessment
├── Financial health
├── Market position
├── Team
├── Technology
└── Customers

Valuation
├── DCF
├── Comparables
├── Precedents
└── Premium

Integration Risk
├── Culture
├── Systems
├── Talent
└── Customers
```

### Questions to Ask
- Why acquire? (strategic rationale)
- What's the target's financial health?
- What's the fair valuation?
- What are the integration risks?

### Data Required
- Target financials
- Market data
- Comparable valuations
- Integration plan

### Analysis
1. Assess strategic fit
2. Assess target
3. Value the target
4. Assess integration risk

### Possible Insights
- Synergies often overestimated
- Integration is where deals fail
- Valuation premium must be justified

### Recommendation
- Proceed / Don't proceed
- Valuation range
- Integration approach

Positioning

├── Differentiation
└── Focus

### Questions to Ask
- Who are the competitors?
- What's the industry structure?
- What's our differentiation?
- What's sustainable?

### Data Required
- Competitive landscape
- Industry structure
- Cost structure
- Customer preferences

### Analysis
1. Analyze five forces
2. Assess competitive position
3. Choose positioning
4. Identify sustainable advantage

- Sustainable advantage is hard to copy

- Competitive strategy
- Positioning
- Key actions
