## Section A — GIS Fundamentals (Q1–Q5)

**Q1.** The two primary GIS data models are:
- (a) Vector and raster
- (b) Point and polygon
- (c) TIN and CAD
- (d) Grid and network

**Q2.** The UTM zone for longitude 82°E is:
- (a) 43N
- (b) 44N
- (c) 45N
- (d) 42N

**Q3.** NDVI is calculated as:
- (a) $\frac{NIR - Red}{NIR + Red}$
- (b) $\frac{Red - NIR}{Red + NIR}$
- (c) $\frac{NIR + Red}{NIR - Red}$
- (d) $\frac{Green - NIR}{Green + NIR}$

**Q4.** IDW interpolation weights samples by:
- (a) Inverse distance power
- (b) Semivariogram
- (c) Nearest neighbor
- (d) Polynomial regression

**Q5.** The primary key in a relational database:
- (a) Uniquely identifies each record
- (b) Links to another table
- (c) Stores spatial data
- (d) Is optional

## Section B — Remote Sensing & GNSS (Q6–Q10)

**Q6.** The Kappa coefficient measures:
- (a) Overall accuracy
- (b) Agreement beyond chance
- (c) Producer's accuracy
- (d) User's accuracy

**Q7.** The Indian regional navigation system is:
- (a) GPS
- (b) GLONASS
- (c) NavIC (IRNSS)
- (d) Galileo

**Q8.** RTK positioning accuracy is:
- (a) 2–10 m
- (b) 0.5–2 m
- (c) 1–2 cm
- (d) 5–10 cm

**Q9.** The largest GNSS error source is:
- (a) Ionospheric delay
- (b) Receiver noise
- (c) Multipath
- (d) Satellite clock

**Q10.** Sentinel-2 has a revisit time of:
- (a) 16 days
- (b) 5 days
- (c) 24 days
- (d) 1 day

## 📋 Answer Key

| Q | Answer | Explanation |
|:-:|:------:|-------------|
| 1 | (a) | Vector and raster are the two primary models |
| 2 | (b) | 82°E → Zone 44N |
| 3 | (a) | NDVI = (NIR − Red)/(NIR + Red) |
| 4 | (a) | IDW: $w_i = 1/d_i^p$ |
| 5 | (a) | Primary key uniquely identifies records |
| 6 | (b) | Kappa measures agreement beyond chance |
| 7 | (c) | NavIC (IRNSS) is India's system |
| 8 | (c) | RTK: 1–2 cm |
| 9 | (a) | Ionospheric delay: 2–50 m |
| 10 | (b) | Sentinel-2: 5 days |
