# Common Civil Engineering Professional Skills

> Practical knowledge layer applicable across all Core Civil, EPC, PMC, Construction Management, Quantity Surveying, and Infrastructure Consultancy roles.

---

## Overview

While technical depth in specialized tracks like [`HWRE`](../hwre/README.md), [`Structural Analysis`](../structural-analysis/structural-analysis.md), or [`Geotechnical Engineering`](../geotechnical/geotechnical.md) is essential for design engineering, Core Civil placement roles (Site Engineer, Project Engineer, Planning Engineer, Quantity Surveyor, Estimator, Contracts Manager) require a strong command over practical execution, estimation, contracts, tendering, quality assurance, and site safety.

## Preparation Guidance for Interviews

1. **Quant & Estimation:** Be ready to estimate quantities for concrete ($m^3$), brickwork ($m^2$ or $m^3$), and steel reinforcement (metric tons from BBS).
2. **Contracts:** Understand the difference between Item Rate, Lump Sum, Cost Plus, and EPC contracts.
3. **Quality Control:** Know concrete cube testing acceptance criteria (mean strength, standard deviation) and slump cone test values for various structural elements.
4. **Safety:** Emphasize Zero Harm culture, PPE compliance, and excavation shoring safety.
