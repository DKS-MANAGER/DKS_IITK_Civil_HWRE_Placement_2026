## Section A — Project Management (Q1–Q5)

**Q1.** The critical path in a CPM network is:
- (a) The shortest path
- (b) The path with zero float
- (c) The path with maximum float
- (d) The path with most activities

**Q2.** Total float is:
- (a) $LS - ES$
- (b) $EF - ES$
- (c) $LF - ES$
- (d) $LS - EF$

**Q3.** The PERT expected time is:
- (a) $\frac{t_o + 4t_m + t_p}{6}$
- (b) $\frac{t_o + t_m + t_p}{3}$
- (c) $\frac{t_o + 2t_m + t_p}{4}$
- (d) $\frac{4t_o + t_m + t_p}{6}$

**Q4.** The variance of a PERT activity is:
- (a) $\left(\frac{t_p - t_o}{6}\right)^2$
- (b) $\left(\frac{t_p - t_o}{3}\right)^2$
- (c) $\frac{t_p - t_o}{6}$
- (d) $\left(\frac{t_p + t_o}{6}\right)^2$

**Q5.** The 100% rule in WBS states:
- (a) Child elements sum to 100% of parent scope
- (b) Each activity has 100% float
- (c) Project completes at 100% schedule
- (d) All costs are 100% allocated

## Section B — Finance & Estimation (Q6–Q10)

**Q6.** A project is accepted on NPV basis if:
- (a) NPV < 0
- (b) NPV = 0
- (c) NPV > 0
- (d) NPV is negative

**Q7.** The Benefit-Cost Ratio (BCR) accept criterion is:
- (a) BCR < 1
- (b) BCR = 1
- (c) BCR > 1
- (d) BCR = 0

**Q8.** The DSCR viability threshold is:
- (a) > 1.0
- (b) > 1.2
- (c) > 2.0
- (d) > 0.8

**Q9.** The plinth area estimate accuracy is:
- (a) ±3–5%
- (b) ±5–8%
- (c) ±15–20%
- (d) ±50%

**Q10.** HAM (Hybrid Annuity Model) is:
- (a) Govt pays 40% during construction + annuity
- (b) Private owns permanently
- (c) Govt pays 100% upfront
- (d) No government payment

---

## 📋 Answer Key

| Q | Answer | Explanation |
|:-:|:------:|-------------|
| 1 | (b) | Critical path = zero float (longest path) |
| 2 | (a) | $TF = LS - ES = LF - EF$ |
| 3 | (a) | $t_e = (t_o + 4t_m + t_p)/6$ |
| 4 | (a) | $\sigma^2 = ((t_p - t_o)/6)^2$ |
| 5 | (a) | 100% rule: children sum to parent scope |
| 6 | (c) | Accept if NPV > 0 |
| 7 | (c) | Accept if BCR > 1 |
| 8 | (b) | DSCR > 1.2 → viable |
| 9 | (c) | Plinth area: ±15–20% |
| 10 | (a) | HAM: 40% during construction + annuity |
