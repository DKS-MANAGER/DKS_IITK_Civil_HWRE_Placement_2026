# GATE Civil — PYQ System

> Topic-wise GATE Previous Year Question tracking system. Organized by Subject → Topic → Year → Concept → Solution reference.
> **Integrity note**: Full copyrighted question text is not reproduced here. Each entry gives Year + question identifier + concept + solution reference so you can locate the original in official GATE papers.

## How to Use

1. Solve the PYQ from the official GATE paper (links below).
2. Log your result in [`ERROR_ANALYSIS.md`](../ERROR_ANALYSIS.md).
3. Mark the entry `✓` when solved correctly.
4. Re-solve after 1/3/7 days.

## PYQ Practice Protocol

1. **Topic-wise first**: solve all PYQs for one topic before moving on.
2. **Timed**: 2 min per 1-mark, 4 min per 2-mark question.
3. **Analyze**: log every error in [`ERROR_ANALYSIS.md`](../ERROR_ANALYSIS.md).
4. **Reattempt**: re-solve after 1/3/7 days.
5. **Pattern recognition**: note which concepts repeat — those are the highest-yield.
