# Getting Started

> **"I just cloned this repo. What do I do?"** This is the fastest path from zero to productive.

---

## Step 1 — Understand the system (5 minutes)

Read the [README](../README.md) for the big picture. This repository is a **placement operating system**: it organizes core revision, non-core tracks, software skills, interview prep, and company strategy into one searchable structure.

The full navigation map is in [MASTER_NAVIGATION.md](MASTER_NAVIGATION.md).

---

## Step 2 — Pick your track (10 minutes)

Ask yourself: **"Which career track am I targeting?"**

| Track | Where to go |
|:------|:------------|
| Core Civil (structures, geotech, transport, env, infra, geoinformatics) | [`02_core/README.md`](../README.md) |
| HWRE / Water Resources (flagship) | [`02_core/hwre/README.md`](../02_core/hwre/README.md) |
| Non-Core (consulting, data, product, finance, etc.) | [`03_non_core/README.md`](../03_non_core/README.md) |

See [TRACKS.md](TRACKS.md) for the full track breakdown and [ROLES.md](..\03_non_core\README.md) for role-specific paths.
