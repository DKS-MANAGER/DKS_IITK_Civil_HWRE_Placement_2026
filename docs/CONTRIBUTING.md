# Contributing

> **Practical guide for contributing content** to the repository. Follow the quality gates and source policy.

---

## Before You Start

1. Read [content-standards.md](content-standards.md) — the quality gates.
2. Read [SOURCE_POLICY.md](SOURCE_POLICY.md) — the evidence rules.
3. Check the [Content Registry](_SYSTEM/DOCS_CONTENT_REGISTRY.md) to avoid duplication.
4. Check the [File Map](_SYSTEM/DOCS_FILE_MAP.md) to understand the structure.

## Contribution Steps

1. **Choose a template** from [`templates/README.md`](templates/README.md).
2. **Write the content** following the template and quality gates.
3. **Label evidence** per [SOURCE_POLICY.md](SOURCE_POLICY.md).
4. **Cross-link** to related content (see [architecture.md](architecture.md) linking rules).
5. **Add the file** to the correct folder.
6. **Update the registry** — add a row to [`_SYSTEM/DOCS_CONTENT_REGISTRY.md`](_SYSTEM/DOCS_CONTENT_REGISTRY.md).
7. **Update the file map** — add a row to [`_SYSTEM/DOCS_FILE_MAP.md`](_SYSTEM/DOCS_FILE_MAP.md).

---

## Quality Checklist

- [ ] Follows the correct template
- [ ] Technical content is accurate
- [ ] Evidence levels are labeled
- [ ] Links are relative and valid
- [ ] No duplication of canonical content
- [ ] Under the size limit (see [content-standards.md](content-standards.md))
- [ ] Registry and file map updated

---

## What Not to Contribute

- Duplicate explanations of canonical topics
- Unverified or unlabeled claims
- Files over the size limit without splitting
- Content without a clear placement purpose
