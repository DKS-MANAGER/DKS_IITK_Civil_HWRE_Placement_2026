# Rapid Revision Guide

> **High-density revision for when time is short.** 1-day, 3-day, and 7-day plans.

---

## 1-Day Crash Plan

**Goal:** Survive tomorrow's interview with maximum recall.

1. Review the company profile → [COMPANIES.md](COMPANIES.md)
2. Skim the role's core topics → [ROLES.md](ROLES.md)
3. Read revision sheets for your track → [TRACKS.md](TRACKS.md)
4. Review the quick revision system → [`prep/interview/quick-revision-system.md`](../prep/interview/quick-revision-system.md)
5. Do one mock test → [TESTING_GUIDE.md](TESTING_GUIDE.md)

---

## 3-Day Sprint

**Goal:** Solidify weak areas and build confidence.

| Day | Focus |
|:----|:------|
| **Day 1** | Diagnose weak topics (topic tests) |
| **Day 2** | Study + revise weak topics |
| **Day 3** | Full mock + behavioural prep |

---

## 7-Day Sprint

**Goal:** Comprehensive revision across all areas.

| Day | Focus |
|:----|:------|
| **Day 1** | Core subjects — part 1 |
| **Day 2** | Core subjects — part 2 |
| **Day 3** | Non-core / software |
| **Day 4** | Question banks + aptitude |
| **Day 5** | Mock tests |
| **Day 6** | Behavioural + HR |
| **Day 7** | Company-wise + final revision |
