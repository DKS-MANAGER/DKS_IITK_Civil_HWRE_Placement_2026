## 3. Hamilton Helmer's 7 Powers Matrix

| Power | Economic Mechanism | Example Company |
| :--- | :--- | :--- |
| **1. Scale Economies** | Per-unit cost drops as volume scales, allowing lower prices or higher margins. | Amazon AWS, TSMC, Netflix |
| **2. Network Effects** | Value to each user expands as total user count expands. | Visa, Uber, LinkedIn |
| **3. Counter-Positioning** | A new business model that incumbents cannot copy without cannibalizing core cash cows. | Vanguard vs active brokers, Netflix vs Blockbuster |
| **4. Switching Costs** | High financial, procedural, or psychological friction to leave the platform. | Bloomberg Terminal, SAP ERP, Salesforce |
| **5. Branding** | Objective premium price commanded due to subjective consumer trust and identity. | Apple, Rolex, Tiffany & Co. |
| **6. Cornered Resource** | Exclusive access to a scarce asset (patent, regulatory license, superstar team). | ASML EUV lithography, Qualcomm 5G patents |
| **7. Process Power** | Embedded organizational routines that deliver superior quality or speed that cannot be reverse-engineered. | Toyota Production System, Danaher DBS |

## 4. The 9-Step Consulting Case Interview Playbook

```text
1. Listen & Take Structured Notes ──► Write prompt data, confirm exact metric.
2. Ask 3–4 Clarifying Questions   ──► Metric definition, geographic scope, timeline, constraints.
3. Pause for Structure (90 sec)   ──► Construct custom issue tree on paper.
4. Pitch Issue Tree Top-Down      ──► Walk interviewer through major branches.
5. Formulate Initial Hypothesis   ──► "I hypothesize X because Y..."
6. Request Empirical Evidence     ──► "Do we have data on channel customer churn?"
7. Perform Intermediate Math      ──► State formula, calculate with units, sanity check.
8. Brainstorm & Prioritize Fixes  ──► Impact vs Feasibility 2x2 matrix.
9. 60-Second Executive Synthesis  ──► Pyramid Principle: Recommendation ──► 3 Facts ──► Next Steps.
```
