# 03_NON_CORE — Non-Core Placement Preparation Hub

> **Directory Focus**: Role-specific preparation for high-impact placement profiles where the primary job function extends beyond traditional Civil engineering: Management Consulting, Software Engineering, Data Science, Business Analytics, Product Management, Finance, and Operations.  
> **Key Principle**: Each role provides concrete domain study, business frameworks, coding practice, and case execution.

---

## 1. Non-Core Preparation Architecture

```text

├── README.md                      # Non-core master dashboard

```
