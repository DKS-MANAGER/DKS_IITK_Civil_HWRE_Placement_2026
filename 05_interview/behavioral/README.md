# Behavioral Interview Guide — Role Execution & STAR Framework

> **Focus**: Navigating competency-based questions, team conflict, pressure scenarios, and ethical dilemmas during campus placement interviews.

---

## 1. The STAR Method Execution Rules

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                            STAR EXECUTION RULES                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ S - Situation (15-20% time) ──► Clear, concise context (no endless backstory)│
│ T - Task (10-15% time)      ──► Your specific responsibility               │
│ A - Action (50-60% time)    ──► What YOU personally did (tools, decisions) │
│ R - Result (15-20% time)    ──► Quantified impact & lessons learned         │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## 2. Core Behavioral Themes & Story Prompts

| Theme | Common Question | Key Candidate Evidence |
| :--- | :--- | :--- |
| **Conflict Resolution** | *"Tell me about a disagreement with a team member or project guide."* | Focus on data-driven discussion, active listening, and objective compromises. |
| **Handling Failure** | *"Describe a project that failed or did not meet expectations."* | Take ownership, explain root cause, and highlight concrete improvements implemented afterward. |
| **Working Under Pressure**| *"How did you handle competing academic and placement deadlines?"* | Priority matrix (Eisenhower matrix), calendar time-blocking, and transparent communication. |
| **Leadership** | *"Give an example of leading a team through ambiguity."* | Setting clear sub-goals, delegating based on strengths, and providing psychological safety. |
