## 💡 How Shared Cases Connect to 01_roles
- **`02_interview-preparation/case-interviews/`**: Universal problem-solving methods, structuring principles, and communication models reusable across all career tracks.
- **`01_roles/<role>/`**: Role-specific case applications (e.g. `consulting` has airline/cement turnaround cases; `business-analyst` has cart abandonment cases; `risk` has credit card deterioration cases).
