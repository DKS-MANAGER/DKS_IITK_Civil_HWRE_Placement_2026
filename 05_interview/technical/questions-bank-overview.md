## Question Tags

Every question can be tagged for filtering:

```
[P0] [P1] [P2] [P3]          ← Priority
[CONCEPT] [WHY] [WHAT-IF]    ← Question type
[NUMERICAL] [APPLICATION]    ← Application
[TRICK] [ADVANCED]           ← Difficulty
[PROJECT] [SOFTWARE]         ← Context
```

## How to Add a Question

1. **Find the canonical concept page** — do not duplicate the explanation
2. **Add the question** to the appropriate section (A–G) of the subject guide
3. **Tag it** with priority and type
4. **Link it** from this index if it's high-value

> See [Content Standards](../docs/content-standards.md) for question quality requirements.
