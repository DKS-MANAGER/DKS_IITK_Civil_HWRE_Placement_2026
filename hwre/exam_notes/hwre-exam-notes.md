## Interview Question Patterns

### PSU Track (BPCL, EIL, NHPC, NTPC, WAPCOS)

#### BPCL
- Technical breadth across all civil branches
- Direct civil applications plus HR probes on relocation, teamwork, failures, and motivation
- Common topics: Foundations, pavements, bridges, drainage, soil tests, concrete defects

#### EIL
- Samples across structures, transportation, soil, and hydraulics in the same panel
- Answers should be compact, code-aware, and application-first
- Recurring questions: BMD, consolidation, pipe losses, hydraulics, transportation, geotech, project management

#### NHPC / NTPC
- Conceptual derivations, plant/canal logic, project-oriented questioning
- Focus: Hydraulics, hydropower, fluid mechanics, structures, general core recall

### Core Design / Consulting Track (L&T, AECOM, Tata Projects)

#### L&T
- Structural design, site execution, concrete, soil, hydraulics, highways, project controls
- BBS, footing quantities, soil classification, SBC, mix design, curing, deflection, IRC basics

#### AECOM
- Data-backed project discussion, watershed logic, model assumptions, communication clarity
- Focus: Water resources, hydrology modeling, flood risk, GIS, CFD-adjacent planning

#### Tata Projects
- Construction methods, scheduling, QA/QC, contracts, execution risk
- Emphasis: Project lifecycle, productivity, resource planning, site decision-making

### Analytics Track (Merilytics, Quant Firms)

#### Analytics Roles
- Python, stats, SQL, business framing, stakeholder communication
- Show EDA, metrics, reproducibility, crisp insight synthesis

#### Quant (DE Shaw, Tower, Optiver)
- OA + multi-round technical
- Probability, coding, combinatorics, estimation, brainteasers

### HR & GD Filters
- Justification of role choice
- Willingness to work in field locations
- Problem ownership and initiative
- "Why PSU vs higher studies/private" framing

## Key Aptitude Formulas

### Percentage
- Percentage = (Part / Whole) × 100
- Percentage change = (New - Old) / Old × 100

### Ratio & Proportion
- Ratio = First quantity / Second quantity (same units)
- If a:b = c:d, then ad = bc (cross-multiplication)

### Time, Speed & Distance
- Distance = Speed × Time
- Average speed (equal distances): 2ab / (a + b)
- Relative speed (same direction): a - b; (opposite direction): a + b

### Time & Work
- Work = Efficiency × Time
- Efficiency ∝ 1 / Time (inverse proportionality)
- Combined work: 1 / (1/a + 1/b) = ab / (a + b)

### Probability
- Probability = (Favorable outcomes) / (Total outcomes)
- P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
- P(A ∩ B) = P(A) × P(B) for independent events

### Averages
- Average = Sum of observations / Number of observations
