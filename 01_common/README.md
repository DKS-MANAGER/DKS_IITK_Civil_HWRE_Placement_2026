# 01_COMMON — Universal Placement Preparation Foundation

> **Directory Focus**: Foundational skills, quantitative aptitude, behavioral stories, resume building, and communication required across all placement tracks (Core, Consulting, Software, Analytics).  
> **Key Principle**: This folder is NOT a dumping ground. It centralizes common material once so specialized roles link here rather than duplicating.

---

## 1. Directory Architecture

```text
01_common/
├── README.md                      # Common preparation dashboard & roadmaps
├── 01_common/aptitude/                      # Quantitative, logical, verbal, DI & mock test system
├── professional-skills/           # Common engineering management, estimation, BOQ, contracts
├── resume/                        # Master CV guidelines, IIT standard templates & audit checklists
├── behavioral/                    # Behavioral frameworks, conflict resolution & STAR stories
├── interview-fundamentals/        # Generic interview delivery, structured communication, self-intro
├── group-discussion/              # Group Discussion (GD) frameworks & evaluation rubrics
└── placement-math/                # Business arithmetic, CAGR, margins, break-even & Excel
```
