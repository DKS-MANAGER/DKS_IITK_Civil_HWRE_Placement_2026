## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(B) -- `30.00`**
- **Mathematical Proof:**
  - Primes between 20 and 40: $23, 29, 31, 37$.
  - Count $= 4$.
  - Sum $= 23 + 29 + 31 + 37 = 120$.
  - Average $= \frac{120}{4} = 30.00$.
- **Distractor Analysis:**
  - Option (A) $29.00$ omits $37$.

#### Q2 Solution
- **Correct Option:** **(B) -- `1,333`**
- **Mathematical Proof:**
  - In an AP of 7 odd numbers, the median (4th number) is the average $= 37$.
  - The series is: $31, 33, 35, 37, 39, 41, 43$.
  - Smallest $= 31$, Largest $= 43$.
  - Product $= 31 \times 43 = 1,333$.
- **Distractor Analysis:**
  - Option (C) $1,365$ multiplies $35 \times 39$.

#### Q3 Solution
- **Correct Option:** **(C) -- `95.5 kg`**
- **Mathematical Proof:**
  - Advisor weight $= W_{\text{new}} = \text{Old Avg} + (\text{New Total Count} \times \text{Increase in Avg})$
  - $W_{\text{new}} = 58 + (25 \times 1.5) = 58 + 37.5 = 95.5\text{ kg}$.
- **Distractor Analysis:**
  - Option (B) $94.0\text{ kg}$ calculates $58 + (24 \times 1.5)$.

#### Q4 Solution
- **Correct Option:** **(B) -- `100`**
- **Mathematical Proof:**
  - Pass average $= 39$, Fail average $= 15$, Total average $= 35$.
  - By Alligation Rule:
    - $\frac{\text{Passed}}{\text{Failed}} = \frac{35 - 15}{39 - 35} = \frac{20}{4} = \frac{5}{1}$.
  - Total passed $= \frac{5}{5 + 1} \times 120 = \frac{5}{6} \times 120 = 100$.
- **Distractor Analysis:**
  - Option (D) $110$ is an arithmetic miscalculation.

#### Q5 Solution
- **Correct Option:** **(B) -- `35`**
- **Mathematical Proof:**
  - Let original average after 11 innings be $A$.
  - $11 A + 90 = 12(A + 5)$.
  - $11 A + 90 = 12 A + 60 \implies A = 30$.
  - New batting average $= A + 5 = 30 + 5 = 35$.
- **Distractor Analysis:**
  - Option (A) $30$ is the old average before the 12th innings.

#### Q6 Solution
- **Correct Option:** **(B) -- `125`**
- **Mathematical Proof:**
  - If every element $x_i$ is transformed by $y_i = a x_i + b$, the new average is $\bar{y} = a \bar{x} + b$.
  - New average $= 3 \times 40 + 5 = 120 + 5 = 125$.
- **Distractor Analysis:**
  - Option (A) $120$ forgets the constant addition $+5$.

#### Q7 Solution
- **Correct Option:** **(C) -- `22.5 years`**
- **Mathematical Proof:**
  - Total age of 5 members today $= 5 \times 24 = 120\text{ years}$.
  - 6 years ago, each of the remaining 4 members was 6 years younger, and the baby was born (age 0).
  - Total age of the 4 members at that time $= 120 - (5 \times 6) = 120 - 30 = 90\text{ years}$.
  - Average age of the 4 members $= \frac{90}{4} = 22.5\text{ years}$.
- **Distractor Analysis:**
  - Option (A) $18.0\text{ years}$ divides $90$ by $5$ instead of $4$.

#### Q8 Solution
- **Correct Option:** **(A) -- `43.12`**
- **Mathematical Proof:**
  - Net change in sum $= (\text{Correct} - \text{Wrong}) = (48 - 34) + (26 - 62) = +14 - 36 = -22$.
  - Change in average $= \frac{-22}{25} = -0.88$.
  - Correct average $= 44.00 - 0.88 = 43.12$.
- **Distractor Analysis:**
  - Option (D) $44.88$ adds $0.88$ instead of subtracting.

#### Q9 Solution
- **Correct Option:** **(B) -- `55 kg`**
- **Mathematical Proof:**
  - Total weight reduction $= 8 \times 2.5\text{ kg} = 20\text{ kg}$.
  - Weight of new recruit $= 75 - 20 = 55\text{ kg}$.
- **Distractor Analysis:**
  - Option (A) $50\text{ kg}$ subtracts $25\text{ kg}$.

#### Q10 Solution
- **Correct Option:** **(B) -- `36 deg C`**
- **Mathematical Proof:**
  - $M + T + W = 3 \times 36 = 108^\circ\text{C}$.
  - $T + W + Th = 3 \times 38 = 114^\circ\text{C}$.
  - Subtracting equations: $Th - M = 114 - 108 = 6^\circ\text{C}$.
  - Given $Th = 42^\circ\text{C} \implies M = 42 - 6 = 36^\circ\text{C}$.
- **Distractor Analysis:**
  - Option (A) $34^\circ\text{C}$ subtracts $8^\circ\text{C}$.

#### Q11 Solution
- **Correct Option:** **(B) -- `85`**
- **Mathematical Proof:**
  - Let wickets taken before the final match be $W$.
  - New average $= 12.4 - 0.4 = 12.0\text{ runs/wicket}$.
  - Final match performance $= \frac{26}{5} = 5.2\text{ runs/wicket}$.
  - By Alligation Rule:
    - $\frac{\text{Previous Wickets}}{\text{Final Match Wickets}} = \frac{12.0 - 5.2}{12.4 - 12.0} = \frac{6.8}{0.4} = \frac{17}{1}$.
  - Previous wickets $= 17 \times 5 = 85$.
- **Distractor Analysis:**
  - Option (C) $90$ is the total wickets including the final match ($85+5$).

#### Q12 Solution
- **Correct Option:** **(C) -- `INR 6,600`**
- **Mathematical Proof:**
  - Expenditure in first 4 months $= 4 \times 4,500 = \text{INR } 18,000$.
  - Expenditure in next 8 months $= 8 \times 5,400 = \text{INR } 43,200$.
  - Total annual expenditure $= 18,000 + 43,200 = \text{INR } 61,200$.
  - Total annual income $= \text{Expenditure} + \text{Savings} = 61,200 + 18,000 = \text{INR } 79,200$.
  - Average monthly income $= \frac{79,200}{12} = \text{INR } 6,600$.
- **Distractor Analysis:**
  - Option (A) $\text{INR } 6,000$ computes $72,000 / 12$.

#### Q13 Solution
- **Correct Option:** **(C) -- `66`**
- **Mathematical Proof:**
  - Total sum of 11 numbers $= 11 \times 60 = 660$.
  - Sum of first 6 numbers $= 6 \times 58 = 348$.
  - Sum of last 6 numbers $= 6 \times 63 = 378$.
  - $6\text{th number} = (348 + 378) - 660 = 726 - 660 = 66$.
- **Distractor Analysis:**
  - Option (A) $62$ occurs if total sum is miscalculated.

#### Q14 Solution
- **Correct Option:** **(B) -- `81.8 km/h`**
- **Mathematical Proof:**
  - Total distance $= 300\text{ km}$.
  - Total time taken $= \frac{100}{50} + \frac{100}{100} + \frac{100}{150} = 2 + 1 + \frac{2}{3} = \frac{11}{3}\text{ hours}$.
  - Average speed $= \frac{\text{Total Distance}}{\text{Total Time}} = \frac{300}{11/3} = \frac{900}{11} \approx 81.82\text{ km/h}$.
- **Distractor Analysis:**
  - Option (D) $90.0\text{ km/h}$ is the arithmetic mean $(50+100+150)/3 = 100$.

#### Q15 Solution
- **Correct Option:** **(B) -- `72.2`**
- **Mathematical Proof:**
  - Ratio of boys to girls $= 3 : 2$.
  - Let boys' average score be $B$.
  - Girls' average score $= 1.20 B$.
  - Weighted average $= \frac{3B + 2(1.20B)}{3 + 2} = \frac{3B + 2.40B}{5} = \frac{5.40B}{5} = 1.08B$.
  - $1.08B = 78 \implies B = \frac{78}{1.08} = 72.22 \approx 72.2$ (or calibrated option B/C).
