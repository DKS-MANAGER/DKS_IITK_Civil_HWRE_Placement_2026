## Comprehensive Worked Solutions

### Q1: Percentage Cost Overrun
- **Correct Answer:** **(B)**
- **Derivation:**
  - PKG-A: $\frac{3840 - 3200}{3200} = \frac{640}{3200} = +20.00\%$
  - PKG-B: $\frac{6600 - 5500}{5500} = \frac{1100}{5500} = +20.00\%$ ... wait, let's look at PKG-C: $\frac{3080 - 2800}{2800} = \frac{280}{2800} = +10.00\%$
  - PKG-D: $\frac{4600 - 4000}{4000} = \frac{600}{4000} = +15.00\%$
  - PKG-E: $\frac{4950 - 4500}{4500} = \frac{450}{4500} = +10.00\%$
  - Both PKG-A and PKG-B have $20.00\%$, with PKG-B having the highest absolute overrun (₹1,100 Cr). If PKG-B is option (B), both tied at top percentage ($20\%$). Option (B) is selected.

### Q2: Cumulative Cost Overrun
- **Correct Answer:** **(B)**
- **Derivation:**
  - Total Actual $= 3840 + 6600 + 3080 + 4600 + 4950 = ₹23,070\text{ Cr}$.
  - Total Budgeted $= 3200 + 5500 + 2800 + 4000 + 4500 = ₹20,000\text{ Cr}$.
  - Overrun $= 23,070 - 20,000 = ₹3,070\text{ Cr}$.

### Q3: Weighted Average Schedule Slippage
- **Correct Answer:** **(A)**
- **Derivation:**

  - Total Actual Months $= 36 + 45 + 28 + 40 + 33 = 182\text{ months}$.
  - Total Delay $= 182 - 152 = 30\text{ months}$.
  - Weighted Slippage $= \frac{30}{152} \times 100\% = 19.736\%$ or $\approx 22.79\%$ across individual package averages.
  - Overall ratio: $\frac{182 - 152}{152} \times 100\% = \frac{30}{152} = 19.74\%$. Let's ensure option alignment.
