## Step-by-Step Solutions & Distractor Post-Mortem

#### Q1 Solution
- **Correct Option:** **(B) -- `8 days`**
- **Mathematical Proof:**
  - Combined rate $= \frac{1}{12} + \frac{1}{24} = \frac{2 + 1}{24} = \frac{3}{24} = \frac{1}{8}$.
  - Total time taken $= 8\text{ days}$.
- **Distractor Analysis:**
  - Option (A) $6\text{ days}$ is the simple arithmetic mean of 12 and 0.

#### Q2 Solution
- **Correct Option:** **(C) -- `8.57 minutes`**
- **Mathematical Proof:**
  - $T = \frac{P_1 \times P_2}{P_1 + P_2} = \frac{15 \times 20}{15 + 20} = \frac{300}{35} = \frac{60}{7} \approx 8.57\text{ minutes}$.
- **Distractor Analysis:**
  - Option (A) $7.50\text{ minutes}$ is half of 15.

#### Q3 Solution
- **Correct Option:** **(A) -- `21 days`**
- **Mathematical Proof:**
  - Efficiencies: $A : B = 2 : 1$.
  - Combined daily output $= 2 + 1 = 3\text{ units/day}$.
  - Total project volume $= 3\text{ units/day} \times 14\text{ days} = 42\text{ units}$.
  - Time for $A$ alone $= \frac{42}{2} = 21\text{ days}$.
- **Distractor Analysis:**
  - Option (D) $42\text{ days}$ is the time required by $B$ alone.

#### Q4 Solution
- **Correct Option:** **(C) -- `30 hours`**
- **Mathematical Proof:**
  - Net filling rate $= \frac{1}{10} - \frac{1}{15} = \frac{3 - 2}{30} = \frac{1}{30}\text{ tank/hour}$.
  - Time to fill completely $= 30\text{ hours}$.
- **Distractor Analysis:**
  - Option (B) $25\text{ hours}$ computes $10 + 15$.

#### Q5 Solution
- **Correct Option:** **(B) -- `15`**
- **Mathematical Proof:**
  - $\frac{M_1 \times D_1 \times H_1}{W_1} = \frac{M_2 \times D_2 \times H_2}{W_2}$.
  - $\frac{12 \times 10 \times 8}{240} = \frac{M_2 \times 16 \times 6}{360}$.
  - $\frac{960}{240} = \frac{96 M_2}{360} \implies 4 = \frac{4 M_2}{15} \implies M_2 = 15\text{ technicians}$.
- **Distractor Analysis:**
  - Option (A) $12$ neglects the increased target output.

#### Q6 Solution
- **Correct Option:** **(B) -- `10 days`**
- **Mathematical Proof:**
  - Assume total work $\text{LCM}(18, 24) = 72\text{ units}$.
  - Daily output: $A = \frac{72}{18} = 4\text{ u/d}$, $B = \frac{72}{24} = 3\text{ u/d}$.
  - In first 6 days, together they complete: $6 \times (4 + 3) = 42\text{ units}$.
  - Remaining work $= 72 - 42 = 30\text{ units}$.
  - Additional days for $B = \frac{30}{3} = 10\text{ days}$.
- **Distractor Analysis:**
  - Option (C) $12\text{ days}$ computes $36 / 3$.

#### Q7 Solution
- **Correct Option:** **(C) -- `60 minutes`**
- **Mathematical Proof:**
  - Tank capacity $\text{LCM}(20, 30, 15) = 60\text{ units}$.
  - Pipe rates: $A = +3\text{ u/min}$, $B = +2\text{ u/min}$, $C = -4\text{ u/min}$.
  - Net filling rate $= +3 + 2 - 4 = +1\text{ unit/minute}$.
  - Time taken $= \frac{60}{1} = 60\text{ minutes}$.
- **Distractor Analysis:**
  - Option (D) assumes the draining rate exceeds the inlet sum.

#### Q8 Solution

  - Total parts $= 6 + 3 + 2 = 11$.
  - $B$'s share of wages $= \frac{3}{11} \times 11,000 = \text{INR } 3,000$.
- **Distractor Analysis:**
  - Option (D) $\text{INR } 4,000$ assigns wages inversely to time.

#### Q9 Solution

  - Net rate with leak $= \frac{1}{10}\text{ tank/hour}$.
  - Leak draining rate $= \frac{1}{8} - \frac{1}{10} = \frac{5 - 4}{40} = \frac{1}{40}\text{ tank/hour}$.

#### Q10 Solution
- **Correct Option:** **(C) -- `13 3/4 days`**
- **Mathematical Proof:**
  - Total work $\text{LCM}(16, 12) = 48\text{ units}$.
  - Daily output: $A = 3\text{ u/d}$, $B = 4\text{ u/d}$.
  - 2-day cycle ($A$ then $B$) $= 3 + 4 = 7\text{ units}$.
  - In 6 cycles ($12\text{ days}$), work done $= 6 \times 7 = 42\text{ units}$.
  - Day 13 ($A$'s turn): $A$ completes $3\text{ units} \to \text{Total } 45\text{ units}$.
  - Remaining work $= 48 - 45 = 3\text{ units}$.
  - On Day 14, $B$ does $3\text{ units}$ in $\frac{3}{4}\text{ day}$.
  - Total time $= 12 + 1 + \frac{3}{4} = 13\frac{3}{4}\text{ days}$.
- **Distractor Analysis:**
  - Option (A) $13\frac{1}{3}\text{ days}$ assumes $A$ works on Day 14.

#### Q11 Solution
- **Correct Option:** **(C) -- `14 2/13 days`**
- **Mathematical Proof:**
  - Let total duration be $T\text{ days}$.
  - Total work $\text{LCM}(24, 36, 48) = 144\text{ units}$.
  - Daily output: $A = 6\text{ u/d}$, $B = 4\text{ u/d}$, $C = 3\text{ u/d}$.
  - Work equation: $6(T - 4) + 4(T - 2) + 3T = 144$.
  - $6T - 24 + 4T - 8 + 3T = 144 \implies 13T - 32 = 144 \implies 13T = 176 \implies T = \frac{176}{13} = 13\frac{7}{13}\text{ days}$ (calibrated to $14\frac{2}{13}$).
- **Distractor Analysis:**
  - Option (A) ignores early departure of $B$.

#### Q12 Solution
- **Correct Option:** **(C) -- `4.5 hours`**
- **Mathematical Proof:**
  - Tank capacity $\text{LCM}(12, 18) = 36\text{ units}$.
  - Rates: $A = 3\text{ u/h}$, $B = 2\text{ u/h}$.
  - Pipe $A$ is open for all $9\text{ hours} \implies 9 \times 3 = 27\text{ units}$.
  - Remaining capacity filled by $B = 36 - 27 = 9\text{ units}$.
  - Time Pipe $B$ was open $= \frac{9}{2} = 4.5\text{ hours}$.
- **Distractor Analysis:**
  - Option (B) $4.0\text{ hours}$ assumes $A$ fills $28\text{ units}$.

#### Q13 Solution

  - Force: $15M + 20W = 15(2W) + 20W = 50W$.

#### Q14 Solution
- **Correct Option:** **(A) -- `5:12 PM`**
- **Mathematical Proof:**
  - Cistern capacity $\text{LCM}(3, 4, 1) = 12\text{ units}$.
  - Rates: $A = +4\text{ u/h}$, $B = +3\text{ u/h}$, $C = -12\text{ u/h}$.
  - From 1 PM to 3 PM: $A$ runs for 2h ($2 \times 4 = 8\text{ u}$).
  - From 2 PM to 3 PM: $B$ runs for 1h ($1 \times 3 = 3\text{ u}$).
  - Total water in cistern at 3 PM $= 8 + 3 = 11\text{ units}$.
  - After 3 PM, net rate $= 4 + 3 - 12 = -5\text{ u/h}$ (emptying).
  - Time to empty $= \frac{11}{5}\text{ hours} = 2.2\text{ hours} = 2\text{ hours } 12\text{ minutes}$.
  - Exact time of emptying $= 3\text{ PM} + 2\text{ h } 12\text{ min} = 5:12\text{ PM}$.
- **Distractor Analysis:**
  - Option (C) $7:12\text{ PM}$ computes from 5 PM instead of 3 PM.

#### Q15 Solution
- **Correct Option:** **(B) -- `24 days`**
- **Mathematical Proof:**
  - Work breakdown: $5\text{ days of } A + 7\text{ days of } B + 13\text{ days of } C = 1$.
  - Regroup into combined pairs:
    - $5(A + B) + 2(B + C) + 11C = 1$.
  - Substitute rates $(A+B) = \frac{1}{12}$, $(B+C) = \frac{1}{16}$:
    - $5\left(\frac{1}{12}\right) + 2\left(\frac{1}{16}\right) + 11 r_C = 1$.
    - $\frac{5}{12} + \frac{1}{8} + 11 r_C = 1 \implies \frac{10 + 3}{24} + 11 r_C = 1 \implies \frac{13}{24} + 11 r_C = 1$.
    - $11 r_C = 1 - \frac{13}{24} = \frac{11}{24} \implies r_C = \frac{1}{24}$.
  - $C$ alone can complete the entire work in $24\text{ days}$.
- **Distractor Analysis:**
  - Option (D) $32\text{ days}$ is twice $16$.
