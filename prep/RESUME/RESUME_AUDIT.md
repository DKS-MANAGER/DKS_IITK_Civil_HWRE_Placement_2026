# RESUME AUDIT

> **Systematically check your resume for quality.** Work through each section and fix issues before you apply.

---

## 1. Factual Consistency

- [ ] Every date is accurate (education, internships, projects)
- [ ] Every claim is true and verifiable
- [ ] No exaggeration of roles or responsibilities
- [ ] CGPA/percentage matches transcripts
- [ ] No contradictions between sections

> ⚠️ **Interviewers WILL probe your resume.** Any inconsistency is a red flag.

---

## 2. Grammar & Language

- [ ] No spelling errors
- [ ] Consistent tense (past tense for completed work)
- [ ] Action verbs used (Led, Developed, Implemented, Optimized)
- [ ] No first-person ("I") — use implied subject
- [ ] No jargon without explanation
- [ ] Consistent formatting (bullets, fonts, spacing)

---

## 3. Technical Specificity

- [ ] Tools/software named specifically (not "various software")
- [ ] Methods/techniques named (not "advanced analysis")
- [ ] Quantified where possible
- [ ] Role-specific keywords included (for ATS)

**Weak:** "Worked on a water project"
**Strong:** "Modeled flood inundation using HEC-RAS for a 100-year return period, calibrating Manning's n to ±10%"

---

## 4. Metrics & Impact

- [ ] Numbers used where possible (%, ₹, time saved, scale)
- [ ] Outcomes stated, not just activities
- [ ] Impact quantified

**Weak:** "Improved drainage design"
**Strong:** "Redesigned storm drainage network, reducing peak runoff by 22% and cutting material cost by 15%"

---

## 5. Formatting

- [ ] One page (most roles) / two pages (if required)
- [ ] Clear section headings
- [ ] Consistent font and size
- [ ] No tables/graphics (ATS-unfriendly)
- [ ] Reverse-chronological order
- [ ] Readable in 30 seconds

---

## 6. ATS (Applicant Tracking System) Check

- [ ] Standard section headings (Education, Experience, Skills, Projects)
- [ ] Keywords from the job description included
- [ ] No images, tables, or graphics
- [ ] No headers/footers with critical info
- [ ] Standard fonts (Arial, Calibri, Times New Roman)
- [ ] PDF version (not scanned image)

---

## 7. One-Page Constraint

- [ ] Fits on one page (most roles)
- [ ] Most important content in top half
- [ ] No filler or redundant lines
- [ ] Every line earns its place

---

## 8. Final Read-Through

- [ ] Read aloud — catch awkward phrasing
- [ ] Get a second opinion (peer/mentor)
- [ ] Test all links (LinkedIn, GitHub, portfolio)
- [ ] Save as `YourName_Resume.pdf`
