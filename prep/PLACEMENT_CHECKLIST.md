# PLACEMENT CHECKLIST

> **The complete document + logistics checklist for placement season.** Use this to make sure nothing is missing before applications, interviews, and offer acceptance.

---

## 📄 CV & Documents

### CV
- [ ] Final resume (1 page for most roles, 2 pages only if required)
- [ ] ATS-friendly version (no tables/graphics, standard fonts)
- [ ] PDF + DOCX versions
- [ ] Resume reviewed for: factual consistency, grammar, metrics, specificity
- [ ] Resume defence prepared (every line can be defended) → [RESUME/RESUME_DEFENSE.md](RESUME/RESUME_DEFENSE.md)

### Academic Documents
- [ ] All semester grade sheets / transcripts
- [ ] Degree certificate (or provisional)
- [ ] CGPA/percentage calculation sheet
- [ ] Backlog/ATKT documents (if any) — know the exact count
- [ ] Bonafide / student ID

### Certificates
- [ ] Internship offer + completion letters
- [ ] Project certificates
- [ ] Course certificates (NPTEL, Coursera, etc.)
- [ ] Achievement/award certificates
- [ ] Any training certificates

### Portfolio / GitHub
- [ ] GitHub profile cleaned + pinned repos
- [ ] LinkedIn profile updated + professional photo
- [ ] Portfolio website (if relevant)
- [ ] Code samples for software/analytics roles

## 👔 Clothing & Logistics

### Clothing
- [ ] Formal shirt + trousers (men) / formal equivalent (women)
- [ ] Formal shoes (polished)
- [ ] Belt, tie (if required)
- [ ] Neat, ironed, professional

### Logistics
- [ ] Interview location known (building, floor, room)
- [ ] Route + travel time planned
- [ ] Phone charged + silent mode
- [ ] Notepad + pen
- [ ] Water bottle
- [ ] Multiple resume copies (3+)
- [ ] ID card / government ID

## 📅 Before Each Interview

- [ ] Re-read company profile
- [ ] Rehearse self-intro aloud
- [ ] Review 12 key formulas
- [ ] Review 2 key STAR stories
- [ ] Review project defence
- [ ] Sleep 7+ hours

> Full day-of playbook: [Interview Day Survival](interview/interview-day-survival.md)

## ✅ Final Pre-Season Sweep

- [ ] All documents scanned + saved to cloud (Google Drive / OneDrive)
- [ ] Physical copies organized in a folder
- [ ] Backup resume on phone
- [ ] Emergency contact / backup plan for travel
- [ ] All links (GitHub, LinkedIn, portfolio) tested and working
