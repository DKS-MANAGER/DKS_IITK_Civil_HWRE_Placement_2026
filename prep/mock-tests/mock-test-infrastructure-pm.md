# Mock Test — Infrastructure / Project Manager

> **Timed test:** 60 minutes · 3 sections · 50 marks. Simulates an infrastructure/PM technical round (L&T, Tata Projects, ITC, JSW).

---

## Section A — Technical MCQ (10 × 2 = 20 marks) · 15 min

1. In CPM, the critical path is:
   - (a) The longest path with zero float
   - (b) The shortest path
   - (c) Any path with float
   - (d) The path with most activities

2. PERT uses which distribution for activity duration?
   - (a) Beta distribution
   - (b) Normal distribution
   - (c) Uniform distribution
   - (d) Poisson distribution

3. The float of an activity is:
   - (a) The slack time available without delaying the project
   - (b) The duration of the activity
   - (c) The cost of the activity
   - (d) The number of predecessors

4. Earned Value Management (EVM) measures:
   - (a) Cost and schedule performance
   - (b) Only cost
   - (c) Only quality
   - (d) Only safety

5. A PPP model where the private party builds, operates, and transfers is:
   - (a) BOT
   - (b) BOO
   - (c) EPC
   - (d) DBB

6. The cost of a project is typically estimated using:
   - (a) Bill of quantities and rate analysis
   - (b) Only intuition
   - (c) Only past projects
   - (d) Only market rates

7. The critical path method is used for:
   - (a) Scheduling activities with dependencies
   - (b) Cost estimation
   - (c) Quality control
   - (d) Safety management

8. A bar chart (Gantt chart) shows:
   - (a) Activities vs time
   - (b) Cost vs time
   - (c) Resources vs time
   - (d) Quality vs time

9. The contract type where the contractor bears cost overruns is:
   - (a) Lump sum
   - (b) Cost plus
   - (c) Time and materials
   - (d) Unit price

10. The project life cycle stages in order are:
    - (a) Initiation → Planning → Execution → Closure
    - (b) Planning → Initiation → Closure → Execution
    - (c) Execution → Planning → Initiation → Closure
    - (d) Closure → Initiation → Planning → Execution

---

## Section B — Numerical (3 × 8 = 24 marks) · 30 min

**Q1.** A project has activities A (5d), B (3d), C (4d, after A), D (6d, after B), E (2d, after C and D). Draw the network and find the critical path and project duration.

**Q2.** A project has a planned value of ₹100 L, earned value of ₹80 L, and actual cost of ₹90 L. Find CPI, SPI, and interpret the project status.

**Q3.** A building has a plinth area of 500 m² and a plinth area rate of ₹25,000/m². Estimate the total cost including 10% contingencies.

---

## Section C — Behavioral / HR (2 × 3 = 6 marks) · 15 min

1. "Describe a project you managed and how you handled a delay." (STAR)
2. "Why infrastructure/project management, and what tools do you use?" (Motivation)

---

## Answer Key

**Section A:** 1-a, 2-a, 3-a, 4-a, 5-a, 6-a, 7-a, 8-a, 9-a, 10-a

**Section B:**
- Q1: Paths: A→C→E = 5+4+2 = 11d; B→D→E = 3+6+2 = 11d. Both critical, duration 11 days.
- Q2: CPI = EV/AC = 80/90 = 0.89 (<1, over budget). SPI = EV/PV = 80/100 = 0.8 (<1, behind schedule).
- Q3: Base cost = 500 × 25,000 = ₹125 L. With 10% contingency = 125 × 1.1 = ₹137.5 L.

**Section C:** Assess STAR structure, delay handling, tool proficiency, motivation.
