# Mock Test — Technology

> **Timed test:** 60 minutes · 3 sections · 50 marks. Simulates a technology/software technical round (SWE, tech roles).

---

## Section A — Technical MCQ (10 × 2 = 20 marks) · 15 min

1. A stack data structure follows:
   - (a) LIFO (Last In, First Out)
   - (b) FIFO (First In, First Out)
   - (c) Random access
   - (d) Priority order

2. A queue data structure follows:
   - (a) FIFO
   - (b) LIFO
   - (c) Random access
   - (d) Priority order

3. The time complexity of binary search is:
   - (a) O(log n)
   - (b) O(n)
   - (c) O(n²)
   - (d) O(1)

4. A hash table provides:
   - (a) Average O(1) lookup
   - (b) O(n) lookup
   - (c) O(log n) lookup
   - (d) O(n²) lookup

5. SQL is used to:
   - (a) Query relational databases
   - (b) Write operating systems
   - (c) Design hardware
   - (d) Compile code

6. A primary key in a database:
   - (a) Uniquely identifies each row
   - (b) Can be null
   - (c) Can be duplicated
   - (d) Is optional

7. Git is used for:
   - (a) Version control
   - (b) Database management
   - (c) Cloud hosting
   - (d) Testing

8. An API is:
   - (a) An interface for software components to communicate
   - (b) A programming language
   - (c) A database
   - (d) An operating system

9. The time complexity of a nested loop (n iterations each) is:
   - (a) O(n²)
   - (b) O(n)
   - (c) O(log n)
   - (d) O(1)

10. Python is:
    - (a) An interpreted, high-level language
    - (b) A compiled low-level language
    - (c) A markup language
    - (d) A database

---

## Section B — Coding / Numerical (3 × 8 = 24 marks) · 30 min

**Q1.** Write a Python function to reverse a string.

**Q2.** Write a Python function to find the maximum element in a list.

**Q3.** Write a SQL query to find the second-highest salary from an `employees` table.

---

## Section C — Behavioral / HR (2 × 3 = 6 marks) · 15 min

1. "Describe a technical project you built and the challenges." (STAR)
2. "Why technology, and how does your engineering background help?" (Motivation)

---

## Answer Key

**Section A:** 1-a, 2-a, 3-a, 4-a, 5-a, 6-a, 7-a, 8-a, 9-a, 10-a

**Section B:**
- Q1: `def reverse_string(s): return s[::-1]`
- Q2: `def max_element(lst): return max(lst)`
- Q3: `SELECT MAX(salary) FROM employees WHERE salary < (SELECT MAX(salary) FROM employees);`

**Section C:** Assess STAR structure, technical depth, engineering-to-tech bridge, motivation.
