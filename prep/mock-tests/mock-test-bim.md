# Mock Test — BIM Engineer

> **Timed test:** 60 minutes · 3 sections · 50 marks. Simulates a BIM/VDC technical round (BIM consultancies, design firms).

---

## Section A — Technical MCQ (10 × 2 = 20 marks) · 15 min

1. BIM stands for:
   - (a) Building Information Modeling
   - (b) Building Integration Method
   - (c) Basic Information Model
   - (d) Building Infrastructure Management

2. The IFC format is:
   - (a) An open standard for BIM data exchange
   - (b) A proprietary format
   - (c) A 2D drawing format
   - (d) A PDF format

3. LOD in BIM stands for:
   - (a) Level of Development
   - (b) Level of Detail
   - (c) Length of Design
   - (d) Load of Data

4. Clash detection in BIM identifies:
   - (a) Spatial conflicts between building elements
   - (b) Design errors
   - (c) Cost overruns
   - (d) Schedule delays

5. Revit is primarily used for:
   - (a) Architectural and structural modeling
   - (b) Only 2D drafting
   - (c) Only cost estimation
   - (d) Only scheduling

6. Navisworks is used for:
   - (a) Clash detection and model review
   - (b) Structural analysis
   - (c) Soil analysis
   - (d) Traffic modeling

7. A federated model is:
   - (a) A combined model from multiple disciplines
   - (b) A single-discipline model
   - (c) A 2D drawing
   - (d) A cost model

8. The BIM execution plan (BEP) defines:
   - (a) How BIM will be implemented on a project
   - (b) The project budget
   - (c) The construction schedule
   - (d) The material list

9. 4D BIM adds:
   - (a) Time/scheduling dimension
   - (b) Cost dimension
   - (c) Sustainability dimension
   - (d) Quality dimension

10. 5D BIM adds:
    - (a) Cost estimation dimension
    - (b) Time dimension
    - (c) Facility management
    - (d) Structural analysis

---

## Section B — Numerical (3 × 8 = 24 marks) · 30 min

**Q1.** A BIM model has 10,000 elements. If clash detection finds 2% clashes, how many clashes are there?

**Q2.** A project uses LOD 300 for design. If the model is upgraded to LOD 400, what additional information is typically added?

**Q3.** A federated model combines 5 discipline models. If each has 8,000 elements, how many total elements are in the federated model?

---

## Section C — Behavioral / HR (2 × 3 = 6 marks) · 15 min

1. "Describe a BIM project you worked on and the coordination challenges." (STAR)
2. "Why BIM, and what software are you proficient in?" (Motivation)

---

## Answer Key

**Section A:** 1-a, 2-a, 3-a, 4-a, 5-a, 6-a, 7-a, 8-a, 9-a, 10-a

**Section B:**
- Q1: Clashes = 10,000 × 0.02 = 200.
- Q2: LOD 400 adds fabrication/assembly details (shop drawings, fabrication specs) vs LOD 300 (design intent).
- Q3: Total = 5 × 8,000 = 40,000 elements.

**Section C:** Assess STAR structure, coordination awareness, software proficiency, motivation.
