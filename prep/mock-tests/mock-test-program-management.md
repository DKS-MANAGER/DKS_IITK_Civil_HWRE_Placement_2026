# Mock Test — Program / Project Management

> **Timed test:** 60 minutes · 3 sections · 50 marks. Simulates a program/project management technical round (PMO, tech program manager roles).

---

## Section A — Technical MCQ (10 × 2 = 20 marks) · 15 min

1. A program is:
   - (a) A group of related projects managed together
   - (b) A single project
   - (c) A task
   - (d) A portfolio

2. The triple constraint of project management is:
   - (a) Scope, time, cost
   - (b) Quality, safety, cost
   - (c) People, process, tools
   - (d) Risk, quality, time

3. A Gantt chart shows:
   - (a) Activities vs time
   - (b) Cost vs time
   - (c) Resources vs time
   - (d) Quality vs time

4. The critical path is:
   - (a) The longest path with zero float
   - (b) The shortest path
   - (c) Any path
   - (d) The most expensive path

5. Stakeholder management involves:
   - (a) Identifying and engaging all affected parties
   - (b) Ignoring stakeholders
   - (c) Only managing the client
   - (d) Only managing the team

6. A risk register documents:
   - (a) Identified risks and mitigation plans
   - (b) Only resolved risks
   - (c) Only financial risks
   - (d) Project costs

7. The RACI matrix defines:
   - (a) Roles and responsibilities
   - (b) Project budget
   - (c) Project schedule
   - (d) Quality standards

8. Agile methodology emphasizes:
   - (a) Iterative delivery and adaptability
   - (b) Fixed requirements
   - (c) Waterfall phases
   - (d) No planning

9. A milestone is:
   - (a) A significant point in the project schedule
   - (b) A task
   - (c) A deliverable
   - (d) A risk

10. Change management involves:
    - (a) Controlling changes to scope/schedule
    - (b) Ignoring changes
    - (c) Only cost changes
    - (d) Only schedule changes

---

## Section B — Numerical (3 × 8 = 24 marks) · 30 min

**Q1.** A project has activities A (4d), B (3d), C (5d, after A), D (2d, after B), E (3d, after C and D). Find the critical path and project duration.

**Q2.** A project has PV = ₹80 L, EV = ₹60 L, AC = ₹70 L. Find CPI, SPI, and project status.

**Q3.** A project has 10 tasks each with a 10% chance of delay. Estimate the probability that at least one task is delayed.

---

## Section C — Behavioral / HR (2 × 3 = 6 marks) · 15 min

1. "Describe a program you managed and how you coordinated multiple teams." (STAR)
2. "Why program management, and what tools do you use?" (Motivation)

---

## Answer Key

**Section A:** 1-a, 2-a, 3-a, 4-a, 5-a, 6-a, 7-a, 8-a, 9-a, 10-a

**Section B:**
- Q1: Paths: A→C→E = 4+5+3 = 12d; B→D→E = 3+2+3 = 8d. Critical path = A→C→E, duration 12 days.
- Q2: CPI = 60/70 = 0.86 (over budget). SPI = 60/80 = 0.75 (behind schedule).
- Q3: P(at least one delayed) = 1 − P(none delayed) = 1 − 0.9¹⁰ = 1 − 0.349 = 0.651 = 65.1%.

**Section C:** Assess STAR structure, coordination, tool proficiency, motivation.
