# Deltax

## Interview Process
Deltax's selection process consists of three rounds:

1. **MCQ Round** — Programming foundation and aptitude; shortlisting based on score and submission time
2. **Coding Round** — 4-5 easy to medium coding questions; solve at least 80% to qualify
3. **Interview Round** — Explain previous coding solution + solve 1-2 LeetCode medium questions + basic programming and design questions

## Key Notes
- Speed matters in MCQ round (time of submission is a selection criterion)
- Coding round requires efficient solutions with good complexity
- Interview tests both communication (explaining solutions) and problem-solving

## Preparation Tips
- Practice time-bound MCQ tests on aptitude and programming fundamentals
- Solve LeetCode medium-level problems
- Be prepared to explain your code clearly and concisely
