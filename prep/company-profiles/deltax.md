# Deltax — Placement Strategy

> **Track:** Software / Tech (SDE). **Relevance:** HIGH for software-track candidates; speed-focused MCQ + coding process.

## 1. Company Snapshot

| Field | Detail |
|---|---|
| **Company** | Deltax |
| **Domain** | FinTech / Tax Technology — tax automation and compliance software |
| **Role** | Software Development Engineer (SDE) |
| **Eligibility** | All engineering disciplines; strong coding + speed required |
| **Relevance** | **HIGH (software track)** — product company; speed of submission matters in MCQ round |

**About:** Deltax builds tax technology solutions for enterprises, automating GST, income tax, and compliance workflows. Their interview process uniquely weighs both correctness AND speed — the MCQ round considers submission time as a selection criterion.

## 2. Role Reverse Engineering

| Job Responsibility | Required Knowledge | Preparation Action |
|---|---|---|
| Build tax automation features | DSA, Java/Python | Master DSA + one language |
| Backend API development | REST, databases | Practice API design |
| Frontend tax dashboards | React/Angular | Build a dashboard project |
| Data processing pipelines | SQL, ETL basics | Practice data manipulation |
| Client-facing integrations | APIs, documentation | Learn API documentation |

| Priority | Topic | Depth |

| **P0** | Speed aptitude (MCQs) | Strong |
| **P1** | OOP Concepts | Strong |
| **P1** | SQL / Database | Basic |
| **P1** | System design (basic) | Basic |
| **P2** | Web development (React/Angular) | Awareness |

## 4. Key Interview Questions

1. Explain the time complexity of quicksort in best, average, and worst cases.
2. What is the difference between a stack and a queue? Give use cases.
3. Write a function to find all pairs in an array that sum to a target.
4. Explain OOP pillars with examples from your project.
5. What is a virtual function in C++?
6. How would you optimize a database query that takes 30 seconds?
7. Design a simple URL shortener.
8. What is the difference between SQL and NoSQL? When would you use each?
9. Explain the concept of memoization in dynamic programming.
10. What are RESTful APIs? How do you design one?

## 5. Preparation (7-Day)

| Day | Focus |
|---|---|
| 1 | Arrays & Strings — timed practice (speed matters!) |
| 2 | Linked Lists, Stacks, Queues — timed |
| 3 | Trees & Graphs — timed |
| 4 | Dynamic Programming — timed |
| 5 | OOP + SQL fundamentals |
| 6 | System design basics + web development overview |
| 7 | Full mock interview (timed MCQ + coding + technical) |

> **Key tip for Deltax:** Practice with a timer. Their MCQ round explicitly considers submission speed.
