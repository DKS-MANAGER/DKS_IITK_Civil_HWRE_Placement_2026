# Hiremi — Placement Strategy

> **Track:** Software / Tech (SDE). **Relevance:** HIGH for software-track candidates; MEDIUM for civil-track candidates exploring tech roles.

## 1. Company Snapshot

| Field | Detail |
|---|---|
| **Company** | Hiremi |
| **Domain** | EdTech / Talent Acquisition — hiring platform |
| **Role** | Software Development Engineer (SDE) / Full-Stack Developer |
| **Eligibility** | All engineering disciplines; strong coding + communication required |
| **Relevance** | **MEDIUM** — product company; evaluates coding + GD/communication |

**About:** Hiremi is a talent-hiring platform that connects students and freshers with employers. As a startup-stage company, they look for versatile engineers who can communicate well (GD round) and code under pressure.

## 2. Role Reverse Engineering

| Job Responsibility | Required Knowledge | Preparation Action |
|---|---|---|
| Build platform features | DSA, web development | Master core DSA |
| Communication with clients | GD skills, clarity | Practice group discussions |
| Code review & deployment | Git, CI/CD basics | Learn version control |
| Full-stack development | Frontend + Backend | Build a small project |

## 3. Technical Syllabus

| Priority | Topic | Depth |
|---|---|---|
| **P0** | Data Structures & Algorithms | Strong |
| **P0** | Group Discussion / Communication | Strong |
| **P1** | OOP Concepts | Strong |
| **P1** | Web Development basics | Basic |
| **P2** | SQL / Databases | Awareness |

## 4. Key Interview Questions

1. Explain the difference between an array and a linked list.
2. How would you design a simple hiring platform? (GD prompt)
3. Write a function to check if a string is a palindrome.
4. What is the difference between SQL and NoSQL databases?
5. Explain OOP pillars with examples.
6. Describe a time you worked in a team under pressure. (Behavioral)
7. What makes a good product from a user's perspective?

## 5. Preparation (7-Day)

| Day | Focus |
|---|---|
| 1 | Arrays & Strings — LeetCode easy/medium |
| 2 | Linked Lists, Stacks, Queues |
| 3 | Trees & Graphs |
| 4 | Dynamic Programming |
| 5 | OOP + SQL practice |
| 6 | GD practice (mock group discussion) + behavioral stories |
| 7 | Full mock interview + company research |
