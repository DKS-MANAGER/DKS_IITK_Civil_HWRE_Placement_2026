## Common Technical Reference

### Java Key Concepts
| Concept | Key Point |
|---|---|
| Interface vs Abstract Class | Interface: multiple inheritance, no state. Abstract class: single inheritance, can have state |
| Checked vs Unchecked Exceptions | Checked: must handle (IOException). Unchecked: runtime (NullPointerException) |
| JIT vs AOT | JIT: compiles at runtime (JVM). AOT: compiles before execution (native image) |
| Primary Key vs Foreign Key | PK: unique identifier, not null. FK: references another table's PK |
| Thread vs Process | Thread: shares memory space. Process: isolated memory |
