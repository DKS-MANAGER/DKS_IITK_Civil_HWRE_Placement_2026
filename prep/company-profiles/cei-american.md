# CEI America — Placement Strategy

> **Track:** Software / Tech (SDE). **Relevance:** HIGH for software-track candidates; tests breadth across aptitude, programming, networks, and OS.

## 1. Company Snapshot

| Field | Detail |
|---|---|
| **Company** | CEI America (Consulting Engineers International) |
| **Domain** | Technology consulting — software development, IT services |
| **Role** | Software Developer / SDE |
| **Eligibility** | All engineering disciplines; tests broad CS fundamentals |
| **Relevance** | **MEDIUM** — consulting/IT firm; evaluates both aptitude and technical breadth |

**About:** CEI America is a technology consulting firm that provides software development and IT services. Their interview process is notably broad — testing quantitative aptitude, programming, networking, and operating systems in a single first round, followed by coding and technical interviews.

## 2. Role Reverse Engineering

| Job Responsibility | Required Knowledge | Preparation Action |
|---|---|---|
| Software development | Java/C++/C#, OOP, DSA | Master OOP + DSA |
| Database management | SQL, Oracle | Practice SQL queries |
| Client consulting | Communication, SDLC | Study SDLC models |
| Network applications | Networking basics | Review OSI, TCP/IP |
| System-level programming | OS, algorithms | Study OS concepts |

| Priority | Topic | Depth |
|---|---|---|

| **P1** | DSA basics | Basic |
| **P2** | SDLC / Software Engineering | Awareness |

## 4. Key Interview Questions

1. What is the difference between an abstract class and an interface?
2. Explain polymorphism with a real-world example.
3. Write a SQL query to find the second highest salary.
4. What is a deadlock? How do you prevent it?
5. Explain the OSI model layers.
6. What is the difference between TCP and UDP?
7. How does garbage collection work in Java?
8. Explain inheritance types in OOP.
9. What is the difference between a process and a thread?
10. Write a program to reverse an array in place.

## 5. Preparation (7-Day)

| Day | Focus |
|---|---|
| 1 | Quantitative aptitude — numbers, percentages, time-speed-distance |
| 2 | OOP concepts — inheritance, polymorphism, encapsulation, abstraction |
| 3 | Java/C++ fundamentals — exception handling, collections, threading |
| 4 | SQL + Oracle — queries, joins, subqueries, stored procedures |
| 5 | OS basics — processes, threads, memory management, deadlocks |
| 6 | Networking basics — OSI, TCP/IP, HTTP, DNS |
| 7 | Mock interview + coding practice (arrays, strings, linked lists) |
