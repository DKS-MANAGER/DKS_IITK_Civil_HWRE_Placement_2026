# CEI America

## Interview Process
CEI America's selection process consists of three rounds:

1. **Aptitude and Technical Questions** — 40 questions across four sections:
   - Quantitative Aptitude
   - Programming
   - Networks
   - Operating Systems
2. **Coding Challenge** — 7 coding questions; attempt any 4
3. **Technical Interview** — In-depth questions covering:
   - College project work
   - OOPs concepts (Inheritance, Encapsulation, Polymorphism, Abstraction)
   - SQL/Oracle database queries
   - JAVA/.NET/C, C++ practical programming
   - Software Development Life Cycle (SDLC)
   - Basics of algorithms and data structures
   - Programming arrays

## Key Notes
- Round 1 tests both aptitude and technical breadth
- Coding round requires solving 4 out of 7 questions
- Technical interview is comprehensive, covering projects, OOPs, DBMS, and programming

## Preparation Tips
- Practice quantitative aptitude (Time, Speed, Distance; Percentages; Profit/Loss)
- Review OS fundamentals (time complexity, processes, threads)
- Study networking basics (OSI model, TCP/IP, HTTP)
- Prepare project explanations thoroughly
- Practice SQL queries and basic Java/C++ programming
