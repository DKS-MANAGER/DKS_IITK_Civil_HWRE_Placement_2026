# Darwinbox — Placement Strategy

> **Track:** Software / Tech (Full-Stack / Backend). **Relevance:** HIGH for software-track candidates; PHP/Java full-stack focus.

## 1. Company Snapshot

| Field | Detail |
|---|---|
| **Company** | Darwinbox |
| **Domain** | HR Tech SaaS — cloud-based human resource management platform |
| **Role** | Software Development Engineer (SDE) — Full-Stack / Backend |
| **Eligibility** | All engineering disciplines; strong DSA + coding required |
| **Relevance** | **HIGH (software track)** — product company with 5-round process; PHP/Java backend focus |

**About:** Darwinbox is a leading HR tech platform serving 700+ enterprises globally. They offer cloud-based HRMS covering recruitment, payroll, performance, and employee engagement. Their tech stack includes PHP (Laravel), Java, and Angular/React for frontend. The 5-round process filters heavily on coding efficiency and full-stack knowledge.

## 2. Role Reverse Engineering

| Job Responsibility | Required Knowledge | Preparation Action |
|---|---|---|
| Build HR platform features | DSA, PHP/Java | Master DSA + at least one backend language |
| Full-stack development | PHP/Java + Angular/React | Build a full-stack project |
| API design & integration | REST APIs, databases | Practice API design |
| Code quality & efficiency | Clean code, testing | Practice efficient solutions |
| Database optimization | SQL, indexing | Study query optimization |

## 4. Key Interview Questions

1. Explain the difference between array and linked list.
2. What is a hash map? How does collision resolution work?
3. Write a function to find the maximum depth of a binary tree.
4. Explain MVC architecture in PHP/Java.
5. What is the difference between a session and a cookie?
6. How do you optimize a slow SQL query?
7. Explain the concept of ACID in databases.
8. What is a closure in JavaScript? How is it used?
9. How would you design a REST API for an HR module?
10. Explain dependency injection in Spring Boot.
