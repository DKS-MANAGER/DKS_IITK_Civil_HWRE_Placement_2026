# Hubstream — Software Engineering Placement Strategy

> **Track:** Software / Tech (SDE). **Relevance:** HIGH for software-track candidates; MEDIUM for civil-track candidates exploring tech.

## 1. Company Snapshot

| Field | Detail |
|---|---|
| **Company** | Hubstream |
| **Domain** | SaaS — AI-powered talent acquisition / recruitment software |
| **Role** | Software Development Engineer (SDE) |
| **Eligibility** | All engineering disciplines; strong DSA + coding required |
| **Relevance** | **HIGH (software track)** — product company; evaluates core CS fundamentals |

**About:** Hubstream builds AI-driven recruitment and talent-acquisition platforms. As a product (SaaS) company, its interview process focuses on software engineering fundamentals — data structures, algorithms, and system design — rather than domain-specific civil knowledge.

## 2. Role Reverse Engineering

| Job Responsibility | Required Knowledge | Preparation Action |
|---|---|---|
| Build recruitment platform features | DSA, OOP, web development | Master arrays, trees, graphs, DP |
| AI/ML integration | ML basics, APIs | Review ML fundamentals |
| Backend services | Databases, REST APIs | Practice SQL + API design |
| Frontend features | JavaScript/React | Build a small project |

## 3. Technical Syllabus

| Priority | Topic | Depth |
|---|---|---|
| **P0** | Data Structures & Algorithms | Strong |
| **P0** | OOP Concepts | Strong |
| **P1** | Database (SQL) | Basic |
| **P1** | System Design (basic) | Basic |
| **P2** | Web Development (MERN) | Awareness |

## 4. Key Interview Questions

1. Implement a function to reverse a linked list.
2. Find the longest substring without repeating characters.
3. Explain the difference between a stack and a queue.
4. How would you design a URL shortener?
5. Explain OOP concepts with real-world examples.
6. Write a SQL query to find duplicate records in a table.
7. What is the time complexity of binary search?

## 5. Preparation (7-Day)

| Day | Focus |
