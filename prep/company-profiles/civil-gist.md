## 5. Key Interview Questions

1. `[CSV-DERIVED]` Explain the difference between vector and raster data. When do you use each?
2. How would you perform a land-use change detection analysis?
3. Write a SQL query to find all parcels within 500m of a river using PostGIS.
4. What coordinate reference system would you use for India? Why?
5. How do you handle missing data in a spatial dataset?
6. Explain georeferencing. What are common distortion models?
7. What Python libraries have you used for geospatial analysis?
8. How does remote sensing help in environmental impact assessment?
