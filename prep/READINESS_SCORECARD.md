## 4. The Continuous Preparation Feedback & Retest Loop

Preparation is an iterative closed-loop optimization system, not a linear syllabus checklist:

```
                  THE CLOSED-LOOP CALIBRATION ENGINE
        ┌──────────────────────────────────────────────────┐
        │  1. PLAN: Set target role & diagnostic baseline  │
        └─────────────────────────┬────────────────────────┘
                                  │
        ┌─────────────────────────▼────────────────────────┐
        │  2. PREPARE: Targeted modules (Core / Non-Core)  │
        └─────────────────────────┬────────────────────────┘
                                  │
        ┌─────────────────────────▼────────────────────────┐
        │  3. TEST: Timed Sectional / Full Placement Mock  │
        └─────────────────────────┬────────────────────────┘
                                  │
        ┌─────────────────────────▼────────────────────────┐
        │  4. ANALYZE: Classify errors into 4 buckets      │
        │     • [C] Conceptual Gap (Formula/Theorem gap)   │
        │     • [A] Execution Slip (Algebraic/Calculation) │
        │     • [T] Trap (Misread stem / distractor choice)│
        │     • [M] Pacing Bottleneck (> 90s on single Q)  │
        └─────────────────────────┬────────────────────────┘
                                  │
        ┌─────────────────────────▼────────────────────────┐
        │  5. PATCH: Re-solve targeted caselets & guides   │
        └─────────────────────────┬────────────────────────┘
                                  │
        ┌─────────────────────────▼────────────────────────┐
        │  6. RETEST: Alternative module or sectional test │
        └──────────────────────────────────────────────────┘
```
