## 📖 How to Use This System

### Step 1: Build Your Foundation (Day 1-3)
1. Read [`frameworks/answer-framework-library.md`](frameworks/answer-framework-library.md) — learn all frameworks
2. Read [`strategies/answering-strategies.md`](strategies/answering-strategies.md) — master timing and delivery
3. Read [`self_intro/self-introduction-system.md`](self_intro/self-introduction-system.md) — perfect your intro

### Step 2: Build Your Story Bank (Day 3-7)
1. Read [`story-bank/`](story-bank/) — review all 60+ stories
2. Map YOUR experiences to each category
3. Write 15-20 personalized STAR stories
4. Time each story — target 60-90 seconds

### Step 3: Master the Questions (Day 7-14)
1. Work through [`question-master-database.md`](question-master-database.md) — prioritize P0 questions
2. Practice answers using your story bank
3. Check each answer with [`answer-quality-checker.md`](answer-quality-checker.md)

### Step 4: Specialize (Day 14-21)
1. Read [`civil-hwre-behavioral.md`](civil-hwre-behavioral.md) for domain-specific prep
2. Read [`resume-defense-system.md`](resume-defense-system.md) for resume questions
3. Read [`company-fit-analysis.md`](company-fit-analysis.md) for each target company
4. Practice [`group-discussion-mastery.md`](group-discussion-mastery.md) if GD is required

### Step 5: Mock & Refine (Day 21-30)
1. Run [`mock-interviews/mock-interview-system.md`](mock-interviews/mock-interview-system.md) weekly
2. Review [`strategies/follow-up-attack-system.md`](strategies/follow-up-attack-system.md) for probing
3. Use [`rapid-revision-cards.md`](rapid-revision-cards.md) for quick refreshers
4. Re-check answers with [`answer-quality-checker.md`](answer-quality-checker.md)
