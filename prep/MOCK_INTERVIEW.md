> **The canonical mock interview system.** Run structured mock interviews to simulate the real selection process. Use the 5-round structure below with the linked question banks.

## The 5-Round Mock Structure

```
ROUND 1: FUNDAMENTALS
ROUND 2: TECHNICAL DEPTH
ROUND 3: PROJECT / CV DEFENCE
ROUND 4: BEHAVIOURAL / HR
ROUND 5: COMPANY / ROLE-SPECIFIC
```

## Scoring Rubric

Score each round 0–10 on these dimensions:

| Dimension | What It Measures |
|:----------|:-----------------|
| **Technical Accuracy** | Correctness of technical answers |
| **Communication** | Clarity, structure, conciseness |
| **Structure** | Logical organization of answers |
| **Depth** | Depth of understanding vs. surface-level |
| **Honesty** | Admitting unknowns vs. bluffing |
| **Confidence** | Poise under pressure |
| **Recovery from Unknown** | How well you handle questions you don't know |

### Scoring Scale

| Score | Meaning |
|:------|:--------|
| 9–10 | Excellent — interview-ready |
| 7–8 | Good — minor gaps |
| 5–6 | Adequate — needs practice |
| 0–4 | Weak — significant gaps |

## How to Run a Mock

1. **With a partner:** Take turns being interviewer + candidate
2. **Solo:** Record yourself answering, then review
3. **Timed:** Use the round durations above
4. **Honest scoring:** Score yourself harshly — it's practice, not the real thing
